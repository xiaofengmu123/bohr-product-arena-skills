# 自检清单（对应评分维度）

提交前按此清单逐条勾选；每条对应评分维度与验证手段。`scripts/selftest.py` 自动验证其中可机器化的部分，人工部分在交付前手动确认。

## A. 实际效果（40 分）

- [ ] 每条 finding 含原文位置（file + locator + 逐字 quote），不是泛泛提醒 —— 任务完成度
- [ ] 每条 finding 含判定依据（条款/指南/授权范围原文及版本日期）—— 结果正确性
- [ ] 每条 finding 含严重度与可执行修改建议 —— 任务完成度
- [ ] 报出的问题确实成立，依据引用正确，未把风格差异/学科惯例判为违规 —— 结果正确性
- [ ] 六方向按材料实际风险面逐项检查，未只挑最省事的一条 —— 结果完整性
- [ ] 每条 quote 可回查原文，依据出处可独立核对（`validate.py` 全绿）—— 结果可核验性

## B. 使用增益（25 分）

- [ ] 相比基础 Agent，输出从"泛泛提醒"变成"逐条可复核结论" —— 质量增益
- [ ] 候选观察由脚本批量提取（DOI/统计/PII/伦理/版权等），把 64 次请求花在判定而非搜索 —— 效率增益
- [ ] 有公平对照口径：同一材料、同一允许资料范围，记录加载前后差异 —— 增益可验证性

## C. 创新增益（15 分）

- [ ] 来源绑定：quote 归一化后机器回查，误报可被自动拦截 —— 新增能力/方法改进
- [ ] 候选观察与 findings 分离（observation ≠ finding），先候选后判定 —— 方法改进
- [ ] 幂等 merge + 确定性排序，同输入重跑结论一致 —— 创新证据

## D. 可靠体验（10 分）

- [ ] `python3 -B scripts/main.py --help` 退出码 0，调用说明与实际一致 —— 调用与易用性
- [ ] 空目录 / 坏 JSON / 坏编码 / 缺工具四种情况各有可执行处置 —— 异常处理
- [ ] 同输入两次运行结论一致（`selftest.py` 通过确定性检查）—— 运行稳定性

## E. 生态贡献（10 分）

- [ ] SKILL.md 写清用途、适用条件、调用方式、输入输出、异常处理与限制 —— 文档完整性
- [ ] 检查项清单、判定规则、脚本可被他人复用 —— 资源可复用性
- [ ] 沉淀真实审查经验（依据库、误报抑制规则、定位策略）—— 分享推广价值
