# 判定规则（audit-rules）

本文件是审查 Agent 的判定细则。脚本只产出候选观察（observation），本文规定如何把候选判定为
confirmed（成立）/ excluded（排除）/ pending（待复核），并规定类型、严重度与四要素。

## 1. 四类发现

| type | 含义 | 示例 |
|---|---|---|
| `fact_error` | 与原文或可核对事实矛盾 | 正文说 n=50，表中 n=48；引用文献元数据与正文不一致 |
| `insufficient_evidence` | 结论依赖的证据/方法/统计交代不足，无法复核 | 声称显著但未给 p 值/样本量；缺数据可用性声明 |
| `norm_violation` | 违反规范/合规要求 | 缺伦理批件号；第三方图片无授权或许可标注；基金/利益冲突缺失 |
| `suggestion` | 非违规的改进建议 | 格式统一、术语一致性、图表可读性 |

## 2. 严重度四级

- `critical`：可能导致撤稿或伦理/授权硬伤（伪造、重复发表、无知情同意的涉人数据、侵权复用）。
- `major`：影响结论可信度或投稿（关键方法/统计缺失、引用张冠李戴、数据与声明冲突）。
- `minor`：局部或格式问题（引用格式不统一、图表编号缺失、错别字不影响理解）。
- `info`：提示性信息（建议补充数据可用性、术语统一）。

调级原则：不确定严重度时向下调一级并标 `severity_adjusted=true` + 原因。

## 3. 每条发现的四要素

1. **位置**：`file`（与 `evidence.json` 中 `sources[].path` 一致）+ `locator`（`p<N>`，N 为段落号）+ `quote`（逐字取自该段 `norm`，不得改写）。
2. **判定依据 basis**：写条款/期刊要求/数据授权范围的**原文或具体编号**，注明版本与日期；
   确实无法给出条款时写 `basis_unavailable`，并把该条降为 `pending` 或 `suggestion`，不得编造条款。
3. **严重度**：按第 2 节。
4. **可执行修改建议 revision**：给出可操作动作（改哪句、补哪个号、向谁要授权），不写空泛套话。

## 4. 误报抑制（关键）

以下情形**不判违规**，判为 excluded：

- 风格差异、学科惯例、个人表述习惯、非母语措辞；
- 期刊之间引用格式的合法差异（除非目标期刊指南明确要求某种格式）；
- 作者已正确声明但 Agent 未读到的信息（先查原文再判定）；
- 单一来源无法核实、无外部交叉证据的"疑似"（改为 `pending`/`pending_human`）。

冲突信息（同一指标两处不一致）：两处都记录，`basis` 标 `source_conflict`，不武断选一边。

## 5. 六方向默认清单（仅当 case.json 未给出维度时使用）

1. **学术诚信**：数据/图像复用、重复发表、不当署名、利益冲突声明、致谢与基金一致性。
2. **引用规范**：被引文献真实性、元数据一致性、正文论断与引用一一对应、引而不证/张冠李戴、格式统一。
3. **隐私与数据合规**：可识别个人信息、受限/未公开数据、授权与伦理审批、脱敏建议。
4. **版权与许可**：图片/表格/代码/数据集的来源标注、许可类型、复用条件。
5. **伦理审查**：知情同意、伦理批件编号与范围、动物实验规范、风险获益表述与实际设计一致。
6. **投稿要求**：目标期刊/会议作者指南逐条映射，报缺失项/超限项/格式冲突，注明指南版本与日期。

若 case.json 给出了 `review_facets`/`checklist` 等字段，**以 case.json 为准**，本文清单仅作缺省回退。

## 6. 状态判定

- 所有维度已查、无未决问题、无 critical/major 未解决 → `ok`。
- 有部分维度未覆盖、或有 pending 项、或预算/解析受限 → `partial`。
- 无可用材料、关键证据缺失导致无法审查 → `insufficient_evidence`。
- 输入本身损坏（case.json 不可读、无材料路径）→ `input_error`。

`status` 必须诚实：宁可 `partial`，不得把未完成的审查写成 `ok`。

## 7. 可复核性要求

- 每条 quote 必须能被 `scripts/validate.py` 在原文中找到（normalize 后子串匹配）。
- 每个关键数值/论断都可指回 `file + locator + quote`。
- 依据出处能被独立核对：给出期刊名、指南版本、条款号，或明确 `basis_unavailable`。
- 不虚构 DOI、参考文献、期刊要求、伦理批件号、数据。
