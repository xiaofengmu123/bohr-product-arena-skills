# 判定规则与依据绑定

本文是 `SKILL.md` 第 5 节的细化实现，供审查 Agent 与复核人使用。

## 1. 证据溯源（硬要求）

每条**确认的问题**必须具备四个要素，缺一不可：

| 要素 | 字段 | 要求 |
|---|---|---|
| 原文位置 | `file` + `locator` | 指向具体文件与页/行/段 |
| 逐字证据 | `quote` | 从原文原样截取，空白归一化后能被脚本回查命中 |
| 判定依据 | `basis` | 写条款/期刊要求/授权范围**原文**，附版本或日期 |
| 修改建议 | `revision` | 可直接执行，不写"建议检查一下"这类空话 |

每条问题还应有 `evidence`（事实链：为什么此处不成立）与 `title`（一句话概括）。

`evidence_map` 把每个 `finding_id` 映射到多个证据锚点，锚点角色分三类：

- `primary`：直接支撑该问题的原文片段（默认与 finding 的 quote 相同）。
- `supporting`：补充支撑（如方法章节的样本量、图注的来源标注）。
- `contradicting`：与该问题相冲突的信息，用于标 `source_conflict`。

当同一指标在材料中多处不一致时，**两处都记录**并标 `source_conflict`，不得只保留对自己结论有利的一处。

## 2. 类型与严重度

### 类型四分类

| 类型 | 含义 | 典型例子 |
|---|---|---|
| `fact_error` | 与材料内部事实或可查证事实矛盾 | 引用编号张冠李戴、正文数值与表格不一致、声称的批件号无法核对 |
| `insufficient_evidence` | 材料未提供足以支持结论的信息 | 声称"显著性"却未给检验名、方法写"如前所述"而无出处 |
| `norm_violation` | 违反明确的规范/要求 | 缺利益冲突声明、复用第三方图未标注许可、含未脱敏邮箱 |
| `suggestion` | 不违反规范但可改进 | 建议统一引用格式、建议补充效应量与置信区间 |

### 严重度分级

| 级别 | 标准 |
|---|---|
| `critical` | 影响结论成立或涉及违法/伦理红线（伪造数据、受限个人信息泄露、无知情同意的人体研究） |
| `major` | 明显影响可复核性或合规性（证据不足的核心论断、缺伦理批件号、复用未授权） |
| `minor` | 局部问题或可补的缺失（缺效应量、格式不一致、基金号未写全） |
| `info` | 提示性信息（需人工确认的候选、风格提示） |

## 3. 误报抑制（评分关键：误报与漏报同样扣分）

下列情况**不判违规**，确认为风格/惯例/表述差异即可，并在 `rejections` 中记录排除理由：

- 学科惯例差异（如某些领域允许作者-年份与数字引用并存）。
- 个人表述习惯、非母语写作痕迹、不影响理解的用词偏好。
- 作者主动声明过的复用以（如"经版权方许可改编"且已给许可信息）。
- 材料是摘要、提案或章节片段，本身不含完整参考文献/伦理声明，且 task 未要求完整稿。

判定三步走，防止过度解读：

1. **先问"这真的错了吗"**：把观察放回上下文，确认不是反讽、引文、举例或免责声明。
2. **再问"依据存在吗"**：`basis` 必须写得出具体条款或原文；写不出依据的条目降为 `pending_human` 或删除。
3. **最后问"影响多大"**：按严重度标准定级，不因发现了问题就默认抬高。

## 4. 十方向覆盖

六方向（学术诚信、引用规范、隐私与数据合规、版权与许可、伦理审查、投稿要求）+ 四通用（质量、方法、统计、逻辑）。每个方向在 `report.coverage` 中给出：

- `checked`：该方向已系统检查并给出结论（可含"未发现问题"）。
- `pending`：材料部分支持，需人工复核。
- `not_checked`：材料缺失或范围外，注明原因。

只检查最容易的一条会被判"完整性不足"；每个方向必须有一个可核对的结论，而不是空置。

## 5. 脚本观察 → 判定映射

`evidence.json` 中的每条 observation 是候选，字段为
`id/rule/category/type_default/severity_default/file/locator/quote/note`。

Agent 对每条 observation 做四种操作之一：

1. **确认**：转为 finding，可保留或调整 type/severity，补充 evidence/basis/revision。
2. **排除**：写入 `rejections`，附 `reason`（如"风格差异""已授权""反讽语境"）。
3. **改级**：确认存在但重新定 type/severity。
4. **转待复核**：写入 `report.pending_review` 或 `pending_human`。

observation 只是脚手架，最终 verdict 必须来自对原文的阅读，不能照抄 observation 的默认判定。

## 6. 依据来源纪律

- 引用条款/期刊要求时，写出条款原文或要求编号，并注明来源版本与获取日期；拿不到原文时标 `not_reported`，不凭记忆编条款号。
- 核对文献真实性：只确认材料中能查到的元数据（作者、年份、标题、DOI/URL 是否自洽）；无法联网核实时标 `pending_human`，不虚构"该文献不存在"的结论。
- 平台固定案例中，`/input` 下的事实材料和原论文是唯一事实依据；不依据错误的领域标签补造数据。
