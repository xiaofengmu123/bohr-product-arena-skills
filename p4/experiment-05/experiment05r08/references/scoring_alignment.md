## 2. 数据形态分派

运行 `python scripts/main.py inspect` 后，`data_profile.json.data_form` 给出判定；按形态套用对应解释模板。

### trace（弯曲/曲线/谱图）
- 逐条曲线取 `series` 特征：n、y_min/max/range、x_at_y_max/min、单调段、拐点数（差分符号变化）、平台段、一阶差分统计。
- 趋势 = 载荷/位移随 x 的方向与拐点，引用曲线区间与拟合方式；异常 = 某条曲线或某段偏离整体分布（对逐曲线特征向量做 z/IQR/MAD）。
- 原因候选须区分：试样缺陷/夹持滑移/传感器过载/软件零点漂移，每条给支持与排除证据。
- 复核：回查原始 trace 行区间、对照重复、设备日志与量程饱和标记。

### tabular（表格/计算实验，如交叉验证）
- 逐列统计 + 逐折/逐估计器分组指标（均值±std、离群折）；异常绑定到具体 fold/split/estimator。
- 原因候选区分：数据泄漏、随机种子、类别不平衡、估计器不匹配、超参漂移；写 confound_risk。
- 复核：回查 fold 划分、指标列、超参与随机种子；冲突指标记录 `source_conflict`。

### workbook_paper（多表工作簿 + 论文）
- 每 sheet 映射到化验/时间点/条件；与论文方法与结果对齐，交叉核对单位与阈值。
- 异常定位到具体 sheet/行/列；论文数值与工作簿数值不一致时两条都记录。
- 复核：回查对应 sheet 字段、论文段落与图表，核对批次与设备日志。

### generic
- 回退五段通用流程，并在 `uncertainty` 注明“未套用领域模板”。

## 3. 确定性要求

- 文件遍历、列、离群结果、sources 均按字典序排序；统计不含随机数。
- 同一输入重复运行必须逐字节一致（JSON `sort_keys=True`、固定浮点格式化）。

## 4. 复算配方（写入 anomalies/trends 的 threshold 或 fit）

- `z>3.0`：假定近似正态；不满足时优先 IQR/MAD。
- `IQR 1.5×`：Tukey 箱线图离群界限 [Q1−1.5·IQR, Q3+1.5·IQR]。
- `MAD mod-z>3.5`：0.6745·(x−median)/MAD。
- Grubbs：单离群双侧 α=0.05，t 临界值为 Fisher 展开近似，N 小时须精确表复核。
