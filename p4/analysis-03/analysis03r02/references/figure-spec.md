# 图件规范（figure-spec）

本文件是 SKILL.md 第 6 节的细化规则，供阶段 B 执行时逐条落实。所有“应该/必须”均可在导出后逐项人工核对。

## 1. 图表选择决策表

| 数据类型 | 分析目的 | 推荐图型 | 避免 |
|-|-|-|-|
| 单连续变量 | 分布 | 直方图 / 核密度 | 饼图 |
| 连续 × 连续 | 相关 / 趋势 | 散点 / 折线（时间序） | 并列柱（时间序） |
| 分类 × 连续 | 比较 | (分组)箱线 / 小提琴 / 点图 | 饼图（无序分类） |
| 分类构成 | 构成 | 堆叠 / 归一化条形 | 饼图（>4 类） |
| 多连续变量 | 相关矩阵 | 散点矩阵 / 相关热图 / 分面 | 面积图 |
| 类别过多(>6) | — | 聚合或分面 | 硬塞单图 |

硬规则：无序分类不用饼图；时间序列用折线/面积而非并列柱；比较用位置或长度，不用角度或面积。

## 2. 编码方式

- 优先级：位置 > 长度 > 颜色 > 形状 > 面积/角度。面积与角度会系统性夸大差异。
- 类别 >6：聚合为“其他”或分面；无序分类配色不给“有顺序”的连续色标。
- 量纲差异大：分面或标准化（z-score / 相对值），不硬塞双轴；确需双轴时显式标注左右轴与单位。
- 对数变换：轴刻度显式写 “log10(x)” 或 “ln(x)”，不在图上伪装线性。
- 连续色标：给色标范围（min/max）与单位；离散色标给图例一一对应。

## 3. 标注与图注

- 轴标题 = 变量名(单位)，如 `Concentration (mg/L)`；无单位时写 `(arbitrary unit)`。
- 图例项与数据字典一一对应；图例在灰度/色觉障碍下可辨。
- 误差线必须写清是 SD / SEM / 95% CI，并给出样本量 n；不同组 n 不同时逐组标注。
- 显著性给 p 值或记号定义（如 `* p<0.05, ** p<0.01`），并写明统计方法。
- 图注独立于正文可读：包含数据来源、清洗口径、样本量、统计方法、误差线与显著性定义。

## 4. 可读性

- Okabe-Ito 色盲安全配色：橙 `#E69F00`、天蓝 `#56B4E9`、绿 `#009E73`、黄 `#F0E442`、蓝 `#0072B2`、朱红 `#D55E00`、粉 `#CC79A7`、黑 `#000000`；灰度打印下各色亮度可区分。
- 字号 ≥7pt（单栏 3.4 in 宽），坐标轴刻度与图例不小于此下限。
- 网格线浅灰、不压过数据；面板编号 a/b/c 顺序与正文一致。
- 缩放到单栏宽度后仍可读：线宽 ≥0.5pt，点标记不重叠。

## 5. 发表级导出

- 矢量：SVG（可编辑）+ PDF（字体嵌入）；位图：PNG ≥300 dpi。
- 尺寸匹配栏宽：单栏 3.4 in，双栏 7 in（按目标要求覆盖）。
- 中文与特殊符号：先探测可用 CJK 字体（如 Noto Sans CJK / SimHei）；缺字体改英文标签并记 degradation。
- PDF 以 `%PDF-` 开头、SVG 可被 XML 解析；导出后用 `pdftotext` 或文件头校验，失败降级重导一次。

## 6. 质量检查（导出前逐项核对）

1. 图上每个数值可指回源数据（locator + 逐字 quote）。
2. 轴类型（线性/对数）与刻度、单位与数据字典一致。
3. 图例与系列一一对应，误差线含义有定义且给出 n。
4. 显著性标记有统计方法说明。
5. 色标范围（min/max）与源数据一致。
6. 图注独立可读，不含未定义缩写。
