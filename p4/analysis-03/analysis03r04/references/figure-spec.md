# 图型选择 / 编码 / 标注 / 导出规范

本文件是 SKILL.md 第 6 节“执行规则”的可复核细则。每一条规则都必须在
`result.json` 里留下对应证据（`sources[].locator` + 逐字 `quote`），
无法取证时不得声称“已满足”，应记 `limitations`/`uncertainty`。

## 1. 图型选择（按数据类型 × 分析目的）

| 数据类型 | 分析目的 | 推荐 | 不推荐（原因） |
|-|-|-|-|
| 连续 | 分布 | 直方图、箱线图 | 饼图（只能构成）、并列柱（丢分布） |
| 连续 + 分类 | 比较 | 分组箱线 / 小提琴 / 抖动点图 | 饼图、并列均值柱（丢分布） |
| 分类 | 比较/频数 | 横向条形（长度编码） | 饼图（角度/面积夸大，灰度不可辨） |
| 连续×连续 | 相关 | 散点（可加回归线） | 折线（非时间序列暗示连续性） |
| 时间序列 | 趋势 | 折线（保持时间顺序） | 并列柱（破坏顺序） |
| 分类构成 | 构成 | 堆叠 / 归一化条形 | 饼图、环形图（面积/角度） |
| 多变量 | 探索 | 散点矩阵 / 相关热图 / 分面 | 单图堆叠过多系列 |

原则：**位置 > 长度 > 颜色/形状；面积与角度只在构成且类别≤5 时谨慎使用**。
类别 >6 时聚合或分面，不硬塞进一张图；量纲差异大时分面或标准化，禁止
无说明的双轴。

## 2. 编码映射（每个视觉通道必须写清变量与含义）

- 一条图只让一个通道承载一个变量；颜色优先 Okabe-Ito 色盲安全色，并保证
  灰度打印可辨（用亮度差校验，不只用色相差）。
- 分类变量用颜色/形状时，图例顺序与数据字典一致；连续变量用色标时注明
  色标范围与方向，色标必须覆盖数据实际 min/max，不人为截断。
- 对数轴必须在轴标目写明“log10(x)”或对数刻度，不得当线性轴标注；基线
  从 0 起（除非有明确理由并在图注说明截断口径）。

## 3. 标注与图注（图注须脱离正文可读）

- 轴标题 = 变量名 (单位)；无单位时写“无单位”，不臆造。
- 误差线必须写明 **SD / SEM / 95% CI** 三选一并给 n；显著性标注给
  p 值或记号定义（如 \* p<0.05），只标注真正比较过的组。
- 图注包含：样本量 n、统计方法、离群/缺失处理口径、数据来源定位
  （`data.csv#L2` 之类）、面板编号与顺序。

## 4. 可读性

- 字号 ≥7pt（单栏 3.4 in 缩放后仍可读）；线宽 ≥0.5pt；网格线浅灰且置后。
- 面板编号 a/b/c 按读取顺序，图注对应编号。
- 中文标签先探测 CJK 字体；探测失败改英文标签并记 `degradations`，不得
  输出豆腐块乱码冒充完成。

## 5. 发表级导出

- 必产 SVG（可编辑矢量）+ PDF（字体嵌入）+ ≥300 dpi PNG；尺寸匹配期刊/
  报告栏宽（默认单栏 3.4 in，可选双栏 7.0 in），并在图注/`artifacts` 注明。
- 导出失败逐项记录到 `limitations`（level=`critical`，recoverable=false 时
  `status` 不得为 `ok`）；缺字体、缺库都如实降级，不伪造文件。
