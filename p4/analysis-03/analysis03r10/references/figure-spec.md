# 图表选型、编码、标注与导出规范

本文件把 SKILL.md 第 6 节的规则展开为可执行判定，供执行阶段逐条落实，也供 `scripts/ir.py` 的规则引擎读取。所有"推荐/不推荐"都要给理由，理由必须落到数据结构本身。

## 1. 数据类型识别

- 数值连续（numeric-continuous）：可比较大小与距离，如长度、浓度、分数。
- 数值离散（numeric-discrete）：整数计数（如花朵数、试验次数），按连续处理但刻度取整数。
- 有序分类（ordinal）：如 低/中/高、Likert 1–5；可排序但间距未必相等。
- 无序分类（nominal）：如物种、处理组、样本编号；只能比较"是否相同"。
- 日期时间（datetime）：有序且间距可计算，特殊处理为时间序列。
- 文本/标识符（id/text）：不参与统计，仅作定位或标注。

类型判定以"字段语义 + 数据字典"为准，不只看 dtype 字符串；数据字典与 dtype 冲突时，以数据字典为准并在 `uncertainty` 注明。

## 2. 图表选型规则

| 数据类型 | 分析目的 | 推荐图型 | 不推荐及原因 |
|---|---|---|---|
| 连续×1 | 分布 | 直方图、箱线图 | 饼图（不是构成）、散点（无第二变量） |
| 连续 vs 无序分类 | 分组比较 | 分组箱线/小提琴/点图 | 饼图（类别间用角度比较失真） |
| 连续 vs 有序分类 | 趋势 | 折线/点线 | 并列柱（有序相邻关系应连线） |
| 构成 | 构成比例 | 归一化堆叠条形 | 饼图（多类别角度难比较；>4 类难读） |
| 连续×2 | 相关/趋势 | 散点（加回归线可选） | 并列柱（丢掉了成对关系） |
| 连续×多 | 多变量 | 散点矩阵、相关热图、分面 | 单一图塞多类别（>6 类不可读） |
| 时间序列 | 趋势 | 折线（对数轴标注） | 并列柱（时间连续性丢失） |

不推荐理由必须写明，如"无序分类画饼图会迫使读者比较角度/面积，而人对角度感知不精确"。

## 3. 编码映射规则

- 优先顺序：位置（position）> 长度（length）> 颜色/形状/分面（color/shape/facet）> 面积/角度（area/angle）。
- 量值差异用位置或长度编码；面积、角度只用于非负量且任务明确要求，且要在图注写明"面积/角度编码放大视觉差异"。
- 类别数 ≤6：可用颜色+形状区分；>6：聚合到"其他"或分面；分面每面板类别 ≤6。
- 量纲差异大：先标准化（z-score）或分面双轴，不硬塞同一轴；双轴组合必须显式标注左右轴刻度与含义。
- 对数变换：轴刻度写成真实值并标注 `log10` / `ln`，图注说明为何取对数（如"跨多个数量级"）。
- 颜色：Okabe-Ito 八色（#E69F00 #56B4E9 #009E73 #F0E442 #0072B2 #D55E00 #CC79A7 #000000），灰度打印可辨；不用红绿单独承载关键差异（色觉障碍）。

## 4. 标注与图注规则

- 轴标题 = 变量名（单位），单位来自数据字典；无单位标注"arbitrary units"或"无单位"。
- 图例项与数据字典取值一一对应，图例标题写变量名。
- 误差线必须写明：`SD`（标准差）/`SEM`（标准误）/`CI95`（95% 置信区间）三选一或全给，并给出每组样本量 n；没有误差线则写明"未提供误差线及原因"。
- 显著性：给 p 值或星号记号（并定义 * p<0.05, ** p<0.01, *** p<0.001）；统计检验方法（如 t 检验、ANOVA、Mann-Whitney）写进图注。
- 图注要求：脱离正文可读，含图表类型、样本量、变量定义、统计方法、误差线含义、色标范围、面板编号。
- 色标（color scale）必须标注取值范围与单位；对数色标写 `log10`。

## 5. 可读性规则

- 字号 ≥7pt（正文与轴标签）；单栏宽度 3.4 in（86.4 mm），双栏 7.0 in（178 mm）。
- 面板编号顺序：从左到右、从上到下；分面标题写变量与取值。
- 网格线：浅灰、半透明，不压过数据标记；基线不截断（除对数轴天然从正数起）。
- 图例不遮挡数据；类别多时图例放图外或分面。

## 6. 发表级导出规则

- 必须导出：SVG（可编辑矢量）+ PDF（字体嵌入）+ ≥300 dpi PNG。
- PDF 字体嵌入：用 matplotlib 默认即嵌入；若用其他后端，显式检查 `%PDF-` 头与字体子集。
- 中文/特殊符号：先探测 CJK 字体（如 Noto Sans CJK、SimHei、SimSun、WenQuanYi）；缺字体改英文标签并在 `degradations` 记录 `missing_cjk_font`。
- 尺寸与线宽：画布按目标栏宽；最小线宽 0.5pt；线宽与字号随缩放成比例。
- 文件名：`<case_id>_<fig_id>.svg|.pdf|.png`，全部落 `/app/output/`。

## 7. 清洗口径（先记录，后处理）

- 缺失：记录每列缺失数 → 决定删除/填充（均值、中位数、前值、模型），填充必须写规则与填充值，原始值保留在 `work/raw_snapshot` 或清洗表中。
- 异常：IQR（Q1−1.5·IQR, Q3+1.5·IQR）或 z-score（|z|>3）判定，只记录不自动删除；确为测量错误才剔除并保留原始值。
- 重复：按所有列或主键判定；删除前保留重复行快照，记录删除数。
- 任何清洗步骤都写进 `data_profile.cleaning` 与 `result.json.change_log`，不静默修改。

## 8. 证据溯源示例（通用模板，非正式案例结果）

每张图渲染前，先在 FigureIR 里把"图元 → 源数据"绑定好，再据此生成 `result.json.sources`。以"分组箱线图的组中位数"为例（通用演示，非正式案例）：

```json
{
  "figure_element": "fig1: species=setosa 的箱线图中位数",
  "locator": "iris.csv#col1 分组后中位数",
  "quote": "5.1,3.5,1.4,0.2,Iris-setosa\n4.9,3.0,1.4,0.2,Iris-setosa",
  "kind": "derived_statistic"
}
```

- `quote` 必须是从材料里逐字截取的片段（含影响该统计量的原始行），不得改写、不得四舍五入。
- 派生统计（均值、中位数、p 值）在 `kind` 标 `derived_statistic`，原始观测标 `value`，数据字典/字段语义标 `definition`。
- 两条来源对同一指标不一致时，各记一条并加 `"conflict": true`，`result.json.sources` 标 `source_conflict`；不选边、不隐藏。

## 9. 交付清单（每图至少 4 个文件）

每张图交付：绘图代码（`.py`，消费 FigureIR，不直接读原始数据）+ 图注（`.md`）+ SVG + PDF + ≥300dpi PNG；`result.json.artifacts` 列出全部主产物路径与格式。若无法渲染（缺软件/字体），交付"纯文本统计表 + 数据表"作为降级产物，并在 `degradations` 写明 limitation，不伪装成完整图。
