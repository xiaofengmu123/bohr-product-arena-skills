# 图件规范（执行时逐条落实）

## 1. 清洗口径（先记录，再处理）

- 缺失：统计每列缺失数并记录到 `result.json` 的清洗表；不静默删除或填充；填充必须写清方法（如中位数）与理由。
- 异常：用 1.5×IQR 或 z>3 初筛，但必须回看源数据判断是否为真实离群；保留原始值与剔除规则。
- 重复：按业务键判定（如样本 ID + 时间戳），剔除前记录重复行与判定键。
- 任何剔除/填充/变换都要在 `change_log` 记一条，并在 `evidence_map` 给一条 `decision` 记录（locator 指向被处理的原始行）。

## 2. 选图规则

| 数据/目的 | 推荐 | 不推荐 |
|---|---|---|
| 单连续变量分布 | 直方图 / 箱线 / 小提琴 | 饼图 |
| 分类比较（无序） | 箱线 / 小提琴 / 点图 | 饼图、雷达图 |
| 构成 | 堆叠 / 归一化条形 | 多系列饼图 |
| 相关 / 趋势 | 散点 / 折线 | 并列柱（时间序列） |
| 多变量 | 散点矩阵 / 相关热图 / 分面 | 单图硬塞多系列 |

判定依据是**数据类型 × 分析目的**，不是美观；每个选择在 `change_log` 里写一句理由。

## 3. 编码方式

- 优先位置、长度；面积、角度会夸大差异，仅当差异本身就是比例时谨慎使用。
- 类别 >6：聚合为"其他"或分面；不硬塞进单一图例。
- 量纲差异大：分面或标准化（z-score/归一化），不默认双轴；确需双轴要显式标注左右轴变量。
- 对数轴：轴刻度显式标注"log₁₀"或给出刻度值，禁止把对数轴当线性轴解读。

## 4. 标注与图注

- 轴标题 = 变量名（单位），来自数据字典；图例项与数据字典一一对应。
- 误差线必须写明 SD / SEM / CI 并给 n；显著性给 p 值或记号定义（如 * p<0.05）。
- 图注脱离正文可读：对象、处理、样本量、统计方法、误差线含义、显著水平。
- 面板编号（a/b/c…）与顺序固定。

## 5. 可读性

- Okabe-Ito 色盲安全配色，灰度打印可辨；不使用只有红绿差异的配色。
- 字号 ≥7pt；单栏宽 3.4 in（约 86 mm）；网格线细且低对比。
- 每张图交付一份 `figure_map`：每个轴标目、单位、图例项、误差线、显著性、色标范围 → 一条 `evidence_map` 的 `id`。

## 6. 发表级导出

- SVG（可编辑）+ PDF（字体嵌入）+ ≥300 dpi PNG 三格式；尺寸匹配栏宽。
- 中文：先探测 CJK 字体（如 Noto Sans CJK / SimHei）；缺字体改英文标签并记 `degradations`。
- PDF 以 `%PDF-` 开头、SVG 可被 XML 解析、PNG 头部合法；`check` 会机械验证。

## 7. 复现性

- 固定随机种子（如 `np.random.seed(42)`）、固定排序（`sort` 前显式 key）、固定布局参数。
- 重跑两次统计与图形一致；不一致时在 `uncertainty` 记录原因，不掩盖。
