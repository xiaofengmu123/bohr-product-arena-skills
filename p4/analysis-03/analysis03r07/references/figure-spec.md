# 图表规范（figure-spec）

执行时逐条落实；每条都是"图上的视觉元素必须与源数据一一对应"这一硬约束的展开。

## 0. 字段判型与统计口径（分析前必做）

- 逐列判型：数值（连续/整数）、分类（名义/有序）、日期时间、布尔、文本；判型依据写入
  evidence（locator=列名#头部样本），类型混杂列记录混杂样本与处理规则。
- 统计方法映射（按数据满足的假设选择，不套固定公式）：

| 分析目的 | 满足假设时 | 不满足时 |
|---|---|---|
| 两组连续比较 | 独立样本 t 检验（正态+方差齐） | Mann-Whitney U |
| 多组连续比较 | 单因素 ANOVA + 事后检验 | Kruskal-Wallis |
| 两连续相关 | Pearson r（正态） | Spearman ρ |
| 分类关联 | 卡方检验 | Fisher 精确检验 |

- 正态性检验记录方法（如 Shapiro-Wilk）与结论；不满足时注明改用非参数并写入图注。
- 误差线选择：展示样本内分布→SD；估计总体均值→SEM 或 95% CI，必须写清含义并给 n。

## 1. 数据口径（先记录，再处理）

- 缺失、异常、重复**先记录**（locator + 逐字 quote + 规则），再决定剔除/保留/填充。
- 不静默删除、不静默填充；剔除必须同时保留原始值与删除规则，并写入 `anomalies`。
- 字段类型混杂（数字列夹字符串）、中文列名、日期时间列：按列探测类型，逐列记录判型依据。
- 宽表/长表识别：有多个度量列且无单值列时视为宽表，先 `melt` 成长表再选图。

## 2. 图表选择（按数据类型 × 分析目的）

| 数据/目的 | 推荐 | 不推荐及原因 |
|---|---|---|
| 连续分布 | 直方图 / 密度 | 饼图（无连续意义） |
| 连续比较 | 箱线 / 小提琴 / 点图 | 并列柱（掩盖分布形状） |
| 无序分类比较 | (分组)箱线 / 点图 | 饼图（角度比较不可靠） |
| 构成 | 堆叠 / 归一化条形 | 多饼图（面积误导） |
| 相关/趋势 | 散点 / 折线 | 并列柱（丢失顺序关系） |
| 时间序列 | 折线 | 并列柱（割裂时间顺序） |
| 多变量 | 散点矩阵 / 相关热图 / 分面 | 单图硬塞多类别 |

选图必须给出理由，并把"不推荐图型的原因"写入 `uncertainty` 或图注旁注。

## 3. 编码方式

- 优先位置/长度；面积与角度会夸大差异，避免用气泡面积、饼图角度承载比较结论。
- 类别 >6 聚合或分面；量纲差异大时分面或标准化，并在轴标题注明变换。
- 对数轴必须显式标注"对数轴 (log10)"，不得把对数轴当线性轴读数。
- 颜色用 Okabe-Ito 色盲安全配色；同一信息至少另靠形状/线型/灰度可辨，不单靠颜色。
- 色标（colormap）连续变量用感知均匀渐变色（如 viridis），并标注色标范围与单位。

## 4. 标注与图注

- 轴标题 = 变量名(单位)；图例文字对应数据字典原始值，不擅自改写类别名。
- 误差线写明是 SD / SEM / CI 并给 n；显著性给 p 值或记号定义（\*, \*\*, \*\*\* 含义）。
- 图注（caption）脱离正文可读：对象、样本量、统计方法、误差线定义、显著性记号。
- 面板编号（a/b/c）与顺序固定，图注按编号一一对应。

## 5. 可读性

- 字号 ≥7pt；单栏宽 3.4 in（约 8.6 cm）；网格线浅色、留白充分。
- 灰度打印可辨：转灰度后同一色系各水平仍有可辨亮度差。

## 6. 发表级导出

- 必出 SVG + PDF（字体嵌入）+ ≥300 dpi PNG；尺寸匹配栏宽。
- matplotlib 固定参数：`pdf.fonttype=42`（TrueType 嵌入）、`svg.fonttype='none'`（保留
  文本可编辑）、`ps.fonttype=42`、`axes.linewidth>=0.5`、`font.size>=7`。
- 栏宽映射：单栏 3.4 in（约 8.6 cm）、双栏 7.0 in（约 17.8 cm）；多面板图按栏宽等分。
- 中文/特殊符号：先探测可用 CJK 字体；缺字体时改用英文标签，并在 `degradations`
  记录"中文标签降级为英文"。
- 复现性：固定随机种子、固定类别排序、固定布局；同一输入两次运行图形一致。

## 7. 图注模板（可复用，逐项填空后随图交付）

> 图 N. **一句话结论**。对象与样本量（n=…；数据来源/数据集标识）。变量定义与单位。
> 图中元素含义：点为单个样本、箱线为四分位距（须线=1.5×IQR 范围）、误差线为
> **SD/SEM/95% CI（择一）**（n=…）。统计方法：…（如独立样本 t 检验，双侧）。
> 显著性：`* p<0.05, ** p<0.01, *** p<0.001`（或给出具体 p 值）。缩写与色标范围说明。

## 8. 证据溯源

- 每个关键数值、图元、统计量给出 `{locator, quote, kind, hash}`；locator 形如
  `data.csv#L12` 或 `materials/xxx.md#p3`，quote 为材料逐字片段。
- 冲突信息不隐藏：同一指标两个来源不一致时全部记录并标 `source_conflict`。
