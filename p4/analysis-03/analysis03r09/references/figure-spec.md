# 图件规范与检查清单

执行 `scripts/viz.py` 前后逐条落实本规范。目标是：图上每个视觉元素都能指回源数据，
图件无需二次修补即可投稿，且他人可按记录重跑。

## 1. 数据口径（先记录，再处理）

- 缺失值：统一识别 `""/NA/N/A/nan/null/None/?/.` 等；**不静默填充**。相关分析仅用该列
  非缺失行并在图注/`cleaning.json` 说明。
- 异常值：连续变量用 IQR 1.5 倍界识别（Q1−1.5IQR, Q3+1.5IQR），**默认保留并标注**，
  不静默剔除；若任务要求剔除，须保留原始值与剔除规则。
- 重复行：记录完全重复行数，保留首个；说明口径。
- 口径全部落入 `{prefix}.cleaning.json`，关键数字同时进 `result.json` 的 `sources`。

## 2. 选图（数据类型 × 分析目的）

| 数据形态 | 目的 | 推荐 | 避免 |
|---|---|---|---|
| 连续单变量 | 分布 | 直方图 + 均值/中位线，或箱线 | 饼图 |
| 分类 × 连续 | 比较 | 分组箱线/小提琴/点图（标注 n） | 饼图、并列柱塞多组 |
| 分类单变量 | 构成/计数 | 条形图（按值排序） | 饼图（无序分类） |
| 两连续 | 相关/趋势 | 散点 + 最小二乘线 + r | 双轴强行组合 |
| 多连续（≥3） | 相关结构 | 相关热图（值标注格内） | 逐一两两散点 |
| 时间序列 | 趋势 | 折线图 | 并列柱 |

判定顺序：先看数据类型（连续/分类/时间/多变量），再看目的（分布/比较/相关/趋势/构成）。

## 3. 编码

- 优先位置、长度；**面积与角度会夸大差异**，不用于精确比较。
- 类别 >6：聚合或分面；类别 ≤6 用 Okabe-Ito 配色并同时用形状/明度区分（灰度可辨）。
- 量纲差异大：分面或标准化，**不用双轴掩盖关系**；确需对数轴必须显式标注 `log10`。
- 图例顺序与数据字典一致；同组同色，跨图一致。

## 4. 标注与图注

- 轴标题 = 变量名(单位)；图例项对应数据字典字段语义。
- 误差线必须写明 SD / SEM / CI 三者之一，并给出 n。
- 显著性给 p 值或记号定义（如 `* p<0.05`）；相关给 Pearson r 与样本量。
- 图注脱离正文可读：含数据来源、样本量、统计方法、编码含义、配色与导出格式。
- 色标范围（如热图 −1~1）在图内明确。

## 5. 可读性

- Okabe-Ito 色盲安全配色 `#0072B2 #E69F00 #009E73 #D55E00 #CC79A7 #56B4E9 #F0E442 #000000`。
- 字号 ≥7pt；单栏宽 3.4 in（双栏/整页按目标期刊调整，默认 3.4）。
- 网格线淡灰、留白充足、面板编号与顺序稳定。

## 6. 发表级导出

- 必须 SVG + PDF（字体嵌入）+ ≥300 dpi PNG 三件套。
- 中文/特殊符号：先探测 CJK 字体（Noto/Source Han/文泉驿/雅黑/黑体等）；缺字体时
  列名改 `col0/col1…` 占位并在 `degradations` + 图注记录原列名映射，**不渲染乱码方框**。
- 尺寸匹配栏宽，线宽与字号在目标尺寸下仍可读。

## 7. 证据溯源与复现

- 每个关键数值/图元给出 `locator`（如 `data.csv#col[sepal_length]` 或 `table#L2`）+
  逐字 `quote`。
- 同指标两来源不一致：两条都记并标 `source_conflict`，不隐藏冲突。
- 复现：固定类别排序（按名称/中位数）、固定布局、固定种子；同参数重跑两次图形一致。
- 绘图代码随图交付（`{prefix}.code.py` + `{prefix}.config.json`），加载 `cleaned.csv` 可重画。

- [ ] 每个关键数值/图元有 `locator` + 逐字 `quote`，冲突标 `source_conflict`
- [ ] 图上数值/轴类型/刻度/单位/图例/误差线含义/显著性/色标范围与源数据一致
- [ ] 覆盖任务全部图表要素，交付绘图代码 + 图注
- [ ] 导出 SVG+PDF+≥300dpi PNG，尺寸匹配栏宽，中文无乱码
- [ ] 重跑两次统计与图形一致
- [ ] 缺失/异常/失败均显式说明，无编造
- [ ] 空输入/坏 JSON/缺参数也产出合法 `result.json` 且退出码 0
