# 图表与导出规范（执行时逐条落实）

本文件是 SKILL.md §5 的细则。所有规则的目标一致：**图上每个视觉元素都能指回源数据，
图件可脱离正文读懂，且能不经二次修补直接投稿或进入正式报告。**

## 1. 数据口径（先记录，再处理）

- 缺失、异常、重复**先记录后处理**，写清口径；不得静默删除或填充。
- 剔除必须保留原始值与规则：在 `work/cleaning.md` 记「原始值 → 规则 → 结果」三元组，
  并同步写入 result.json 的 `sources` 与 `degradations`。
- 数值解析口径：千分位、百分号、货币符号、括号负数（`(12.3)` → `-12.3`）逐条说明；
  无法解析的值记 `not_reported`，不猜。
- 重复判定：以「主键/全部业务列」为准；无主键时按整行去重并在 `uncertainty` 标注。

## 2. 选图（类型 × 目的）

| 数据结构 | 分析目的 | 推荐图型 | 不推荐 |
|---|---|---|---|
| 单连续 | 分布 | 直方图 / 密度曲线 | 饼图 |
| 单连续 × 多组 | 比较分布 | 分组箱线 / 小提琴 / 抖动点图 | 并列柱（隐藏分布） |
| 分类 × 连续 | 比较中心+离散 | (分组)箱线 / 点图+误差线 | 饼图（无序分类） |
| 构成 | 占比 | 归一化堆叠条形（≤6 类） | 饼图（>3 类不可靠） |
| 两连续 | 相关/趋势 | 散点（+拟合线，注明方法） | 平滑曲线冒充因果 |
| 时间序列 | 趋势 | 折线（点线图） | 并列柱 |
| 多变量 | 关系矩阵 | 散点矩阵 / 相关热图 / 分面 | 3D 饼图 |

- 无序分类不画饼图；时间序列不画并列柱；构成类超过 6 类聚合为「其他」或分面。
- 记录推荐理由与「不推荐某图型的原因」，写入图注或 `work/chart_choice.md`。

## 3. 编码方式

- 优先**位置/长度**编码差异；面积与角度会系统性夸大差异，仅用于占比且轴从 0 起。
- 颜色仅编码分类（最多 8 类），不编码连续量级（用位置或明度序列）。
- 类别 >6 聚合或分面；量纲差异大时分面或标准化（注明标准化方式）。
- 对数轴显式标注「log10」，不把对数轴当线性轴读；基线截断必须画断裂标记或注明。
- 双轴组合仅在两个量纲有明确换算关系时使用，并标注两条轴各自单位。

## 4. 标注与图注

- 轴标题 = 变量名（单位）；图例逐项对应数据字典，不缩写到无法对应。
- 误差线必须写明含义：SD（标准差）/ SEM（标准误）/ CI（置信区间）并给样本量 n。
- 显著性给出 p 值或记号定义（如 `* p<0.05, ** p<0.01, *** p<0.001`），并写检验方法。
- 图注脱离正文可读：包含样本、统计方法、误差线定义、显著性定义、色标范围与面板含义。
- 面板编号按 (a)(b)(c) 顺序；色标（colormap）给范围与单位。

## 5. 可读性

- 配色：Okabe-Ito 色盲安全色（`#E69F00 #56B4E9 #009E73 #F0E442 #0072B2 #D55E00 #CC79A7 #000000`），
  灰度打印可辨（明度有差异）。
- 字号 ≥7pt；单栏宽 3.4 in（86.4 mm），双栏 7.0 in；线宽 ≥0.5pt。
- 网格线淡灰（#cccccc）且不压过数据；留白充分，不堆叠。

## 6. 发表级导出

- 导出 `SVG`（矢量，可编辑）+ `PDF`（字体嵌入）+ `PNG`（≥300 dpi）。
- 中文/特殊符号：先探测系统 CJK 字体（matplotlib `font_manager`）；缺字体改英文标签，
  并在 `degradations` 记录 `cjk_font_missing`，不输出乱码。
- 画布尺寸匹配目标栏宽；导出后运行 `main.py check` 校验 PNG 分辨率与 SVG/PDF 合法性。
- 绘图代码写入 `work/plot_*.py` 并在图注/`sources` 记录脚本路径，保证可复跑。

## 7. 确定性

- 随机种子固定 `seed=42`（记录在 result.json `determinism.seed`），不使用系统随机数。
- 类别排序用「(频次, 标签)」稳定排序；JSON 用 `sort_keys=True`；布局参数显式给定。
- 输入/输出指纹由 `main.py manifest` 维护，`main.py check` 复核输入指纹是否与产物一致。
- 同一输入、同一 Python 版本，两次运行统计与图形字节级一致（`scripts/selftest.py` 验证）。
