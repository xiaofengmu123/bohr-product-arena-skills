# 评分维度对齐清单（本版设计重心）

本 Skill 不把评分当作"外部评审"，而把它内化为执行时的审计清单：每个维度都映射到
一个流程步骤、一组可勾选自检项、以及 result.json 中的一个证据字段。规则：**文字
自述不能替代运行证据**——只有落进 `sources`/`artifacts`/`scorecard`/`quality_gain`
/`figure_check`/`change_log` 的条目才算完成。

## 1. 实际效果（40 分）

| 评分点(分) | 流程落点 | 自检 | 证据字段 |
|-|-|-|-|
| 任务完成度(15) | 阶段 B 全部：真实图件+绘图代码+图注 | S1 | artifacts / 图件文件 |
| 结果正确性(15) | 阶段 B⑤⑥：图元与源数据逐一对齐 | S2 | figure_check / sources |
| 结果完整性(5) | 阶段 B⑥⑦：轴、单位、图例、误差线、显著性、色标、图注、面板编号、比例尺、格式分辨率 | S3 | 契约字段回填 |
| 结果可核验性(5) | 阶段 A→C：源数据→成图链可复跑逐元素核对 | S4 | sources(locator+quote) / change_log |

执行要求：每个关键数值/图元调用 `main.py add-source --locator ... --quote ...` 登记
逐字证据；图元与源值的一致性用 `main.py check-figure` 校验；源值必须来自真实读入
的文件，不得凭记忆填写。

## 2. 使用增益（25 分）

| 评分点(分) | 流程落点 | 自检 | 证据字段 |
|-|-|-|-|
| 质量增益(15) | 选图/编码/标注/导出规则 vs 基础 Agent 常见失败 | S5 | quality_gain.baseline/skill |
| 效率增益(5) | 减少重画/格式调整/导出试错/人工核对 | S5 | quality_gain.reductions |
| 增益可验证性(5) | 公平对照：同输入同任务，记录差异 | S5 | quality_gain.evidence |

执行要求：在 `quality_gain` 中记录与基础 Agent 的可观察差异（例如"基础 Agent 把无
序分类画成饼图，本 Skill 输出分组箱线"）与减少的返工项；不自称"更好"而无对照项。

## 3. 创新增益（15 分）

| 评分点(分) | 流程落点 | 自检 | 证据字段 |
|-|-|-|-|
| 新增能力(5) | profile.py 按数据结构/目的推荐图型；check-figure 校验图元一致性 | S6 | chart_plan.json / figure_check |
| 方法改进(5) | 选型规则+编码映射+标注生成+导出流水线针对真实难点 | S6 | chart_plan.candidates 的 reason/not_recommended |
| 创新证据(5) | 证明相对通用画图方案的价值边界 | S6 | scorecard.innovation |

执行要求：`chart_plan.json` 每个候选图型必须写清推荐理由与不推荐理由；`figure_check`
每条注明"源值 vs 图上值"与匹配结果。

## 4. 可靠体验（10 分）

| 评分点(分) | 流程落点 | 自检 | 证据字段 |
|-|-|-|-|
| 调用与易用性(3) | 触发清晰、命令可跑 | S7 | SKILL.md 示例 / 退出码 |
| 运行稳定性(4) | 宽/长表、缺失列、类型混杂、中文列名、日期时间、规模、重复运行 | S7 | degradations / 复现说明 |
| 异常处理(3) | 缺失/异常/重复/样本不足/类别过多/导出失败/字体缺失/权限不足 | S8 | errors / degradations |

执行要求：所有脚本异常也退出码 0；空输入/坏 JSON 也产出合法 result.json；固定随机
种子与确定性布局保证重跑一致。

## 自检映射速查（对应 SKILL.md 第 7 节）

- S1 完成度 → 实际效果/任务完成度
- S2 正确性 → 实际效果/结果正确性
- S3 完整性 → 实际效果/结果完整性
- S4 可核验 → 实际效果/结果可核验性
- S5 增益可验证 → 使用增益
- S6 创新证据 → 创新增益
- S7 稳定 → 可靠体验/运行稳定性
- S8 异常 → 可靠体验/异常处理
- S9 生态 → 生态贡献
- 通用项 → result.json 合法 + 退出码 0
