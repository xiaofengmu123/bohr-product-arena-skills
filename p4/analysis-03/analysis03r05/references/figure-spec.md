# 图件规范（选图 / 编码 / 标注 / 导出）

本规范是 SKILL.md 第 5 节的展开。执行时逐条落实；任何一处偏离都应在
`result.json` 的 `uncertainty` 或 `degradations` 中显式说明，不得静默处理。

## 1. 数据口径先于画图

- 先读数据字典、字段语义与约束：列名、单位、类型、取值域、缺失码（如 NA/-999/空串）。
- 缺失/异常/重复**先记录再处理**：写清规则（删除条件、填充方法与理由、离群阈值），
  保留原始值与逐行定位（locator），剔除记录必须在 `result.json.sources` 或
  `cleaning` 契约字段中可追溯。
- 不静默删除、不静默填充、不静默改类型；量纲与单位转换须显式记录换算关系。

## 2. 图表选择（类型 × 目的）

| 数据类型 | 分析目的 | 推荐 | 不推荐及理由 |
|-|-|-|-|
| 连续单变量 | 分布 | 直方图 / 密度 / 箱线 / 小提琴 | 饼图（无分布信息） |
| 分类比较 | 组间差异 | (分组)箱线 / 小提琴 / 点图（带抖动） | 饼图（无序分类不构成比例整体） |
| 构成 | 占比 | 堆叠/归一化条形 | 3D 饼图（角度与体积失真） |
| 相关趋势 | 两变量关系 | 散点（连续×连续）/ 折线（时间序列） | 时间序列画并列柱（错用离散编码） |
| 多变量 | 联合结构 | 散点矩阵 / 相关热图 / 分面 | 单图硬塞多变量 |
| 分组时间序列 | 趋势对比 | 分面折线 / 折线+误差带 | 并列柱堆叠误导 |

选择理由与"不推荐某图型的原因"必须写进图注或 `result.json` 的图型说明字段。

## 3. 编码方式

- 优先位置/长度编码连续量；面积与角度会夸大差异，谨慎用于比例类数据。
- 颜色优先作分组/离散映射，不单独承载连续精度；连续量用有序色标（如 viridis），
  显式标注色标范围与单位。
- 类别 >6 时聚合为"其他"或分面，避免色相不可分辨。
- 量纲差异大的变量分面或标准化，不强行双轴；确需对数轴时在轴标注明"对数刻度"。
- 离散分类使用 Okabe-Ito 色盲安全色板：橙 #E69F00、天蓝 #56B4E9、蓝绿 #009E73、
  黄 #F0E442、蓝 #0072B2、朱红 #D55E00、紫红 #CC79A7；灰度打印需亮度可分。

## 4. 标注与图注

- 轴标题 = 变量名（单位）；刻度字号 ≥7pt，网格线弱化不压数据。
- 图例对应数据字典；符号/线型/颜色与图中系列一一对应。
- 误差线必须写明 SD / SEM / CI（置信水平）并给出样本量 n；显著性给 p 值或
  记号定义（如 `* p<0.05, ** p<0.01, ns 不显著`）。
- 图注脱离正文可读：图型、变量、单位、样本量、统计方法、误差线含义、显著性
  定义、异常处理、数据来源逐条列清；面板编号按 (a)(b)(c) 顺序。

## 5. 发表级导出

- 同时导出：可编辑 SVG、字体嵌入的 PDF、≥300 dpi PNG。
- 单栏宽 3.4 in（双栏 7.0 in）；导出前用 `figure.set_size_inches` 固定画布，
  保持文字与线宽在缩印后仍 ≥7pt / ≥0.5pt。
- 中文先探测 CJK 字体（如 Noto Sans CJK / SimHei）；缺字体时改用英文标签并在
  `degradations` 记录，不输出乱码。
- 固定随机种子、排序与布局，重复运行得到同一张图；绘图代码与图注一并落盘。

## 6. 一致性核验（逐元素）

- 图上的每个点/柱/线/误差棒/显著性记号都要能指回源数据行（locator + 逐字 quote）。
- 色标范围、轴范围、刻度与源数据 min/max 一致；截断基线须显式标注断裂符号。
- 导出后读回图像核对：无元素缺失、无乱码、无色标越界、字号达标。
