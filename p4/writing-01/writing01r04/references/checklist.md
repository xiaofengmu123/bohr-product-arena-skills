# 自检清单与处置动作（Checklist & Degradation）

按题目评分维度组织，每条可勾选；未通过时按右侧动作处置。收口前逐条执行。

## A. 实际效果（40 分）

- [ ] 稿件是完整可编辑章节稿，不是提纲/写作建议/素材堆叠 → 重写为连贯段落章节稿
- [ ] 每个数值/单位/样本量/统计显著性/图注可指回 material_index 的 locator+quote → 补 evidence_map 条目
- [ ] 正文无材料外事实；补写处已标 `[待确认]` → 删除或标注
- [ ] 每条事实性论断可指回具体材料位置与文献条目 → 补 `[S:]`/`[C:]`
- [ ] 改动留痕 → `scripts/main.py --step record --note ...`

## B. 使用增益（25 分）

- [ ] 从拿到材料到可修改初稿无需人工返工重写 → 按模板一次成稿
- [ ] 摘要与结果、正文与图注、方法与步骤无冲突 → `consistency_check.py` 清零
- [ ] 对照公平：材料、章节模板、字数范围、引用格式、工具权限一致 → 不引入额外前提

## C. 创新增益（15 分）

- [ ] 材料-图表-正文三向对齐成立 → evidence_map 每条三字段齐备
- [ ] 论断-引用绑定成立 → 每条 `[C:键]` 有定义且支撑所在句
- [ ] 章节缺项检测成立 → 缺项显式标注并计入 uncertainty
- [ ] 术语与缩写统一 → 全稿口径一致

## D. 可靠体验（10 分）

- [ ] agent 能被正确触发，材料能喂入并产出可编辑稿件 → 验证输入发现逻辑
- [ ] 换学科/换篇幅/换材料完整度/重复运行均稳定 → 运行 `selftest.py`
- [ ] 缺图注、图表冲突、文献取不到全文、材料超长、引用格式不识别的识别与处置 → 见降级表

## E. 生态贡献（10 分）

- [ ] SKILL.md、章节模板、材料格式、依赖、示例、适用与维护信息齐全
- [ ] 脚本可被他人直接复用 → 仅标准库、相对路径、参数化
- [ ] 有可分享的案例/题集/学科适配经验与真实价值说明

## F. 降级处置表

| 情况 | 处置 |
|---|---|
| PDF 解析缺失/失败 | 用可用工具；失败标 `[无法解析]`，不凭标签补写 |
| 图表缺图注 | 图注标 `[缺失]`，正文标 `[待确认]`，计入 uncertainty |
| 文献取不到全文 | 仅用给定元数据；缺失字段写 `unknown`，禁止补 DOI |
| 材料冲突 | 并列各方+来源，标 `[冲突待确认]`，记 `source_conflict` |
| 材料超长 | 按可用部分产出 `partial`，说明未处理部分 |
| 格式不认识 | 统一为 `[C:键] 作者. 题目. 期刊 年份;卷(期):页. DOI` |
| 空输入 | 退出码 0，写 `insufficient_evidence` 并列缺口 |
| 脚本失败 | 保留骨架，手工补字段，如实记录 |

## G. 收口前三查

1. `result.json` 能被 `json.load` 正常读取；
2. `sources` 每条 `ref_id`/`cite_key` 都能在 material_index 或 literature 中找到；
3. `uncertainty` 覆盖全部 `[缺失]`/`[待确认]`/`[冲突待确认]`/`[无法解析]` 标记。
