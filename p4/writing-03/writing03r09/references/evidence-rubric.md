# 证据强度分级与不确定性口径

## 1. 证据强度等级（evidence_level）

| 等级 | 含义 | 适用 |
|-|-|-|
| direct_quote | 逐字引用原文，定位可回查 | 数字、术语、结论、引用 |
| paraphrase_supported | 转述，原文可支撑该句 | 一般论断 |
| inference | 由原文推断，原文未直接表述 | 须加“可推断/初步表明” |
| unverified | 无法在材料中核验 | 标 `pending_human` 或删除 |

原则：能逐字引用的不用转述；能转述的不推断；原文没有的不写。

## 2. 来源类型分级

- primary_study（原始研究）：最高可信，仍受样本量与设计约束。
- review（综述）/ guideline（指南）：领域综合，非新证据。
- preprint（预印本）：未经同行评议，明确标注。
- secondary（二手转引）：仅当原始文献不可得时使用，标“转引自”。

## 3. 不确定性表述口径

- 相关 ≠ 因果：观察性研究只能说“与…相关”，不能说“导致”。
- 单篇小样本 ≠ 领域共识：加“本研究中/该样本中”。
- 冲突证据并列：同一指标两个来源不一致，两个都记录并标 `source_conflict`。
- 未报告：写 `not_reported`，不猜测数值。

## 4. 论断—来源记录结构（fact_source_map 条目）

```json
{
  "claim_id": "C1",
  "claim_text": "一句可判定的论断",
  "quote": "逐字摘录原文片段",
  "locator": "materials/paper.md#p3 或 PDF 第 3 页",
  "source_ref": "sources 中的 id",
  "evidence_level": "direct_quote",
  "status": "confirmed | needs_confirmation | conflict"
}
```

## 5. 常见失败类型

- 摘录与论断脱节（quote 不支持 claim_text）。
- locator 指不到实际段落或页码。
- 证据强度与表述不匹配（把推断写成事实）。
- 冲突证据只保留一方。
- 元数据错误或二手转引未标注。

## 6. 模板规格检查项（本任务特有）

每项记“规格值—成品实测值—符合性”三元组，逐项可核对：

栏数、字号、行距、页边距、标题层级、编号规则、图表题注位置与字号、参考文献样式（字段顺序 / 作者截断 / 标点 / 中英文混排）、页眉页脚、字体嵌入、页面尺寸、目录页码、导出格式、内容单元完整性（正文 / 图表 / 公式 / 脚注 / 批注 / 修订 / 域代码）。
