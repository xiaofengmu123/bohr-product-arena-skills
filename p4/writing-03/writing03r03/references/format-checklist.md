# 学术格式与模板适配：可勾选检查清单

本文档是 Skill 的硬检查基准，逐条对应评分维度“实际效果 / 结果正确性 / 结果完整性 / 结果可核验性”。每条检查项都必须落到 `result.json` 的 `fact_source_map`（带 locator + 逐字 quote）或 `deliverable.format_spec_applied`，不允许只写“已核对”而无定位。

## A. 认得准：模板规格提取

- [ ] A1 从模板/格式要求中逐项抽取：栏数、字号、行距、页边距、标题层级、图题/表题位置与字号、参考文献样式、导出格式
- [ ] A2 每项规格都记录 `locator`（模板文件路径 + 页码/段落）与逐字 `quote`；无逐字原文可引时标 `verification="unverified"`
- [ ] A3 模板版本号、适用对象（学位论文/期刊投稿/报告）已记录到 `sources`
- [ ] A4 同一规格出现两个相互冲突的规定时，两条并列写入 `uncertainty.conflicting_evidence`，不在正文偏选其一
- [ ] A5 字体要求优先使用 `environment/resources.yaml` 提供的字体（本题为 Liberation Serif）；缺字体时降级并写入 `degradations`

## B. 排得对：层级、编号、图表与参考文献

- [ ] B1 标题层级与模板层级一一映射，编号规则、样式绑定（而非只改字号/加粗）与目录/书签同步
- [ ] B2 图题/表题位置（上方/下方）、字号、编号格式与正文交叉引用一致
- [ ] B3 三线表规则逐表核对（顶线/栏目线/底线；不滥用竖线）
- [ ] B4 参考文献字段顺序、作者截断规则（et al./等）、标点、中英文混排与目标样式一致
- [ ] B5 页眉页脚、页码样式与模板一致；目录条目与标题文本逐字一致

## C. 转得全：内容单元完整性

- [ ] C1 清点并保留：正文、图表、公式、脚注、批注、修订痕迹、域代码、分节符、嵌入对象、目录
- [ ] C2 每个内容单元在 `fact_source_map` 中有一条记录（`claim_id` 稳定、`quote` 逐字、`locator` 可定位）
- [ ] C3 转换后逐项比对：无删除、无合并、无改写、无“图片化”代替可编辑文本
- [ ] C4 数字、单位、显著性、区间端点逐字一致；术语拼写不因转码改变
- [ ] C5 引用条目不新增材料外事实，二手转引与版本差异已标注

## D. 交得出：导出与可复核

- [ ] D1 导出文件可正常打开；`main.py verify` 退出码 0（或仅警告且已记录）
- [ ] D2 字体已嵌入（Liberation Serif）；页面尺寸/页边距实测值与规格一致
- [ ] D3 页码与目录已刷新且可用
- [ ] D4 可编辑源文件（md/tex/docx）与渲染预览（pdf/png）同时产出，路径回填 `deliverable.artifact_paths`
- [ ] D5 他人可按 `fact_source_map` 从输入件独立复现“输入 → 成品”全过程并核对每一项

## E. 证据强度与不确定性口径

| 证据类型 | 可主张的表述 | 禁用表述 |
|-|-|-|
| 模板逐字规格 | 模板规定…… | 未引用时写“应使用……” |
| 稿件中报告的值 | 稿件报告…… / 原文为…… | 直接当作领域共识 |
| 单篇小样本 | 该研究样本为 n=……，仅表明…… | 证明 / 证实因果 |
| 摘要可得、正文不可得 | 摘要表明…… | 补写正文细节 |
| 来源无法核验 | verification="unverified"，pending_human | 当作已核验引用 |

规则：相关≠因果；单篇小样本≠领域共识；冲突证据必须并列不隐藏。

## F. 规格字段词表（认得准的抽取与归一化字段）

抽取模板规格时逐项归一化到下列字段，写入 `deliverable.format_spec_applied`；每项同时给 `locator` + `quote`。凡模板未明示的字段标 `not_specified`，禁止凭经验补默认值。

| 字段 | 说明 | 常见取值示例（须以模板为准） |
|-|-|-|
| `columns` | 栏数 | 1 / 2 |
| `font_family` | 字体族 | Liberation Serif / Times New Roman / 宋体 |
| `body_font_size` | 正文字号 | 10.5pt / 12pt / 小四 |
| `line_spacing` | 行距 | 单倍 / 1.5 倍 / 20pt 固定值 |
| `margins` | 页边距（上下左右） | 2.54cm / 3.0cm / 25mm |
| `page_size` | 页面尺寸 | A4 / Letter |
| `heading_levels` | 标题层级与编号规则 | 章 / 节 / 条；1 / 1.1 / 1.1.1 |
| `caption_position` | 图题/表题位置 | 图下 / 表上 |
| `caption_font_size` | 题注字号 | 9pt / 五号 |
| `ref_style` | 参考文献样式 | GB/T 7714 / APA / 作者-年份 |
| `export_format` | 交付导出格式 | docx / pdf / tex |

## G. 参考文献样式对照（需核对的字段级差异）

不同样式在字段级即可区分；适配时按字段核对而非整体“看起来像”。以下为常见差异，实际以模板/学校规定逐字为准。

| 维度 | GB/T 7714 | APA | 作者-年份（变体） |
|-|-|-|-|
| 作者截断 | 3 人后“等” | 3–20 人列全后省略 | 视模板而定 |
| 年份位置 | 作者后括号内 | 作者后括号内 | 作者后括号内 |
| 标题大小写 | 句首大写（中文不变） | 句首大写 | 视模板 |
| 刊名/卷期 | 刊名, 年, 卷(期): 页码 | 刊名, 卷(期), 页码 | 视模板 |
| 分隔符 | 半角逗号/冒号混合 | 半角逗号/句点 | 视模板 |
| 中英文混排 | 中文用全角、英文用半角，数字与单位间留空格 | 全半角视语种 | 视模板 |

未核对的字段不得声称“已按要求格式化”；只能写“字段级已核对”并给出逐条 `fact_source_map` 记录。
