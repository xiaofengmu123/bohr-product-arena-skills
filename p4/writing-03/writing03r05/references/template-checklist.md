# 模板规格检查项清单与 locator 约定

本文件定义"认得准、排得对、转得全、交得出"四类检查项，以及事实/引文/改动的定位规范。所有规格必须来自模板或格式约束原文，未给出者写 `pending_human`。

## 1. 模板规格检查项（format_spec）

| 检查项 | 字段 | 要求 |
|---|---|---|
| 栏数 | `columns` | 单栏/双栏，来自模板或投稿要求原文 |
| 字号 | `font_size` | 正文/标题/题注字号，逐级记录 |
| 行距 | `line_spacing` | 1.5 倍/2 倍/固定值 |
| 页边距 | `margin` | 上下左右实测值 |
| 标题层级 | `heading_levels` | 允许的层级深度，如 `[1,2,3]` |
| 图注位置 | `figure_caption_position` | 图下/图上 |
| 表注位置 | `table_caption_position` | 表上/表下 |
| 参考文献样式 | `reference_style` | 顺序编号/著者-年，字段顺序、作者截断、标点与中英文混排 |
| 导出格式 | `export_format` | docx/tex/pdf，字体嵌入与页码目录要求 |

每项填 `source_locator`（来自哪个模板/约束的哪一处）。规格冲突时并列双方，不擅自取一。

## 2. 排得对（逐项落地）

- 标题层级：编号规则、样式绑定、目录与书签生成，避免只改字号加粗导致层级错位。
- 图/表：三线表、题注位置与字号、编号与正文交叉引用一致。
- 参考文献：条目字段顺序、作者截断、标点、中英文混排逐条核对。

## 3. 转得全（内容单元完整性）

正文、图表、公式、脚注、批注、修订、域代码、分节符、嵌入对象、目录：每一项都要确认未丢失、未合并、未改写、未图片化。缺失项写入 `version_boundary.material_gaps`。

## 4. 交得出（导出可用性）

导出文件可打开；字体嵌入；页码与目录可刷新；可编辑源文件保留；他人可按记录复核每一项。

## 5. locator 约定

| 对象 | locator 示例 |
|---|---|
| 原文段落 | `para.3`（与 `show` 输出一致） |
| 表格/数据 | `table.csv:row.4`、`T1:r3c2` |
| 图/图注 | `fig1`、`p3#caption1` |
| 稿件章节 | `sec:3.2`、`heading#Results` |
| 模板/版式 | `template:master`、`layout:Title` |
| 运行/日志 | 文件名 + 行号 |

每个事实、论断、改动都要能按 `source_id + locator + quote` 回到原文或模板的具体位置。

## 6. 证据强度与表述

- `strong`：原始研究直接测量，样本/条件齐全，可直接断言。
- `moderate`：单篇、小样本、或需要推论的表述。
- `weak`：仅摘要、作者观点、或间接证据。
- 相关≠因果；单篇小样本≠领域共识；冲突证据不隐藏。

## 7. 格式适配逐项核对（排得对的最小闭环）

### 7.1 标题层级与编号

- 检查项：章节层级深度、编号规则（`1`/`1.1`/`1.1.1`）、样式绑定（Heading 1/2/3 而非手改字号加粗）。
- 失败特征：只改字号加粗未绑样式 → 目录/书签错位、导航窗格层级错误。
- 处置：目录刷新、书签重建、交叉引用更新后逐条记录 locator。

### 7.2 图表与交叉引用

- 检查项：三线表（顶线/栏目线/底线）、图注在图下/表注在表上、题注字号、编号与正文交叉引用一致。
- 失败特征：编号跳跃、正文引用"见图 X"与题注编号不一致、题注位置相反。
- 处置：`figure_caption_position`/`table_caption_position` 逐项记录，冲突双方并列。

### 7.3 参考文献样式

- 检查项：条目字段顺序（作者/年/题名/刊名/卷期/页码）、作者截断规则（`et al.`/`等`）、标点、中英文混排。
- 失败特征：字段错位、作者名截断不一致、中英文标点混用、编号与正文引用不一致。
- 处置：逐条核对后写入 `fact_source_map`，编号改动写入 `change_log`。

### 7.4 转换完整性

- 检查项：公式、脚注、批注、修订、域代码、分节符、嵌入对象、目录逐一确认未丢失/未合并/未改写/未图片化。
- 失败特征：公式转成图片、脚注丢失、批注被合并进正文、域代码失效、分节符缺失导致页眉页脚错乱。
- 处置：缺失项写入 `version_boundary.material_gaps`，无法判定写入 `pending_human`。

### 7.5 导出可用性

- 检查项：导出格式、字体嵌入、页面尺寸与页边距实测、页码与目录刷新、文件可打开。
- 失败特征：字体未嵌入、目录页码未更新、PDF 不可检索（内容被图片化）、可编辑源文件缺失。
- 处置：真实导出件落 `/app/output`，渲染预览（pdf/png）供复核；依赖不可用时如实标 `degradations`。

## 8. 模板版本差异与冲突

- 同一模板存在多版本或多份补充规定时，提取所有可核对规格并标注各自来源。
- 冲突规定写入 `uncertainty.conflicting_evidence`，正文用"存在冲突/待确认"，不擅自取一。
- 版本不明写入 `pending_human`，并在 `version_boundary.exceptions` 记录依据。
