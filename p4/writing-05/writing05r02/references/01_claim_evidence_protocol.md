# 论断—证据协议（claim–evidence protocol）

本文件是 evidence-driven writing Skill 的判定口径，供 Agent 在 P1/P2 阶段执行、评审者复核。所有层级均为**规则口径**，不产生科学事实；事实只来自实际读到的材料。

## 1. 论断单元（claim unit）

论断 = 一个可独立判定真假的实质性陈述。拆分规则：

- 一句只承载一个主张；含"和/并且/但是"且连接两个独立判断时拆开。
- 数字、比例、效应量、方向性判断、机制判断、适用人群、比较对象各成一条，不与前提混写。
- 模糊铺垫句（"近年来受到关注""需要进一步研究"）不列为论断，除非它承载了需要来源的事实。
- 一条论断可对应多条来源；一条来源可支撑多条论断（多对多）。

`claim_id` 顺序编号 `C1, C2, ...`；每条含 `text`（正文原文句）、`kind`、`strength`、`uncertainty`。

`kind` 取值：

| kind | 含义 |
|---|---|
| `fact` | 可被单一来源直接证实的数值/事实 |
| `interpretation` | 对结果的解释、机制推断 |
| `comparison` | 组间/跨研究比较 |
| `citation` | 文献存在性与著录信息声明 |
| `method` | 方法学声明 |

## 2. locator 规范（可回查）

统一格式（`is_valid_locator` 可校验）：

- `S{section}.P{para}.s{sentence}`：有章节/段落/句三层时首选。
- `P{para}.s{sentence}`：无章节信息时。
- `P{para}`：段落级。
- `page:{n}`：仅能定位到页时（来自 pdftotext 的换页符 `\f`）。
- `char[start:end]`：文本流字符区间（无段落结构时）。

每个 locator 必须配合 `source_doc`（材料文件名）与**逐字 `quote`**（原文摘录，不允许改写、不允许省略关键词）。评审者用 source_doc + locator + quote 三者即可独立复核。

## 3. 证据强度分级（strength）

| 级别 | 口径 | 典型研究设计 |
|---|---|---|
| `S1` | 汇总/综合估计或权威指南 | 系统综述、Meta 分析、临床指南、汇总重分析 |
| `S2` | 强原始证据 | RCT、大样本前瞻队列、多中心、充分检验效能 |
| `S3` | 中等观察证据 | 病例对照、横断面、单中心队列、中等样本 |
| `S4` | 弱/间接证据 | 病例报告/系列、专家意见、letter、会议摘要、预印本、二手转引 |
| `UNK` | 材料不足以判定 | 无研究设计信息、仅摘要、来源不明 |

分级只依据材料中**实际出现**的研究设计、样本量、重复验证、共识程度。材料没写"样本量/设计"时写 `UNK` 并把该缺口写入 `limitations`，不得从领域常识补造。

## 4. 支持判定（support）

证据对论断的支持方向：

| 值 | 含义 |
|---|---|
| `supports` | 原文直接支持该论断（表述与强度相当） |
| `partial_supports` | 支持但范围/人群/方向弱于或窄于论断 |
| `contradicts` | 原文与论断冲突或相反 |
| `insufficient` | 引用存在但不足以支撑该强度 |
| `not_found` | 未在材料中找到该引用/该句 |

当一句论断比来源"更强"（如把相关写成因果、把单篇写成共识、把小样本写成普适），support 记为 `partial_supports` 或 `insufficient`，并在 `reason` 说明差距，正文表述收窄到证据等级。

## 5. 不确定性标记（写得准）

| 标记 | 触发条件 | 正文处理 |
|---|---|---|
| `none` | 无特定不确定 | 按强度直接表述 |
| `correlation_as_causal` | 观察性证据却用因果措辞 | 改为"相关/关联"，加"机制未明" |
| `small_sample` | 单中心/小样本/代表性不足 | 加"样本量有限""单中心"限定 |
| `conflict` | 多来源方向相反 | 同时呈现冲突证据，不隐藏 |
| `indirect` | 二手转引/综述转述原始研究 | 标注"转引自"，能查原始文献则回查 |
| `not_reported` | 材料未报告 | 写"未报告"，不补造 |
| `version_uncertain` | 预印本/版本差异 | 标注预印本状态，注明可再核验 |
| `retracted_risk` | 已知撤稿/更正风险 | 暂停引用，写入 `pending_human` |

## 6. 冲突与可回溯规则

- 同一指标两个来源不一致：两条都写入 `sources`，`support` 分别为各自方向，并在 `uncertainty` 记录 `conflict`；不擅自调和。
- 数字/术语/引用/图表/关键论断无法指回材料原文：不写入 `deliverable` 的结论性正文；确需保留写入 `uncertainty` 并标 `not_reported` 或 `pending_human`。
- 不得新增材料外事实、不得虚构 DOI/引用/数值；缺失就写 `pending_human` / `not_reported`。

## 7. 端到端示例（示例，非正式案例）

材料（示例）：`material.txt` 含一句——"该中心 2019–2023 年 214 例患者的回顾性分析显示，早期手术与更好的 5 年生存相关（P=0.03）。"

按协议处理：

1. **论断切分（找得到）**：拆为 `C1`「214 例患者的回顾性分析」、`C2`「早期手术与更好的 5 年生存相关」、`C3`「P=0.03」。三者 kind 分别为 `method` / `interpretation` / `fact`。
2. **证据匹配（对得上）**：`C2` 的 `source_doc=material.txt`、`locator=P1.s1`、`quote=早期手术与更好的 5 年生存相关（P=0.03）`。
3. **强度分级（说得准）**：来源为"单中心回顾性分析、214 例"，属 `S3`（中等观察证据）；`support=supports`。
4. **不确定性控制（说得准）**：原文用"相关"而非"导致"，故 `uncertainty=correlation_as_causal`；正文只写"相关"，不写"改善/导致"，并加"单中心回顾性，样本量有限"。
5. **可复现（复得现）**：`C2` 的 `claim_id + source_doc + locator + quote + support + reason` 六项齐备，他人可独立回查。

对照"弱证据写成强结论"的反例：若成稿写"早期手术改善生存"，则该句比来源更强，`support` 应记 `partial_supports`，并在 `reason` 说明"来源为观察性相关，不可作因果表述"。
