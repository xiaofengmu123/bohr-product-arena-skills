# 自检清单（02_selfcheck.md）

提交/交付前逐条勾选；与评分维度一一对应。脚本自检运行 `python scripts/selftest.py`，此处清单由 Agent 在每次运行后人工复核。

## A. 实际效果（40 分）

- [ ] 三段交付齐备：论断清单、证据表、成稿全部落盘，且成稿为可编辑 `.md`。
- [ ] 每条实质论断都被切分并编号（`C001…`），无遗漏真实论断。
- [ ] 每条论断至少有 1 条证据，且 `quote` 与原文逐字一致、`locator` 可指回原文。
- [ ] 引用真实存在、元数据准确、原文确实支持该论断（无"更弱/更强错配"）。
- [ ] 证据强度（L1–L4/U）、支撑程度（fully…none）、不确定性、结论（verdict）四要素齐备。
- [ ] 每条论断可独立复核：`claim_id + quote + locator + strength_reason` 齐全。

## B. 使用增益（25 分）

- [ ] 同任务下比"通用建议"更具体：给出的是逐条编辑动作（收窄/加限定/并列冲突/删除无据句）。
- [ ] 一次给全论断清单 + 证据表 + 成稿，减少回原文核对、补引用、改写过度推断段的人工返工。
- [ ] 同稿同版本同口径记录在 `sources` 与 `change_log`，可支撑增益对照。

## C. 创新增益（15 分）

- [ ] 含论断切分、论断—来源关联、证据强度分级、不确定性控制至少一项结构级产物。
- [ ] 脚本 + 证据方法规范 + locator 规范可独立复用，不绑定具体案例。
- [ ] 创新点相对"只写一份成稿"的边界写明（SKILL.md 第 1、7 节）。

## D. 可靠体验（10 分）

- [ ] 缺材料 / 仅摘要 / 原文与摘要矛盾 / 证据冲突 / 格式不支持 / 权限不足均识别并写入 `limitations`。
- [ ] 重复运行不覆盖已改进结果；同输入两次产物一致（`--fixed-time` 下字节级一致）。
- [ ] 空输入、坏 JSON、坏编码、缺软件均降级为合法 partial/failed，不崩溃、不编造。

## E. 生态贡献（10 分）

- [ ] SKILL.md、scripts、references 齐备；依赖（仅标准库）、路径、限制、最小示例写清。
- [ ] 最小示例标注为示例，不冒充正式案例结果。
- [ ] 失败类型、核验方法、强度分级口径沉淀为可分享文档。

## 运行后验证

python scripts/main.py validate --result /app/output/result.json   # 退出码 0
python scripts/selftest.py                                          # 退出码 0
