# 证据强度分级、论断切分与来源匹配（evidence_strength）

本规范把"说得准"落成可复用的判定规则。所有规则只做机械分类，不代替通读原文。

## 1. 证据强度四级（A–D）
按"研究设计 > 样本量 > 重复验证 > 共识程度"依次判定，取最低档（木桶原理）。

| 级 | 含义 | 典型证据 | 正文允许的力度 |
|-|-|-|-|
| A 强 | 系统综合、多来源一致或指南背书 | 系统综述 / Meta 分析、临床指南、多个一致的高质量 RCT 或大样本前瞻队列 | 可用"表明 / 证实 / 确立"，可作一般性结论 |
| B 中 | 设计良好但来源单一或未综合 | 单个 RCT、前瞻性队列、样本充分且方法规范的观察性研究 | 可用"显示 / 表明 / 发现"，需限定人群与条件 |
| C 弱 | 证据本身弱或单点 | 横断面、回顾性、小样本、病例系列、专家意见、单篇未经重复 | 只能"提示 / 初步表明 / 与…相关"，不得写共识或因果 |
| D 极弱 / 不可用 | 无法作为实质依据 | 预印本、仅摘要、二手转引、撤稿、版本不明、无法核对原文 | 只能"有待验证 / 个案提示"，并标 `pending_human` |

判定顺序：
1. 先看来源类型：`original_research`（原始研究）/ `review`（综述）/ `guideline`（指南）/ `preprint`（预印本）/ `abstract_only`（仅摘要）/ `secondary`（二手转引）。
2. 再看研究设计：RCT > 队列 > 病例对照 > 横断面 > 病例系列 / 个案 > 意见。
3. 再看样本量、效应量、置信区间是否支持原论断的范围（人群、时间、剂量）。
4. 最后看是否被多篇独立重复、是否有系统综合、是否与领域共识一致。

冲突证据必须并列记录，不得隐藏：两条证据给同一 `claim_id`，其中一条标 `support_scope=conflict`。

## 2. 支撑范围（support_scope）六类
| scope | 含义 | 处置 |
|-|-|-|
| full | 原文直接、完整支持该论断 | 保留，`verdict=accept` |
| partial | 支持范围更窄 / 更宽或仅部分成立 | 收窄表述或拆分论断，`verdict=revise` |
| weaker | 原文表述比论断更弱（过度推断） | 降级动词 / 加限定语，`verdict=revise` |
| stronger | 原文表述比论断更强（引文不足） | 换更强来源或降论断强度，`verdict=revise` |
| conflict | 与另一来源矛盾 | 两方都记录，`uncertainty` 说明，`verdict=verify` |
| absent | 未找到原文支撑 | 删除该论断或标 `pending_human`，不得保留为有据论断 |

## 3. 论断切分规则
- 一个论断 = 一个可判定命题，含单一主语与单一谓语；"A 降低 X，并通过 Y 机制"拆成两条（`C1`、`C2`）。
- 复句、让步句、条件句拆开；"虽然…但…"的转折前后各成一条。
- 方法句、背景句若只是交代而不主张，则不列为实质论断；带数字、比较、因果、范围、结论的句子必须列为论断。
- 每条论断给 `location_in_manuscript`（成品中的位置）与 `evidence_refs`（来源 id 列表）。
- 多来源支撑一条论断：多篇来源分别记为多条 source，`claim_id` 指向同一论断，取最高强度但需标注是否一致。

## 4. 论断—动词对应（不确定性控制）
| 强度 | 允许 | 禁止 |
|-|-|-|
| A | 表明、证实、确立、显示 | — |
| B | 显示、表明、发现 | 证实、确立 |
| C | 提示、初步表明、与…相关、可能 | 表明、证明、导致、证实 |
| D | 有待验证、个案提示、尚不清楚 | 任何肯定性结论 |

铁律：相关性不得写成因果（"相关 / 关联"≠"导致 / 引起"）；单篇小样本不得写成领域共识（"本研究表明"≠"多项研究证实"）；把"机制未明"写出来，不脑补机制。

## 5. 引用真实性核验
- 引用必须来自本案例实际提供的材料；不得凭记忆补 DOI、页码、作者、期刊。
- 二手转引：标注 `source_type=secondary`，给原出处与转引处，`strength=D`，不冒充一手。
- 版本差异 / 撤稿：检测到撤稿或版本冲突时写 `uncertainty`，该引用不得用于实质论断。
- 编号与参考文献表一致性：正文引用编号与文末表一一对应；不一致记 `change_log` 并修复或标注。

## 6. 切分与分级示例（示例，非正式案例）
原始底稿句：
> 既往研究显示，干预 A 可降低心血管事件风险 32%（P<0.01），其机制可能与抑制炎症相关。

按规则拆为两条可判定论断，各配来源与强度：

| id | claim（拆后） | evidence_refs | 来源设计 | strength | support_scope | 动词校正 |
|-|-|-|-|-|-|-|
| C1 | 干预 A 降低心血管事件风险 32%（P<0.01） | S1 | 单个 RCT，样本充分 | B | full | 保留"降低/显示" |
| C2 | 其机制与抑制炎症相关 | S2 | 动物实验 / 机制推测，未在人体证实 | C | weaker | "与…相关"→"可能通过…相关"，禁止"通过…导致" |

要点：同一复合句拆成 C1/C2 后，两条证据强度不同，正文动词随之分开校正；C2 不得借 C1 的 RCT 强度写成确定机制。此例只演示规则，不冒充正式案例结果。
