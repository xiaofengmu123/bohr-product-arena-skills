# 证据强度分级与不确定性表达口径

本文给出"说得准"的统一口径。分级不是机械套关键词：同一来源若终点/样本不同，等级随之调整；分级依据写入证据表 `rationale`。

## 1. 证据强度阶梯（弱 → 强）

| rank | level | 类型 | 正文建议措辞（示例） |
|---|---|---|---|
| 0 | `unknown` | 证据不足/无法判定 | 证据不足，不作结论；`pending_human` |
| 1 | `opinion` | 专家意见、社论、评论 | 仅个别观点认为 / 有专家提出 |
| 1 | `preprint` | 预印本（未同行评议） | 未经同行评议的预印本提示 |
| 2 | `case_report` | 个案报告 | 个案报告显示 |
| 2 | `preclinical` | 体外/动物实验 | 体外/动物实验提示 |
| 3 | `case_series` | 病例系列 | 小样本病例系列提示 |
| 3 | `cross_sectional` | 横断面研究 | 横断面研究显示（相关，非因果） |
| 4 | `cohort` | 队列研究 | 队列研究显示（相关，非因果） |
| 4 | `case_control` | 病例对照研究 | 病例对照研究显示（相关，非因果） |
| 5 | `rct` | 随机对照试验 | 随机对照试验表明（限定终点/人群） |
| 5 | `guideline` | 临床指南/共识 | 指南推荐（注明推荐强度） |
| 6 | `meta` | 系统综述/Meta分析 | 多项研究一致表明（领域共识） |

## 2. 分级判据（至少看四点）

1. **研究设计**：以上表 rank 为基准。
2. **样本与终点**：RCT 但 n=30、替代终点、单中心 → 降一档并在 `rationale` 注明；观察性研究有重复验证且效应一致 → 可标注"多项观察研究一致"但不升为因果。
3. **重复验证与共识程度**：仅当多篇独立、方向一致且可合并时，才用 `meta`/共识措辞；单篇即使是大样本也保留单篇限定。
4. **来源类型**：预印本一律 `preprint`（即使声称 RCT）；二手转引标 `secondary_citation` 并降级到"待核"。

## 3. 措辞强度词表（按证据，不按愿望）

- 强（`rct`/`guideline`/`meta` 且支持）：表明、证实、确立（仅在证据确实支持时）
- 中（观察性/部分支持）：显示、提示、与……相关/关联
- 弱（病例/预印本/意见）：个案提示、有待验证、尚不能排除
- 不确定性：可能、或许、尚不明确、机制未明、样本受限、有待更大样本验证

**反向规则**：不要把 `相关` 写成 `导致`，不要把 `单篇` 写成 `已公认`，不要把 `体外` 写成 `人体有效`。

## 4. 冲突与不确定性标注

- 同一指标两来源不一致：两条都记，标 `source_conflict`，正文按"一方……另一方……"如实呈现，不择一隐藏。
- 原文与摘要矛盾：以全文为准，并在 `uncertainty` 记录"摘要与正文不一致"。
- 结论边界：写明适用人群、样本范围、机制是否未明；越界推广（如动物结果用于人、单中心推广到全人群）单独标 `pending_human`。
- 无法判定时写 `unknown`，宁缺勿造；绝不用"可能成立"冒充"已证实"。

## 5. 判定理由模板（写入 evidence_table.rationale）
