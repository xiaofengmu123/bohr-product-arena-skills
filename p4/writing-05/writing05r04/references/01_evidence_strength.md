# 证据强度分级、支撑范围与不确定性表达（口径）

本文件是 Skill 的判断口径，供 Agent 在 P2 证据定级、P3 表述校准时逐条对照。
任何分级都必须能指回原文 locator + 逐字 quote；材料不足时不强行定级。

## 1. 证据强度分级（S1–S4）

| 级 | 含义 | 典型研究设计 | 正文可用的表述强度 |
|-|-|-|-|
| S1 | 高：多来源一致或高级别证据 | 系统综述/荟萃分析、多个独立大样本研究一致、指南强推荐 | 可用"证实/表明/指南推荐" |
| S2 | 中：单一较高质量证据 | 随机对照试验、大样本前瞻队列、严格病例对照 | 可用"表明/显示/报告"，注明设计 |
| S3 | 低：弱或间接证据 | 小样本、横断面、回顾性、单臂、动物/细胞实验 | 只能用"提示/初步提示/关联"，不得写因果 |
| S4 | 极低/未知 | 个案报告、预印本、专家意见、二手转引、摘要 | 只能用"据报道/有观点认为/尚待验证"，或标注待核实 |

定级依据四要素，缺一即在 `limitations` 记录：**研究设计、样本量、重复验证程度、共识程度**。

## 2. 支撑范围（support_scope）

| 值 | 含义 | 判定要求 |
|-|-|-|
| full | 原文直接、完整支持该论断 | 摘录语句与论断语义一致，无范围放大 |
| partial | 原文部分支持（结论更弱或仅覆盖子集） | 指出缺哪一部分 |
| weak | 原文仅相近，方向或强度不对应 | 必须改写正文，否则删除 |
| conflict | 与其他来源冲突 | 两方都保留并标 source_conflict |
| none | 无来源支撑 | 不得写入 deliverable；确需保留记 pending_human |

## 3. 表述校准（说得准）

- 相关性不写成因果：横断面/观察性结果只能说"相关/关联"，除非 S1/S2 且有因果设计证据。
- 单篇小样本不写成领域共识：S3/S4 证据不出现"公认/已确立/普遍认为"。
- 冲突证据不隐藏：正文提及时同时记录冲突来源，写入 uncertainty。
- 数值必须与原文逐字一致，含单位、区间、样本量；不得四舍五入后不标注。
- 每条实质性论断在成稿中以 [C#] 指回论断清单，[S#] 指回证据表。

## 4. 不确定性（uncertainty）显式化口径

出现下列任一情况，写一条 uncertainty 并关联到对应 claim_id：
机制未明、结论边界不清晰、适用人群外推、结果冲突、样本量不足、p 值/置信区间缺失、
原文与摘要矛盾、版本差异、二手转引。每条含 `issue` 与可选 `resolution`（如何向人工确认）。

## 5. 降级与缺数据不编造（limitations/pending_human）

| 场景 | 处置 | 记录字段 |
|-|-|-|
| 材料缺失/文件不可读 | 只处理已读到的部分，不补造正文 | limitations |
| 仅有摘要/原文不可得 | 明确标"仅摘要"，相关论断降为 S4 或 pending_human | limitations + uncertainty |
| 原文与摘要矛盾 | 两个都记录，标 source_conflict，待人工裁决 | uncertainty + pending_human |
| 证据相互冲突 | 双方并列，不隐藏，不自行裁定哪方对 | uncertainty |
| 格式不支持（PDF 无文本层/扫描件/图表不可读） | 记"该处有公式/图但无法读取"，不猜内容 | limitations |
| 权限不足/文件超限/截断 | 记录缺口与影响范围 | limitations |
| 二手转引/撤稿/版本差异 | 标注核验路径，不当作一手证据定 S1/S2 | uncertainty |
| 数字/术语/引用无法回溯 | 不写入 deliverable；确需保留记 pending_human | pending_human |

铁律：**不新增材料外事实；无据可循的论断要么改写弱化到有据，要么删除，要么明确挂 pending_human，绝不静默保留。**
