# 自检清单与异常处置

对应评分维度：实际效果(40)、使用增益(25)、创新增益(15)、可靠体验(10)、生态贡献(10)。逐条勾选，结论写入 `result.json` 的 `evidence` / `mapping` / `change_log`。

## A. 科学实体（命名正确性）

- [ ] 基因名（斜体、大小写，如 TP53）、蛋白名、物种拉丁名、化合物/药物名与源材料逐字一致。
- [ ] 中文专名无乱码/方框；单位符号（µ、μ、°、×、±、⁻¹、kDa、mg/mL、ng/mL）正确。
- [ ] 缩写首次出现给出全称，图注与正文引用一致。

## B. 空间关系（示意图/机制图/流程图）

- [ ] 实体之间箭头方向、抑制/激活关系、上下游顺序与源材料一致。
- [ ] 多面板对齐、子图编号（a, b, c）与正文引用一致；图层顺序无遮挡。

## C. 数据编码（数值→图元）

- [ ] 每个柱高/点位置/色阶/扇区角度/误差线长度能回溯到源数据的列与行号。
- [ ] 量级与单位（ng/mL vs µg/mL、% 与小数、10³ vs 10⁶）核对无误。
- [ ] 坐标轴刻度、范围、线性/对数刻度选择正确。

## D. 图例与标注

- [ ] 图例系列与数据系列一一对应，无错配、无遗漏。
- [ ] 误差线含义（SD/SEM/CI/n）与显著性标记（如 * p<0.05）有图注说明。
- [ ] 样本量 n、重复数在图注或面板上可见且与源数据一致。
- [ ] 轴标签含单位；标注无遮挡、无超长截断。

## E. 可编辑源文件

- [ ] 分层 SVG（文字为 `<text>`，未转曲）或 PPTX/EPS 可继续编辑。
- [ ] 源文件与导出件一致（同一数据、同一版本）；重跑脚本能复现同一张图。

## F. 导出格式

- [ ] PNG 分辨率≥300 dpi（或按目标要求），颜色模式正确，无意外透明背景。
- [ ] PDF 矢量文字可选中、字体嵌入；尺寸与留白符合目标期刊或模板。

## 证据与映射 schema

`evidence` 每项：`locator`（如 `materials/paper.md#p3` 或 `materials/data.csv#L12`）、`quote`（逐字原文）、`target`（图元 id，如 `bar_treatment_A`）、`value`（编码后的数值）、`conflict`（同指标多来源冲突时填 `source_conflict`）。

`mapping` 两项：`figure->data`（图元 id → locator + value）与 `data->figure`（locator → 图元 id 列表），支持双向回溯。冲突信息不隐藏：两个来源同一指标不一致时两个都记录并标 `source_conflict`。

## 异常处置（对应可靠体验）

| 异常 | 处置 |
|---|---|
| 缺列/空值 | `extract_tables.py` 已报 missing；核对源文件，仍缺→`null` + `uncertainty` |
| 量级异常 | 报 issue，人工核对单位；不确定则保留原值并标注 |
| 标签过长 | 缩写 + 图注全称，或旋转/换行标签 |
| 字体缺失 | font-discovery 查找中文字体；无则英文标签或注明乱码风险 |
| 导出失败 | 换标准库手写 SVG 兜底；PNG/PDF 无法渲染则如实 `partial` |
| 标注遮挡 | 调整面板尺寸/图例位置/留白后重渲 |
| 材料冲突 | 记录 `source_conflict`，不擅自取舍 |

## 导出预设（常用）

- 期刊单栏：宽 89mm；双栏：宽 183mm；高按黄金比例或数据面板自定。
- PNG：dpi=300、facecolor 白底（避免意外透明）；SVG：文字节点、`<svg>` 含 width/height 与 viewBox。
- 演示：PPTX 16:9；图注与面板同页。
- 中文字体：优先 Noto Sans CJK / Source Han Sans；找不到则英文标签并记录 `uncertainty`。
