# 自检清单与异常处置（细化）

本清单对应评分维度：实际效果(40)、使用增益(25)、创新增益(15)、可靠体验(10)、生态贡献(10)。逐条勾选并把结论写入 `result.json` 的 `evidence_map` / `uncertainty` / `change_log`。16 项主清单见 `SKILL.md` 第 6 节，此处给出可操作的判据与证据落点。

## A. 科学实体（命名正确性）
- [ ] 基因名（斜体、大小写，如 TP53）、蛋白名、物种拉丁名、化合物/药物名与源材料逐字一致。
- [ ] 中文专名无乱码/方框；单位符号（µ、μ、°、×、±、⁻¹、kDa、mg/mL、ng/mL）正确。
- [ ] 缩写首次出现给出全称；图注与正文引用一致。
- 证据落点：`evidence_map` 逐字 `quote`；实体名以 `locator`（如 `materials/paper.md#p3`）定位。

## B. 空间关系（示意图/机制图/流程图）
- [ ] 实体间箭头方向、抑制/激活关系、上下游顺序与源材料一致。
- [ ] 多面板对齐、子图编号（a, b, c）与正文引用一致；图层顺序无遮挡。
- 证据落点：SVG 用 `<g id="...">` 分层；关系写 `edge(source,target,type)` 到工作笔记。

## C. 数据编码（数值→图元）
- [ ] 每个柱高/点位置/色阶/扇区角度/误差线长度可回溯到源数据的列与行号（SVG 的 `data-*` 属性）。
- [ ] 量级与单位（ng/mL vs µg/mL、% 与小数、10³ vs 10⁶）核对无误。
- [ ] 坐标轴刻度、范围、线性/对数刻度选择正确。
- 证据落点：`evidence_map` 每条 `claim` + `quote`（如 `min=… max=… mean=…`）。

## D. 图例与标注
- [ ] 图例系列与数据系列一一对应，无错配、无遗漏。
- [ ] 误差线含义（SD/SEM/CI/n）与显著性标记（如 * p<0.05）有图注说明。
- [ ] 样本量 n、重复数在图注或面板上可见且与源数据一致。
- [ ] 轴标签含单位；标注无遮挡、无超长截断。

## E. 可编辑源文件
- [ ] 分层 SVG（文字为 `<text>`，未转曲）或 PPTX/EPS 可继续编辑。
- [ ] 源文件与导出件一致（同一数据、同一版本）；重跑脚本能复现同一张图。

## F. 导出格式
- [ ] PNG 分辨率≥300 dpi（或按目标要求），颜色模式正确，无意外透明背景。
- [ ] PDF 矢量文字可选中、字体嵌入；尺寸与留白符合目标期刊或模板。

## 异常处置（对应可靠体验）

| 异常 | 处置 | 结果字段 |
|---|---|---|
| 缺列/空值 | `extract` 已报 missing；核对源文件，仍缺→`null` + `uncertainty` | `uncertainty`/`limitations` |
| 量级异常 | 报 issue，人工核对单位；不确定则保留原值并标注 | `uncertainty` |
| 标签过长 | 缩写 + 图注全称，或旋转/换行标签 | `change_log` |
| 字体缺失 | font-discovery 查找中文字体；无则英文标签或注明乱码风险 | `uncertainty` |
| 导出失败 | 换 `render_svg.py` 手写 SVG 兜底；PNG/PDF 无法渲染则如实 `partial` | `degradations` |
| 标注遮挡 | 调整面板尺寸/图例位置/留白后重渲 | `change_log` |

## 最小可复核结果（降级时仍须满足）
1. `/app/output/result.json` 存在且含 `case_id`、`status`、`sources`、`uncertainty`、`change_log`。
2. 每个 contract 字段要么有产物/对象，要么 `null` 且注明原因。
3. 至少一个可编辑 SVG（或手写 SVG 骨架）+ 一份来源与修改说明。
