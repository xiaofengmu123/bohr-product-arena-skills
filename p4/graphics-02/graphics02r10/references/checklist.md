# 自检清单与异常处置

本清单对应六类检查点（科学实体、空间关系、数据编码、图例标注、可编辑源文件、导出格式）。逐条勾选，并把结论写入 `result.json` 的 `annotation_checks` 或 `change_log`。

## A. 科学实体
- [ ] 基因（斜体/大小写，如 TP53）、蛋白、物种拉丁名、化合物名与源材料逐字一致。
- [ ] 中文专名无乱码/方框；单位符号（µ、μ、°、×、±、⁻¹、kDa、mg/mL、ng/mL）正确。
- [ ] 缩写首次出现给全称；图注与正文引用一致。

## B. 空间关系（示意图/机制图/流程图）
- [ ] 箭头方向、抑制/激活、上下游顺序与源材料一致。
- [ ] 多面板对齐、子图编号（a/b/c）与引用一致；图层顺序无遮挡。

## C. 数据编码（数值→图元）
- [ ] 每个柱高/点位置/色阶/扇区角度/误差线长度可回溯到源列与行号（`data_ref`）。
- [ ] 量级与单位（ng/mL vs µg/mL、% 与小数、10³ vs 10⁶）核对无误。
- [ ] 坐标轴范围、线性/对数选择正确；刻度覆盖数据全范围且不误导。

## D. 图例与标注
- [ ] 图例系列与数据系列一一对应，无错配、无遗漏。
- [ ] 误差线含义（SD/SEM/CI/n）与显著性标记（如 * p<0.05）有图注说明。
- [ ] 样本量 n、重复数可见且与源一致。
- [ ] 轴标签含单位；标注无遮挡、无超长截断。

## E. 可编辑源文件
- [ ] 分层 SVG（文字为 `<text>`，未转曲）或 PPTX/EPS 可继续编辑。
- [ ] 源文件与导出件同一数据、同一版本；重跑 `main.py --phase all` 复现同一张图。

## F. 导出格式
- [ ] PNG ≥300 dpi、RGB、无意外透明背景；PDF 矢量文字可选、字体嵌入。
- [ ] 尺寸与留白符合目标期刊/模板。

## 异常处置（可靠体验）

| 异常 | 处置 |
|---|---|
| 缺列/空值 | `extract` 已报 missing；核对源文件，仍缺 → 对应 contract 字段 `null` + `uncertainty` |
| 量级异常 | `extract` 报 magnitude issue；人工核对单位，不确定则保留原值并标注 |
| 标签过长 | 缩写 + 图注全称，或旋转/换行标签 |
| 字体缺失 | `discover_cjk_fonts()` 回退；无中文字体 → 英文标签或注明乱码风险 |
| 导出失败 | 标准库手写 SVG 兜底；PNG/PDF 无法渲染则如实 `partial` |
| 标注遮挡 | 调整面板尺寸/图例位置/留白后重渲 |
| 同一策略两次失败 | 停止重复，换策略或降级为最小可复核结果，不硬造结果 |

## 最小可复核结果（降级时仍须满足）

1. `/app/output/result.json` 存在，含 `case_id`、`status`、`sources`、`uncertainty`、`change_log`。
2. 每个 contract 字段要么有产物/对象，要么 `null` 且注明原因。
3. 至少一个可编辑 SVG（或手写 SVG 骨架）+ 一份来源与修改说明。

## 禁止事项

- 不编造 benchmark 分数、运行结果、源数据、软件状态。
- 不以错误领域标签补造数据；PDF 用真实提取文本，不凭标签臆测内容。
