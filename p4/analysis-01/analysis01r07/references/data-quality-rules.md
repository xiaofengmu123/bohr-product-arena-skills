# 字段级清洗规则参考（data-quality-rules）

本文件给出清洗判断的保守默认规则，作为 SKILL.md 第 5 节的补充依据。**每条规则都必须能指回材料的逐字片段（locator + quote）；当材料无明确依据时，标 `pending_human`，不做静默处理。**

## 1. 缺失值四分类（不互相覆盖）

| 类别 | 判定依据 | 处置 |
|---|---|---|
| 未检测 / not detected | `nd`、`n.d.`、`not detected`、`未检测`、`未检出` 等 | 保留原文，标记 `not_detected`，**非缺失、非 0** |
| 低于检出限 / below LOD | `<0.01`、`<LOD`、`BLQ`、`低于检出限` 等左删失标记 | 保留原文，标记 `below_lod`，**非缺失、非 0** |
| 录入缺失 | 空、`NA`、`N/A`、`-`、`--`、`-999`/`-9999` 等哨兵 | 置空并标记 `missing`，保留原始快照，**不插补** |
| 真值 0 | `0`、`0.0`、`0e0` | 保留，标记 `zero`，**不得误归入缺失** |

注意：哨兵仅把**整数 ≤ -999** 判为录入缺失；`-999.5` 等非常规哨兵保留原文并标 `uncertainty`。`0` 与 `-999` 必须可区分。

## 2. 异常值（用物理上下界，不用均值的 n 倍标准差）

- 上下界优先取自数据字典与单位/QC 规则；无明确界值则参考该指标公认生理/物理范围并写明来源。
- 判定为异常后给三种动作之一：**保留**（真实高值，如样本真实超限）、**剔除**（加样失误、录入错误，需逐字证据）、**截帽**（据规则替换为界值，需写明界值与依据）。
- 默认只标记、不删除；删除必须由 Agent 确认并写入 `change_log`。
- 分布诊断（箱线图、四分位距）只用于**提示**，不替代物理界值做删除决策。

## 3. 重复记录（按真实主键）

- 主键候选：样品编号、时间戳、受试者标识、记录编号；以工单/字典明确声明者为准。
- 近似重复：大小写、空白、单位写法不一致（如 `A01` 与 `a01`），键先做 `casefold + 去空白` 归一化再分组。
- 每个重复组明确**保留哪一条及依据**（如信息最完整、最新时间戳、规则指定），其余标记不静默删除。
- 主键冲突（多列候选、键缺失）标 `uncertainty`/`pending_human`，不得猜主键。

## 4. 格式与单位转换（可逆或留映射表）

- 编码先于解析：`utf-8-sig → gb18030 → latin-1` 无损兜底；NUL 字节判二进制。
- 科学计数法、千分位、有效数字**不静默截断**；日期时区保留原字符串并在映射表记时区假设。
- 单位换算只做因子明确的换算（如 `mg/L = μg/mL`），保留换算因子与映射表；需摩尔质量等额外信息的换算标 `pending_human`。
- 任何转换记录“原值 → 新值 → 因子/规则 → locator”，保证可逆核对。

## 5. 质量报告一致性

- 报告为**字段级清单**：缺失率、四类计数、异常条数、重复组、转换记录、处理动作与影响范围。
- 报告数字必须由 `cleaned_data.csv` 程序实时重算，禁止手写；逐字段可对账。
- 报告与结果表不一致时，以结果表为准并在 `uncertainty` 记录差异原因。
