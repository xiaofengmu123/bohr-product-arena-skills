# 清洗决策规则（references/rules.md）

本文件是 SKILL.md 第 5 节的展开：把五类处理（缺失值、异常值、重复记录、格式/单位、质量报告）落实为逐字段可执行的决策表与证据要求。脚本 `core_impl.py` 只执行其中**可确定性自动化**的部分；需要裁决的部分必须由 Agent 判断并写进 `change_log` 与 `evidence_map`。

## 1. 缺失值：四类分类，禁止互相覆盖

| 类别 | 判定信号 | 处理动作 | 禁止事项 |
|---|---|---|---|
| `未检测 / not detected` | 文本 `ND`、`not detected`、`未检出` 等明确表述 | 保留原文，单列报告，不并入数值 | 不得当作 0 或缺失 |
| `低于检出限 / below LOD` | `<0.01`、`<LOD`、`BLQ`、`低于检出限` 等左删失标记 | 保留原文并标记左删失；可用区间 `[0, 阈值)` 表示，但**不得**当作 0 | 不得与"未检测"混为一谈 |
| `录入缺失` | 空串、`NA`、`-999`、`.`、哨兵值 | 保留原文；默认不插补，确需标记时写 change_log | 不得用列均值/中位数/众数填补 |
| `真值 0` | `0`、`0.0`、`0e0`（解析后恰为 0） | 作为数值 0 保留，与缺失分开 | 不得把 0 改写成缺失或反之 |

- 判定顺序：先看是否命中哨兵/空（`entry_missing`），再看左删失标记（`below_lod`），最后尝试数值解析（`true_zero` / `value`），其余为 `text`。
- 任何分类都保留 `locator`（如 `data.csv#r12c3`）+ 原文 `quote`；冲突或歧义并列记录并标 `source_conflict`。

## 2. 异常值：物理上下界优先，不做武断截尾

- 判断依据**只用**数据字典与单位/QC 规则给出的物理上下界（如正常范围、质控限），不用"均值±n 倍标准差"删除真实高值。
- 处理动作三选一，均需写理由与 locator：
  - **保留**：字典/规则未说明越界即错，或越界值属合理极端（标注 `uncertainty`）；
  - **剔除**：字典/规则明确该值物理不可能（如负数浓度、浓度 > 物理上限）；
  - **截帽**：仅在字典/规则明确要求 Winsorize/截帽时执行，并记录截帽值与原因。
- 脚本只给出"候选异常"（对照 `rules_resolved.json` 的 `qc_min/qc_max`），是否处置由 Agent 定。

## 3. 重复记录：真实主键 + 近似重复

- 主键候选：样本编号、时间戳、受试者标识、记录号等（脚本按列名提示词初筛，Agent 确认）。
- **精确重复**：主键完全相等 → 归组，保留依据（字典给出的录入顺序/最完整记录/最新时间戳）。
- **近似重复**：大小写、空格、前后缀不一致但规范化主键相等 → 单独报告为 fuzzy 组，不静默合并；单位写法不一致（mg/L vs μg/mL）**不**视为同一键，需先做单位归一后再判断。
- 保留策略必须成文：保留哪一条、为什么；被合并的行不删除，仅在报告中标注 `dedup_keep`/`dedup_drop` 与来源行号。

## 4. 格式与单位：可逆或留映射，不丢精度

- **编码**：读取顺序 UTF-8-SIG → GB18030 → Latin-1；若因编码退化产生替换符 `\ufffd`，在 `degradations` 记录，不静默修复。
- **数值格式**：科学计数法、千分位（`1,234`）、括号负数 `(3.2)`、逗号小数（`1,5`）分别解析并记录方法；逗号小数记 `ambiguous`。
- **有效数字**：脚本只存 float 或原文字符串，不截断；展示层四舍五入必须注明有效位数规则。
- **单位换算**：保留 `单位映射表 + 换算因子`（见 `rules_resolved.json`/`data_profile.json` 的 `units`）。常见等价：`mg/L = μg/mL`、`mg/L = 1000 ng/mL`、`mg/mL = g/L`。
- **摩尔浓度**（mmol/L、μmol/L 等）换算到质量浓度需摩尔质量，**不猜**，标 `pending_human`。

## 5. 质量报告：数字必须由清洗表实时重算

- 报告含字段级清单：缺失率（按四类分列）、异常条数、重复组数、转换记录、处理动作与影响范围。
- **任何数字不得手写**；由 `cleaned_data.csv` 程序化重算，`selftest.py` 独立复算核对（CSV ↔ data_profile.json ↔ quality_report.md 三者一致）。
- 缺失率分母约定：该字段总条数（含缺失）；低于检出限单列，不并入缺失率。

## 6. 证据溯源规范

- 每个关键结论/数值/图元，写 `locator`（文件路径 + 行/列定位）+ 逐字 `quote` + `note`。
- `locator` 示例：`materials/data.csv#r12c3`、`materials/dictionary.md#p3`。
- 同一指标多来源冲突：两项都记录并标 `source_conflict`，裁决写 `change_log`。
- 不虚构引用、DOI、数值；缺失写 `not_reported` 或 `pending_human`。
