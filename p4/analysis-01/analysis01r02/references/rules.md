# 清洗规则与决策依据（references/rules.md）

本文是 SKILL.md 第 5 节的细化展开，Agent 逐条执行并写入 change_log 与
evidence_map。原则：**原值保留、可逆、可指回材料、不插补、不静默改值。**

## 1. 四类缺失状态（互斥、不覆盖）

对每个单元格按下面顺序判定，标注其一；后三类都**不是缺失**，不得折算：

| 类别 | 含义 | 典型写法 | 处置 |
|-|-|-|-|
| `true_zero` | 真值 0 | `0`、`0.0`、`0.00` | 保留为数值 0，不改写 |
| `below_lod` | 低于检出限（左删失） | `<0.01`、`<LOD`、`BDL`、`低于检出限` | 保留原文并标注，不折算为 0 |
| `not_detected` | 未检测（无峰/未检出） | `ND`、`not detected`、`未检出` | 保留原文并标注，不等于 0 或缺失 |
| `entry_missing` | 录入缺失（哨兵/空） | 空串、`NA`、`-999`、`null` | 保留原文并标注，默认不插补 |

- 判定的词表见 `scripts/core_impl.py` 的 `ENTRY_MISSING` / `NOT_DETECTED` /
  `BELOW_LOD`；**词表是默认建议，不是结论**。数据字典若明确声明某个哨兵
  的含义（例如 `-999 = 未检测`），以字典为准并在 change_log 记录覆盖理由与
  locator。
- `below_lod` 与 `not_detected` 的分界依赖字典/QC 规则；规则未说明时并列记录，
  标 `source_conflict` 或 `pending_human`，不臆断。

## 2. 异常值（物理上下界优先）

1. 上下界只来自数据字典与单位/QC 规则给出的物理范围或检出限；**没有明确边界
   就不判定异常**，尤其不用“均值 ± n 倍标准差”删除真实高值。
2. 超出上下界的值默认**保留原文**，加异常标注列 `_outlier`，并在报告中给
   locator + quote 说明判定依据与保留/剔除/盖帽理由。
3. 若规则明确要求剔除或盖帽，才执行，且保留原始行在 `cleaned_data.csv` 中
   （以 `_outlier` 标记而非删行），使动作可逆、可复核。

## 3. 重复记录（真实主键）

1. 主键只能来自字典/工单（样品编号、时间戳、受试者标识、坐标等）；脚本的
   “全列归一化”分组只是**候选建议**，不得直接当作去重结论。
2. 归一化键：统一大小写、去首尾空格、折叠连续空白；涉及单位写法不一致的
   （`mg/L` vs `μg/mL`）先做**可逆单位对齐**（见第 4 节）再比对。
3. 每个重复组明确保留哪一条及依据（如“保留字段最完整者”“保留最早时间戳”），
   写入 change_log；近似重复单独报告，不静默合并。

## 4. 格式与单位（可逆、留映射）

1. 编码先于解析：`core_impl.read_text_robust` 依次尝试 UTF-8 → GB18030 →
   Latin-1，降级时在 `degradations` 记录。
2. 科学计数法、千分位、有效数字：原字符串始终保留在 cleaned 表中，数值化仅用于
   画像/范围展示，不做静默截断或改写。
3. 单位换算仅在规则给出**明确换算因子**时执行，换算前后值并存并留
   `_unit_map` 映射表；因子可逆（乘/除）才执行。摩尔浓度等需要摩尔质量的换算
   **不猜**，标 `pending_human`。
4. 日期时区、文本混排：只标注类型，不改写；无法判定的一律 `pending_human`。

## 5. 质量报告（数字实时重算）

- 报告中的缺失率、异常条数、重复组、转换记录均由 `cleaned_data.csv` 重算，
  脚本生成，不手写。
- 每次改动清洗表后必须重跑报告；`selftest` 会交叉核对 CSV 行数与
  `data_profile.json` 的 `n_rows` 是否一致。

## 6. 证据溯源（硬要求）

- 每个关键结论/数值/动作 → `locator`（文件 + 行号/段落）+ 逐字 `quote` +
  `note`，写入 `evidence_map.json` 与 `result.json.sources`。
- 冲突信息并列保留，标 `source_conflict`，不藏不选。
- 不虚构引用、DOI、数值；缺失写 `pending_human` 或 `not_reported`。
