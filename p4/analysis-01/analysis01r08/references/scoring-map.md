## 设计取舍（与参考包的差异）

1. **评分维度前置**：把 16 个评分点映射到流程与自检项，让 Agent 每步动作有明确的对分目标，而非泛泛"清洗干净"。
2. **决策台账 + 单元审计双产物**：`rules.json`（字段级决策）与 `cell_audit.csv`（单元级证据）把"每个改动为什么"变成可逐行核对的结构化记录，直接支撑正确性/可核验性/创新证据。
3. **报告数字强制重算**：quality_report.md 与 data_profile.json 的数字来自 cleaned_data.csv 重算，selfcheck 再验一次，消除"报告数字与表对不上"这一高频失分点。
4. **保守默认 + Agent 增量回填**：脚本只做可逆、无插补的确定性操作；语义判断（字典解读、规则冲突裁决、主键判定）由 Agent 写入 rules.json/evidence_map.json，脚本再重跑，保证"人工判断"与"机器复算"可分离复核。
