# 自检清单（对应评分维度）

交付前逐条勾选；`scripts/selftest.py` 只做结构自检，本清单补足科学正确性与诚实标注。

## 实际效果（40）
- [ ] 走通「材料 → 图稿 → 导出」，不是套模板插画
- [ ] 每个实体、关系、方向、层级与来源一致（抑制≠激活、上下游不倒置、包含≠并列）
- [ ] 图中不出现材料中不存在的基因名/浓度/时间点/单位
- [ ] 图例项、配色、标记与数据表分类和数值逐项一致
- [ ] 覆盖实体、关系、图例、标注、单位、子图编号等必要图面元素
- [ ] `provenance` 每条都能定位到来源（locator + 逐字 quote），可独立复核

## 使用增益（25）
- [ ] 数据改动后能重绘（改 spec/数据重跑成图，图例与数据同源）
- [ ] 输出可编辑 SVG（`<g>` 图层、可编辑 `<text>`），改标签不整张重画
- [ ] `change_log` 如实记录人工修改量与返工轮次，不夸大

## 创新增益（15）
- [ ] 文字描述 → 实体—关系清单的抽取方法可说明
- [ ] 数据表驱动图例重绘（legend 与 entities 同源）
- [ ] `finalize.py` 契约校验真实运行（含类型/枚举/必填/未知键回填）

## 可靠体验（10）
- [ ] 按 SKILL.md 步骤可独立完成一次出图
- [ ] 重复运行稳定：同一输入结果一致（固定随机种子、确定性布局、幂等 finalize）
- [ ] 缺数据/缺字体/导出失败时如实标注，不编造

## 生态贡献（10）
- [ ] 说明、依赖、路径、边界与维护信息齐全
- [ ] 契约（contract.md）、配色/图例规范、导出预设可复用
- [ ] 沉淀可分享案例与经验（不预写正式答案、不伪造评测分数）

## 异常处理（降级）
- [ ] 缺 PDF 文本层 → OCR/pdftoppm，并在 `sources` 标注「OCR 识别，需人工复核」
- [ ] 缺字体 → font-discovery 找替代并记录；无法嵌入则 `font_check="none"` + `uncertainty`
- [ ] 渲染/导出失败 → 保留 SVG，`export_files` 记 failed 与原因，`status=partial`
- [ ] 材料缺失/矛盾 → 记入 `uncertainty`/`pending_human`；不确定实体不画或标「推测」
- [ ] 所有 limits 写入 `uncertainty` 与 `change_log`，不冒充 `complete`
