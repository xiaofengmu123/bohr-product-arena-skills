# 写作与证据规则

本文是 SKILL.md 第 5 节的完整展开，Agent 起草与核对正文时逐条遵守。

## 1. 四要素与四段结构

引言与相关工作成稿必须四段齐全且彼此承接：

1. **研究背景**：交代领域脉络、具体问题与技术约束，说明“为什么现在值得做”。禁用“近年来受到广泛关注”“具有重要意义”等无指涉空转；每句背景断言应能指向具体研究脉络或未解决问题。
2. **相关工作**：按**问题设定 / 方法路线 / 数据与评价方式**分组，组内按同一维度比较取舍，不按时间顺序罗列、不逐篇摘要拼接。每篇转述须保留原文结论、适用条件与局限。
3. **研究空白**：由已引工作的**共同限制 / 未覆盖场景 / 相互冲突结论**推出，并写明本文工作与之的对应关系。无法由文献推出的判断必须标注“作者判断”。
4. **贡献**：把方法、实验、结论压缩为可核对的贡献条目；每条贡献须能在正文方法/图表/实验结果中找到对应证据，不夸大适用范围。

## 2. 证据溯源（硬要求）

- 正文每个事实句挂 `[S#]` 标记；`evidence_map.json` 中 `[S#]` → `{locator, quote, kind}`。
- `locator` 形如 `materials/paper.md#p3`（段落定位）或 `case.json#output_contract`（键定位），必须能回到真实文件。
- `quote` 是材料中的**逐字片段**，不得改写；数字、单位、统计量、限定词（如“显著”“约”“在 X 条件下”）逐字复用。
- `kind` 取值建议：`fact`（事实）、`number`（数值）、`claim`（他人论断）、`citation`（引用元数据）、`method`（方法）、`result`（结果）、`author_judgment`（作者判断）。
- 材料没有的数据不补，写 `MATERIAL GAP`；材料有但未报告具体值写 `not_reported`。

## 3. 引用与元数据

- 引用只用材料中真实出现的来源；不造 DOI、作者、年份、页码。
- 元数据缺失 → 写入 `pending_human` 与 `uncertainty`，不臆测补全。
- 目标期刊格式未知 → 缺省采用作者—年份，并在 `uncertainty` 中声明假设，不冒充特定格式。
- 关键工作、代表性工作与近期进展都要覆盖；同一论断与引用一一对应，不做“挂一堆引用却不落在具体论断上”。

## 4. 冲突与版本

- 材料冲突不隐藏：同一指标两个来源不一致时，两条都记入 `sources`，并在 `uncertainty` 标 `source_conflict`，正文选择其中一种口径并说明理由。
- 数值与单位保全清单写入 `preserved_facts.json`（或并入 change_log），记录原值、写入值、是否改动。
- `change_log` 每项 `{at, target, before, after, reason}`，保证可回退到上一版。

## 5. 限定强度

- 用词与证据强度匹配：已有定论用“表明/证实”，初步证据用“初步表明”，前景用“有望”。
- 语言切换（中↔英）时保持术语、数字、引用原位，仅换语言，限定强度不变。
- 转述他人工作用“X 表明/提出/观察到”，与“本文贡献”分清楚，不把他人结论写成本文结论。

## 6. 完成度判定（对应 result.json 的 status）

- 四段齐全 + 证据齐全 + 引用可回溯 → `ok`。
- 有可用成稿但存在缺口（如个别引用待人工确认、个别贡献缺对照）→ `partial`。
- 材料不足以成稿 → `insufficient_evidence`，正文只写可支撑内容，其余标 `MATERIAL GAP`。
- 输入无法解析（如 case.json 坏、材料全不可读）→ `input_error`。

## 7. 分组、空白与贡献模板（可复用）

### 相关工作组卡片（每组一卡，组内按同一维度比较）

- 问题设定：解决什么问题、输入/输出、目标场景。
- 方法路线：核心技术路线（模型/算法/范式）。
- 数据与评价：数据集、基准、评价指标。
- 代表工作：作者—年份、关键结论（逐字转述，保留适用条件与局限）。
- 比较维度：组内用同一维度写成并列句或表格，不按时间罗列。

### 空白推导三段式（说得实）

1. 共同限制：已引工作普遍存在的局限，引用落在具体条目上。
2. 未覆盖场景：已引工作没有覆盖的条件/数据/任务。
3. 冲突结论：不同工作结论不一致处，标 `source_conflict`。
4. 本文如何填补：每条空白对应一条本文工作或贡献。

### 贡献核对表（对得上）

| 贡献条目 | 正文证据（方法/图表/结果） | 适用边界 |
|---|---|---|
| 贡献 1 | 第 X 节方法 / 图 Y / 表 Z | 在…条件下成立 |

每条贡献必须能指到正文具体位置；尚未验证的写“待验证”，不得夸大适用范围。
