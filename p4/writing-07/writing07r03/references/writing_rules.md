# 引言与相关工作写作规则（证据、分组、空白与贡献）

本文档是 SKILL.md 的执行细则，Agent 起草与核对时逐条遵守。核心原则：**每个可复核论断都可回到材料中的逐字片段；材料没有的，只标注缺口，不补写。**

## 1. 四段结构与承接

成稿 `manuscript.md` 必须包含四部分，且顺序与逻辑承接一致：

1. **研究背景**：从领域脉络、具体问题与技术约束入手，交代“为什么现在值得做”。必须指向真实的、具体的未解决问题，禁止“近年来受到广泛关注”“随着人工智能发展”式空转铺垫。背景段末尾落到一个可由后续文献缺口推出的问题陈述。
2. **相关工作**：按问题设定 / 方法路线 / 数据与评价方式分组，组内沿同一比较维度讨论取舍，禁止逐篇按时间摘要拼接。每个工作写清：问题设定、方法、数据、评价维度、结论、适用条件与局限。
3. **研究空白**：由已引工作的共同限制、未覆盖场景或相互冲突的结论**推出**；每条空白写明“本文如何填补”。无法由文献推出的判断，必须标注“作者判断”，不得伪装成文献事实。
4. **贡献**：把方法、实验、结论压缩为可核对条目；每条贡献必须能映射到正文的方法 / 图表 / 结果，不夸大适用范围。贡献条数应≤正文实际可支撑的条数。

## 2. 证据与事实规则

- 每个事实句（含数字、单位、统计量、他人工作结论）后挂 `[S#]` 标记；`evidence_map.json` 提供 `[S#]` → `{locator, quote, kind}` 映射。
- `quote` 必须是材料中的**逐字片段**，不得改写或概括后冒充原文；`locator` 形如 `materials/paper.md#p3`（页面/段落定位）。
- 数字、单位、限定词逐字复用。材料未给出的：写 `not_reported` 或 `MATERIAL GAP`，不补近似值、不换算后冒充实测。
- 材料的结论转述须保留原文结论、适用条件与局限；转述与原文出现偏差即算事实错误。
- 两个来源对同一指标不一致时，两条都记录，并在 `uncertainty` 中加一项 `{item, reason:"source_conflict"}`，不得只保留一方。

## 3. 相关工作分组

- 分组维度从材料本身归纳（问题设定 / 方法路线 / 数据 / 评价方式），并在文稿中用一句“按……分组”交代分组依据。
- 组内比较写“同一维度上的取舍”（例如同方法路线下数据规模或评价指标的不同），不写“A 用了 X，B 用了 Y”式无维度并列。
- 每篇被引工作至少给出：作者、年份、来源（原文可得时）、问题设定、方法、结论、局限。引用元数据缺失时写 `pending_human`，不臆造作者 / 年份 / DOI。

## 4. 引用覆盖与格式

- 只引用材料中真实出现的来源；关键工作、代表性工作与近期进展都要覆盖，避免只引几篇。
- 引用落在具体论断上，不使用段尾一次性堆引用。
- 引用格式：案例指定格式优先；未指定时缺省作者—年份（如“Smith 等，2024”）。格式选择与假设记入 `uncertainty` 或 `change_log`。
- 元数据真实可核对：只写材料中出现的作者 / 年份 / 来源；查不到原文的写 `pending_human`。

## 5. 贡献对齐

- 每条贡献逐条对照正文：能指出支撑它的方法小节、图表编号或结果数据；对不上的条目删除或改写。
- 不把“我们提出”“我们展示”当作可核对的贡献；贡献必须是可验证的声明。
- 适用范围按材料报告的实验对象 / 条件 / 指标限定，不向材料外场景外推。

## 6. 确定性规则（本版重点）

- 脚本写入的所有 JSON 用 `sort_keys=True`、无墙钟时间戳，保证同输入两次运行字节一致。
- `result.json` 的 `runtime` 只写预算常量（`budget_seconds` / `budget_requests` / `tokens_per_response`），**不写** `wall_seconds`、`elapsed_seconds`、`started_at`、`finished_at`、`timestamp`；墙钟时间由平台 trace 记录，不进产物。
- 完成后运行 `scripts/main.py finalize`，把 `result.json`、`evidence_map.json`、`change_log.json`、`preserved_facts.json` 按键名字典序重新序列化并校验，消除 Agent 手写键序差异。
- 列表项排序固定（文件名、来源 key、检查项均按字典序），不用依赖插入顺序的写法。
- 随机成分（如若有）必须固定种子；本流程不引入随机性。

## 7. 语言切换与改写

- 语言切换（中英互译）：术语、数字、引用、来源逐字保留，仅换语言，限定强度不变；不因翻译而新增或删减事实。
- 改写：保留原文结论与适用条件，改结构不改事实；改动记入 `change_log`（`{at, target, before, after, reason}`），可回退。

## 8. 不适用边界

- 不做期刊排版模板（LaTeX/Word 版式）适配；引用格式只做语义层，不做排版宏。
- 不生成材料外事实；不自动联网补参考文献；不做“综述式罗列”的示例填充。
