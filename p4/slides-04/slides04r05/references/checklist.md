# 自检清单（对应评分维度）

逐页产出后逐条勾选；未满足项写入 `uncertainty`，不得伪装通过。每条对应
`challenge.json` 的评分维度，括号内为分值。

## 实际效果（40）
- [ ] 源论文/材料被真实写入指定模板：母版、版式、占位符继承关系可在 pptx XML 中查到，而非整段粘进默认模板。
- [ ] 页内文字、数字、图号与源材料逐字一致；图表与数据对应，图号与正文引用一致（evidence_map 有 locator + quote）。
- [ ] 覆盖封面→正文→结论主要页类型，六类要素（主线/页结构/图表引用/讲解逻辑/模板约束/导出渲染）齐全。
- [ ] 交付可打开、可继续编辑的 pptx，以及真实渲染的 PDF/PNG 预览（pptx_path 非空，pdf/png 真实存在）。
- [ ] 源文件、模板、导出件、逐页偏差与 change_log 齐全，他人可复跑逐页核对。

## 使用增益（25）
- [ ] 前 3 分钟已落盘完整 result.json 骨架（`init` 幂等），后续只做增量改进，减少返工。
- [ ] 记录实际消耗（`runtime` 的耗时/请求数）与改动页数（change_log），用证据对照而非自述。
- [ ] 每页 `page_plan.notes` 即讲稿，降低人工核对量。

## 创新增益（15）
- [ ] 明确选定突破方向并写清（本版：输出契约完整——result.json 字段逐一对齐 output_contract 并含 change_log）。
- [ ] 字号/间距阶梯、图表等比缩放、批量一致性规则可解释，并写入 SKILL.md 或 references。
- [ ] 用 `validate`/`selftest.py` 证明方法边界：哪些能自动测、哪些只能人工核。

## 可靠体验（10）
- [ ] 输入输出路径、调用顺序、时间预算写清；他人可按说明复现"论文+模板→pptx+PDF"。
- [ ] 缺版式、占位符缺失、文本框溢出、字体缺失、图表失效、导出失败均有识别与处置路径。
- [ ] 重复运行幂等：`init` 合并不覆盖，脚本 exit code 语义明确（0=ok，2=契约违规）。

## 生态贡献（10）
- [ ] 模板准备规范、参数含义、导出设置、字体要求、限制与维护信息齐全。
- [ ] 脚本只用标准库、路径相对可执行，契约引擎与检查脚本可被直接复用。
- [ ] 沉淀可分享的规则/清单（本文件 + output_contract.md），不夹带预写答案、不编造评测分数。
