# 自检清单（对应评分维度，逐条勾选）

每页产出后逐条核对；未满足项写入 `uncertainty` 或 `pending_human`，不假装通过。
确定性检查由 `scripts/selftest.py` 与 `scripts/main.py --phase validate` 自动执行；
渲染质量与学术判断只能人工核，边界在「自动可测 / 仅人工」两栏中明确。

## 实际效果（40）
- [ ] 源论文/材料真正写入指定模板，而非整段粘进默认模板；母版/版式/占位符继承关系可在 pptx XML 查到（`main.py --phase validate` 的 `integrity.slide_layout_map`）。〔自动可测：继承关系；仅人工：视觉是否“套用到位”〕
- [ ] 页内文字、数字、图号与源材料一致；每条结论在 `evidence_map` 中有 locator+逐字 quote。〔自动可测：locator/quote 存在；仅人工：数值语义正确性〕
- [ ] 覆盖封面→正文→结论的主要页类型，六类要素（主线/页结构/图引用/讲解逻辑/模板约束/导出渲染）齐全。〔仅人工〕
- [ ] 交付可打开、可继续编辑的 pptx，以及真实渲染的 PDF/PNG 预览（`%PDF-` / `\x89PNG` 魔数检查通过）。〔自动可测：魔数；仅人工：逐页渲染一致〕
- [ ] 源文件、模板、导出件与逐页偏差记录齐全，他人可按 `change_log` + `sources` 复跑核对。〔自动可测：字段齐全；仅人工：复跑后逐页比对〕
- [ ] 图号与正文引用一致，图表与数据对应；矢量图/位图混排不拉伸。〔仅人工〕

## 使用增益（25）
- [ ] 同一输入先落骨架（init 阶段）、后增量改进，减少返工页数；每页 `notes` 即讲稿。〔自动可测：`runtime.phase_order` 含 init；仅人工：返工页数对比〕
- [ ] 记录实际消耗（`runtime`、`change_log` 时间戳、改页数），供公平对照；不以自述代替运行证据。〔自动可测：字段存在；仅人工：数值真实性〕

## 创新增益（15，本版=证据溯源强化）
- [ ] 明确选定「证据溯源」为突破方向，在 SKILL.md 第 1/7 节写明，与参考方案形成可辨识取舍。〔仅人工〕
- [ ] 每条结论带 `locator + verbatim quote`，`evidence_map` 为 schema v2（claim 级 type/status + evidence 级 confidence/matcher/score），比只给 refs 更细。〔自动可测：结构断言见 selftest〕
- [ ] 字号/间距阶梯、图表等比缩放策略、批量一致性规则有可解释规则并在 SKILL.md/references 写明。〔仅人工〕
- [ ] 用 `selftest.py` 证明方法边界：哪些可自动测（结构/魔数/定位），哪些只能人工核（视觉/语义/渲染一致）。〔自动可测：selftest 通过〕

## 可靠体验（10）
- [ ] 输入输出路径（/input、/app/output、/app/work）、调用顺序、时间预算写清；他人能复现“论文+模板→pptx+PDF”。〔仅人工〕
- [ ] 缺版式、占位符缺失、文本框溢出、字体缺失、图表失效、导出失败均有识别与处置路径（见 SKILL.md 降级策略）。〔自动可测：空输入/坏 JSON 处置；仅人工：各异常分支〕
- [ ] 重复运行幂等：`init_result` 合并而非覆盖，change_log 去重，脚本 exit code 语义明确（0=成功，1=失败但已尽力落盘）。〔自动可测：selftest 幂等用例〕

## 生态贡献（10）
- [ ] 模板准备规范、参数含义、导出设置、字体要求、限制与维护信息齐全（references/output_contract.md + 本文件）。〔仅人工〕
- [ ] 脚本只用标准库、路径相对可执行，证据引擎与 pptx 检查器可直接复用。〔自动可测：`python scripts/selftest.py` 通过即证明可运行〕
- [ ] 沉淀可分享的规则/清单，不夹带预写答案、不预置正式测试产物。〔仅人工：检查 outputs/ 无答案文件〕
