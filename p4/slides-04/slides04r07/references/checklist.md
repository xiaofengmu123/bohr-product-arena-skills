# 自检清单（对应评分维度）

每页产出后逐条勾选；未满足项写入 `uncertainty`，不假装通过。交付前跑
`python scripts/selftest.py`，须 6/6 通过；确定性检查跑 `scripts/validate_deck.py`。

## 实际效果（40）
- [ ] 源论文/材料被真正写入模板，而非整段粘进默认模板；母版、版式、占位符继承关系可在 pptx XML 中查到（`validate_deck.py` 的 slide_layout_chain）。
- [ ] 页内文字、数字、图号与源材料一致；图表与数据对应，图号与正文引用一致。
- [ ] 覆盖封面→正文→结论的主要页类型；六类要素（论文主线/页结构/图引用/讲解逻辑/模板约束/导出渲染）齐全。
- [ ] 交付可打开、可继续编辑的 pptx，以及真实渲染的 PDF/PNG 预览（PDF 以 `%PDF-` 开头、PNG 魔数正确）。
- [ ] 源文件、模板、导出件与逐页偏差记录齐全，他人可复跑逐页核对。

## 使用增益（25）
- [ ] 同一输入下先落骨架、后增量改进，减少返工页数；每页备注即讲稿，降低人工核对量。
- [ ] 记录实际消耗（时间/请求数/改动页数）到 `runtime` 与 `change_log`，便于公平对照。

## 创新增益（15）
- [ ] 明确选择鲁棒性为突破方向，并写出与常规流程不同的设计取舍（先 partial 骨架、坏输入降级、超大文件跳过、幂等合并）。
- [ ] 字号与间距阶梯、图表等比缩放策略有可解释规则，并写入 `render_record`。
- [ ] 用 `validate_deck.py` 的确定性检查证明方法边界：继承链/页数/文件魔数可自动测；溢出、字号可读性、图文语义一致性只能人工核，脚本只给可疑项。

## 可靠体验（10）
- [ ] 输入输出路径、调用顺序、时间预算写清；他人能按 SKILL.md 复现"论文+模板→pptx+PDF"。
- [ ] 缺版式、占位符缺失、文本框溢出、字体缺失、图表失效、导出失败均有识别与处置路径。
- [ ] 重复运行幂等：`main.py init` 合并而非覆盖；`merge` 深度合并；脚本退出码语义明确（0/2/3）。

## 生态贡献（10）
- [ ] 模板准备规范、参数含义、导出设置、字体要求、限制与维护信息齐全。
- [ ] 脚本只用标准库、路径相对可执行；`main.py`/`validate_deck.py`/`selftest.py` 可被直接复用。
- [ ] 沉淀可分享的规则清单（本文件 + `output_contract.md`），不夹带预写答案。
