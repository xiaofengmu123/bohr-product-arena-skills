# 自检清单（按评分维度组织）

每项标记 `[自动]`（脚本可确定性检查）或 `[人工]`（需人眼/渲染复核）。逐页完成后勾选；未满足项写入 `result.json` 的 `uncertainty`，不假装通过。脚本边界即创新证据：`validate_deck.py` 只保证 `[自动]` 项，`[人工]` 项写入 `pending_human`。

## 实际效果（40 分）

- [ ] 源论文/材料被真正写入模板，而非整段粘进默认模板；母版、版式、占位符继承关系可在 pptx XML 查到。`[自动]` validate_deck 的 masters/layouts/rels
- [ ] 页内文字、数字、图号与源材料一致；图表与数据对应，图号与正文引用一致。`[自动]` build_evidence_map 逐字 quote 命中 + `[人工]` 图号核对
- [ ] 覆盖封面→正文→结论的主要页类型，六类要素（主线/页结构/图引用/讲解逻辑/模板约束/导出渲染）齐全。`[人工]`
- [ ] 交付可打开、可编辑的 pptx，以及真实渲染的 PDF/PNG 预览。`[自动]` validate_deck 的 zip/PDF/PNG 检查
- [ ] 源文件、模板、导出件与逐页偏差记录齐全，他人可复跑逐页核对。`[自动]` init_result sources + `[人工]`

## 使用增益（25 分）

- [ ] 同一输入下先落骨架、后增量改进，减少返工页数；每页备注即讲稿，降低人工核对量。`[自动]` init_result 幂等合并
- [ ] 记录实际消耗（时间/请求数/改动页数），公平对照，不用自述代替证据。`[自动]` result.runtime

## 创新增益（15 分）

- [ ] 明确选择突破方向（本版：模板套用 + 证据映射，横切导出渲染）。`[人工]`
- [ ] 字号与间距阶梯、图表等比缩放策略、批量一致性校验有可解释规则，并写入 SKILL.md/脚本。`[人工]`
- [ ] 用 validate_deck 的 `auto_verifiable/human_required` 证明方法边界（哪些能自动测、哪些只能人工核）。`[自动]` validate_deck integrity

## 可靠体验（10 分）

- [ ] 输入输出路径、调用顺序、时间预算（900s/64 请求）写清，他人能按说明复现"论文+模板→pptx+PDF"。`[自动]` selftest 引用文件存在性
- [ ] 缺版式、占位符缺失、文本框溢出、字体缺失、图表失效、导出失败均有识别与处置路径。`[自动]` validate_deck 告警 + `[人工]`
- [ ] 重复运行幂等：init_result 合并而非覆盖，脚本 exit code 语义明确（0/1/2）。`[自动]` selftest --help=0

## 生态贡献（10 分）

- [ ] 模板准备规范、参数含义、导出设置、字体要求、限制与维护信息齐全。`[人工]`
- [ ] 脚本只用标准库、路径相对可执行；selftest.py 用 AST 校验 stdlib-only。`[自动]` selftest
- [ ] 沉淀可分享的规则/清单（本文件 + output_contract.md），不夹带预写答案。`[自动]` selftest 无预制产物
