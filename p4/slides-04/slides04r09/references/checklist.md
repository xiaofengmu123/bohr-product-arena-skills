# 自检清单（对应评分维度）

每页产出后逐条勾选；未满足项写入 `result.json` 的 `uncertainty`，不假装通过。

## 实际效果（40）
- [ ] 源论文/材料被真正写入模板，而非整段粘进默认模板；母版、版式、占位符继承关系可在 pptx XML 查到（`validate` 的 `render_record.layouts_used` 与 `layout_inheritance` 检查）。
- [ ] 页内文字、数字、图号与源材料逐字一致；图表与数据对应，图号与正文引用一致。
- [ ] 覆盖封面→正文→结论的主要页类型；论文主线、页结构、图表引用、讲解逻辑、模板约束、导出渲染六类要素齐全。
- [ ] 交付可打开、可继续编辑的 pptx，以及真实渲染的 PDF/PNG 预览。
- [ ] 源文件、模板、导出件与逐页偏差记录齐全，他人可复跑逐页核对。

## 使用增益（25）
- [ ] 同一输入下先落骨架（`init`）、后增量改进，减少返工页数；每页备注即讲稿，降低人工核对量。
- [ ] 记录实际消耗（`runtime`/`change_log`），便于公平对照，不用自述代替证据。

## 创新增益（15）
- [ ] 明确选择了一个突破方向（模板套用/版式约束/字体颜色/图表适配/批量一致性之一）。
- [ ] 字号与间距阶梯、图表等比缩放策略、批量一致性校验有可解释规则并在 SKILL 中写明。
- [ ] 用 `validate` 的确定性检查证明方法边界：哪些能自动测（页数、继承、图片等比、导出签名）、哪些只能人工核（溢出目检、字体嵌入、视觉保真、图号与源一致性）。

## 可靠体验（10）
- [ ] 输入输出路径、调用顺序、时间预算写清；他人能按说明复现“论文+模板→pptx+PDF”。
- [ ] 缺版式、占位符缺失、文本框溢出、字体缺失、图表失效、导出失败均有识别与处置路径。
- [ ] 重复运行幂等：`init` 合并而非覆盖，脚本退出码语义明确（0/1/2）。

## 生态贡献（10）
- [ ] 模板准备规范、参数含义、导出设置、字体要求、限制与维护信息齐全。
- [ ] 脚本只用标准库、路径相对可执行；模板适配层与检查脚本可被直接复用。
- [ ] 沉淀了可分享的规则/清单（本文件 + `output_contract.md`），不夹带预写答案。
