# 降级与不确定性登记规则 + 静默错误清单

本文件是 SKILL.md §5/§6 的展开，供执行时逐条对照。核心设计取舍：**不做"兜底填一个看起来合理的值"，而是把不知道、算不了、降了级的地方显式写进 `limitations` 与 `uncertainty`**，让评分方能一眼看到边界在哪里。

## 1. limitations / uncertainty 登记规则

每条必须回答三个问题，缺一不可，不允许写"可能略有误差"这类无信息量的话。

- `uncertainty`：`{item, basis, mitigation}`
  - `item`：受影响的结论/字段/数值（精确到名字）。
  - `basis`：为什么不确定（缺失 n 行、异常剔除 k 条、字段歧义、近似口径、随机抽样）。
  - `mitigation`：已经做的补偿（改用中位数、加 flag 列、换稳健估计、请求人工）。
- `limitations`：`{item, effect, fallback}`
  - `item`：能力/数据/软件的缺口。
  - `effect`：对结果的真实影响范围（哪些结论受影响、程度）。
  - `fallback`：降级方案或 `pending_human`。

判定优先级（从坏到好）：`insufficient_evidence` > `partial` > `ok`。只要有一条关键结论依赖未验证的假设或缺失数据，就不得给 `ok`。

## 2. 缺失与异常策略（必须显式三选一并记录）

| 策略 | 适用 | 必须写入 |
|---|---|---|
| `drop` | 缺失少（<5%）且可假设完全随机缺失 | change_log 记录删除行数与列 |
| `mean-median` | 缺失中等且有中心趋势依据 | 记录填充值、使用的统计量 |
| `flag` | 缺失有信息量（如"未检出"） | 新增 `*_missing` 指示列，保留原列 |

铁律：**任何统计（均值/标准差/相关系数/回归/t 检验）前，先显式处理缺失；缺失不得当 0 参与均值。** 异常值剔除必须写阈值与理由，并给出剔除前/后对比，不能静默删除。

## 3. 静默错误清单（Step 4 逐条核对）

1. 缺失值被当成 0 参与均值/求和。
2. 重复记录未去重就做分组统计（先确认"重复"口径：整行重复 vs 业务主键重复）。
3. t 检验未检查正态性/方差齐性/独立性前提就报 p 值。
4. SQL WHERE 条件漏字段，导致行数偏多或口径错（逐字段核对条件完整性）。
5. 分组统计口径与数据字典不一致（组别编码、缺失归组）。
6. 单位与有效数字不一致（原始单位 vs 换算单位；保留位数与原始精度匹配）。
7. 图表坐标轴、单位、图例与数据不符（轴标签必须来自字典，图例值必须可溯源）。
8. 列名未对齐就取列（别名映射前先核对 normalized 名与原始名）。
9. 随机种子/依赖版本/命令行未记录，隔天重跑数字漂移。
10. 查询为空/数值溢出被当成正常结果或静默跳过。

每发现一条，先在 result.json 的 change_log 记动作，再修；不要掩盖。修完用 `scripts/main.py validate` 复查。

## 4. 字段对齐与口径规则

- 先对齐再计算：原始列名 → `normalize_column`（小写、去单位括号、非字母数字折叠为下划线）→ 匹配数据字典字段名。
- 同义别名（示例，实际以数据字典为准）：`sepal_length`/`sepal length`/`sepal length (cm)` 归一后为 `sepal_length`；发现多列归一到同一键时记 `source_conflict`，不静默取第一列。
- 单位换算必须记录换算系数与来源；结果标注单位。有效数字：中间计算保留全精度，最终输出按原始数据最少有效位数四舍五入，且注明。

## 5. 复现证据要求

每个关键数值/图表元素都要能指回材料逐字片段：`sources[].locator` 形如 `materials/xxx.csv#L12`、`data_profile.json#column_stats`、`case.json#output_contract.summary`；`quote` 必须是实际读到的原文片段，不能是转述。保留：原始快照、清洗规则表、代码（`/app/work/*.py`）、依赖版本、随机种子、命令行、stdout/stderr、退出码。

## 6. 缺数据不编造的具体做法

- 行数未知 → 写 `not_reported`，不写猜测行数。
- 字段缺失 → `pending_human`，不用同义名硬凑。
- 软件缺失 → 降级为纯标准库 `.csv`/`.md`，并在 `degradations` 声明"未渲染 PNG/PDF"。
- 结论矛盾 → 两个都记并标 `source_conflict`，转 `pending_human`。
