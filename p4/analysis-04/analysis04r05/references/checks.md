# 评分维度对照与静默错误清单（sci-analysis-contract）

本文件把题目评分维度映射为可执行的核对动作，并把"跑通了但算错了"的静默错误变成逐条检查项。

## 1. 评分维度 → 核对动作

| 评分维度 | 分值 | 核对动作（交付前逐条执行） |
|-|-|-|
| 任务完成度 | 15 | 清洗/统计/图表/执行(查询)四类产物是否都产出；缺一项则记 `partial` 并说明 |
| 结果正确性 | 15 | 见 §2 静默错误清单；数值与数据字典、金标准三方核对 |
| 结果完整性 | 5 | 契约字段全回填（`validate` 的 `contract_fields_complete` 必须 ok）；主产物 + 预览齐备 |
| 结果可核验性 | 5 | 快照、规则表、代码、依赖版本、随机种子、命令行、日志、退出码齐全；sources 带 locator+quote |
| 质量/效率增益 | 20 | 用 change_log 的 delta 证明"一次跑通/少调试轮次"；不靠文字自述 |
| 新增能力/方法改进 | 15 | 字段对齐账本、口径显式化、缺失异常策略、确定性重跑（固定种子 + 锁定依赖版本） |
| 调用与易用性 | 3 | 从包根按 §4 最小示例能独立完成"给数据、出结果" |
| 运行稳定性 | 4 | 空输入/坏 JSON/坏编码/缺参数四场景退出码 0 且 result.json 合法（`selftest` 验证） |
| 异常处理 | 3 | 缺列/类型不符/依赖缺失/查询为空/数值溢出/权限不足均有识别与降级 |
| 生态贡献 | 10 | 脚本纯标准库、文档齐全、失败处理说明齐全，他人可直接复跑 |

## 2. 静默错误清单（Step 4 逐条对照）

1. **缺失当 0**：均值/求和前必须 `dropna` 或显式计数，缺失值不得进分母；报告 `n` 与缺失数。
2. **未去重分组**：先判断重复记录是否应合并（按业务键，而非全行），去重前后行数都写入 change_log。
3. **t 检验前提未查**：报 p 值前检查正态性/方差齐性（或改用非参数）；前提不满足要在 uncertainty 说明。
4. **SQL WHERE 条件漏字段**：多条件查询逐条对照数据字典，条件缺一项会多算行数；把 WHERE 逐字写入 sources。
5. **单位与有效数字不一致**：列单位、图轴单位、结论单位三者一致；有效数字按原始精度保留，不臆造小数位。
6. **图表轴/单位/图例错配**：图轴标签与数据列语义一致，图例对应正确分组，缺单位在轴上显式标注。
7. **随机种子/依赖版本未留痕**：`random.seed(42)` 或 `np.random.default_rng(42)`；记录 `sys.version`、包版本、命令行。
8. **字段名与字典不符**：清洗/查询用的列名必须来自 `data_profile.json` 实际列，不按标签或记忆假设。

## 3. 异常场景处置矩阵

| 场景 | 识别方式 | 处置 | 落地字段 |
|-|-|-|-|
| 缺列 | 代码 KeyError/字段对齐失败 | 尝试别名匹配，仍失败转人工 | `errors`/`pending_human` |
| 类型不符 | 数值转换失败/列类型非预期 | 显式记录并强制类型或降级为字符串 | `errors`/`degradations` |
| 依赖缺失 | ImportError | 改纯标准库或降级文本产物 | `degradations`/`limitations` |
| 查询为空 | 结果集 0 行 | 如实记录空集，不静默跳过 | `not_reported`/`uncertainty` |
| 数值溢出 | OverflowError/NaN/Inf | 记入 errors，用有限值重算或标异常 | `errors`/`uncertainty` |
| 权限不足 | PermissionError | 降级写最小合法 result.json，退出码 0 | `errors` |
| 坏 JSON/坏编码 | 解析异常 | 捕获后继续处理其余材料 | `errors`/`degradations` |

## 4. 增益的可验证口径

- 每次代码执行记录：命令行、stdout/stderr 尾部、退出码、耗时 → 写入 `/app/work/*.log` 或 change_log。
- 调试轮次 = change_log 中 `run_failed`/`retry` 动作的数量；交付时报告该计数与根因归类。
- "一次跑通"以 `run_success` 且无后续 `retry` 为准，不靠口头声明。
- 确定性重跑：同一输入两次运行，除时间戳外 result.json 数值字段必须一致。
