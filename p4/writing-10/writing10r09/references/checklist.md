# 自检清单（逐条可勾选，对应评分维度）

## 实际效果（40 分）
- [ ] 任务完成度：把给定基线 + 意见摘要处理成可编辑修订稿与逐条回复，实质修改真实落在演练基线。
- [ ] 结果正确性：事实/数字/引用/专业判断准确；"已修改"声明与稿件真实状态一致，不虚报补做实验。
- [ ] 结果完整性：覆盖全部意见条目与一条意见内的全部子要求；回复信与修订稿格式达标。
- [ ] 结果可核验性：每条回复的定位能在指定版本稿件中独立核对（`selftest.py` 的 locator_verifiable 通过）。

## 使用增益（25 分）
- [ ] 质量增益：拆解 + 台账使逐条回应更完整、定位更可核验；同输入复跑结果一致。
- [ ] 效率增益：一次结构化动作替代"逐条比对意见、人工找行号、重写语气、补证据清单"。
- [ ] 增益可验证性：以 `selftest.py` 输出报告作为对照证据，而非仅文字自述。

## 创新增益（15 分）
- [ ] 新增能力：意见—改动—定位—证据四台账 + 版本一致性，是基础 Agent 不易稳定实现的能力。
- [ ] 方法改进：锚点定位（改后仍有效）、语气四档、not_doable 替代说明为实质改进。
- [ ] 创新证据：自检报告可独立复跑，说明相对通用写作 Agent 的边界与价值。

## 可靠体验（10 分）
- [ ] 调用与易用：SKILL 描述清晰，脚本相对路径可执行，作者可按说明完成一次完整返修。
- [ ] 运行稳定：长稿件、多意见、多轮返修、重复运行下要素不漂移、目标与版本一致。
- [ ] 异常处理：意见冲突、意见有误、稿件缺章节、无法补实验、版本不匹配、权限不足被识别并处置。

## 生态贡献（10 分）
