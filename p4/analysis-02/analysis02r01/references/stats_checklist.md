# 统计口径与检验选择清单

## 1. 描述统计口径（全部写单位）

| 量 | 口径 | 备注 |
|---|---|---|
| n | 非缺失观测数 | 缺失不当 0，不静默删除 |
| mean | Σx/n | 受异常值影响，须与 median 对照 |
| median | 50% 分位（type-7 线性插值） | 稳健中心 |
| sd | 样本标准差（ddof=1） | 报告时写清口径 |
| Q1/Q3 | 0.25/0.75 分位（type-7） | 与箱线图一致 |
| IQR | Q3−Q1 | 异常值标记用 1.5×IQR |
| skewness | 偏差校正 g1 | |
| kurtosis | 偏差校正超额峰度 g2 | |

## 2. 检验选择（先假设，后检验）

1. 先正态性：Shapiro（有 scipy）或 Shapiro-Francia 近似（纯标准库，n≥5）。
2. 再方差齐性：Brown-Forsythe（Levene 中位数版）。
3. 选择规则：
   - 两组 + 正态 + 齐 → Student t（合并方差）；
   - 两组 + 正态 + 不齐 → Welch t；
   - 两组 + 非正态 / 小样本 → Mann-Whitney U；
   - ≥3 组 + 正态 + 齐 → 单因素 ANOVA；
   - ≥3 组 + 正态 + 不齐 → Welch ANOVA（标准库不可用时如实标注，不得静默改用）；
   - ≥3 组 + 非正态 → Kruskal-Wallis H；
   - **≥3 组禁止两两 t**；事后两两比较用 Bonferroni 或 BH，并保留校正前后 p。

## 3. 效应量

| 设计 | 效应量 | 方向/口径 |
|---|---|---|
| 两组 | Cohen's d（合并 sd）/ Hedges' g（小样本校正） | group1 − group2，写方向 |
| 方差不齐 | Glass Δ（参考组 sd） | 写明参考组 |
| ≥3 组 | eta² = SSB/SST；omega² 校正 | 解释比例 |
| 分类 | Cramér's V | 关联强度 |

## 4. 置信区间（95%）

- 均值：t 分布 CI（n−1 df）。
- 均值差：Welch-Satterthwaite CI。
- 比例：Wilson score 区间。
- 相关：Fisher z 变换 CI。
- 效应量 d：Hedges-Olkin 近似 CI。
- **CI 是参数覆盖区间，不是个体取值范围**，不写"95% 的个体落在区间内"。

## 5. 结果解释

- p 写精确值（`p=0.043`），不写 `p<0.05` 一略而过；不写"证明有效"。
- 区分统计显著与实际意义；效应量 + CI 与 p 并列呈现。
- 标注适用条件（正态性/方差齐性是否成立）、剩余不确定性与待人工确认项。

## 6. 七类情形核对

缺失值 / 异常值 / 重复记录 / 统计假设 / 图表选择 / 代码运行 / 数据库字段，七类都要在
`quality_checks.json` 有明确计数、处理规则与证据定位。

## 7. 常见错误（红线）

- 缺失当 0；整行删除不报 n 前后变化。
- 异常值不识别直接进均值；静默删除。
- 重复不去重导致样本量虚增。
- 三组塞进 t 检验；未做正态性/方差齐性。
- 只有 p 没有效应量与 CI；多重比较不校正。
- 字段单位 μg/mg、cm/mm 乱猜；单位不明仍硬算。
- 依赖外部包版本导致换机报错；随机数导致不可复现。
