# 统计口径、检验选择与证据清单（stats_checklist）

本清单是 `scripts/core_impl.py` 的计算口径说明，也是 Agent 撰写结果解释时的核对表。
脚本只给出可确定计算的数字；**正态性 p 值在 scipy 可用时用 `scipy.stats.shapiro` 交叉核对**，
脚本本身只输出确定性的 Shapiro-Francia W' 统计量，绝不把 W' 冒充 p 值。

## 1. 描述统计口径

| 统计量 | 口径 | 备注 |
|---|---|---|
| n | 去重后、该列非缺失样本数 | 缺失不当 0，不当有效样本 |
| mean / median | 算术平均 / 中位数 | 与单位一致 |
| sd | 样本标准差（ddof=1） | 用于推断 |
| min / max | 最小值 / 最大值 | 报告原始量纲 |
| Q1 / Q3 / IQR | Type-7 线性插值分位数；IQR=Q3-Q1 | 与 numpy 默认一致 |
| skewness | Fisher-Pearson g1 | n≥3 才计算 |
| kurtosis | 超额峰度 g2 | n≥4 才计算 |

单位：数据字典未声明单位时一律写 `unit_unknown`，不猜 μg/mg、cm/mm。每个数值带
`locator`（表名+列名）与 `quote`（原始前 5 个值摘录）。

## 2. 假设检验前必须做的两项检查

1. **正态性**：每组 Shapiro-Francia W'（脚本）→ scipy `shapiro` p 值（Agent，可用时）。
   拒绝正态的判定以 scipy shapiro 的 p 为准；scipy 不可用则把检验降级为非参数，不报 p。
2. **方差齐性**：Brown-Forsythe（中位数中心 Levene）F 检验（脚本已给出 F/p）。

## 3. 检验选择表（≥3 组禁止两两 t）

| 设计 | 条件 | 方法 |
|---|---|---|
| 两组独立 | 正态 + 方差齐 | Student t（pooled） |
| 两组独立 | 正态 + 方差不齐 | Welch t |
| 两组独立 | 非正态或小样本/离群多 | Mann-Whitney U（tie 校正） |
| ≥3 组独立 | 正态 + 方差齐 | 单因素 ANOVA |
| ≥3 组独立 | 非正态或方差不齐 | Kruskal-Wallis（tie 校正） |
| 配对两组 | 差值正态 | 配对 t |
| 配对两组 | 差值非正态 | Wilcoxon signed-rank |
| 两连续变量 | 线性相关 | Pearson r + Fisher z CI |
| 两分类变量 | 独立性 | Pearson χ² + Cramér's V |

**多重比较**：≥3 组的事后两两比较必须用 Bonferroni 或 BH 校正，并同时留校正前后 p。
脚本只给整体检验；事后比较由 Agent 依据设计补做并注明校正方法。

**样本量/方差边界**：n<2、组内方差为 0、缺失比例过高时，该检验标 `不适用`，不给 p。

## 4. 效应量口径

| 设计 | 效应量 | 说明 |
|---|---|---|
| 两组均值 | Cohen's d（pooled SD） | 方向=组1-组2 |
| 两组均值 | Hedges' g | d 的小样本偏倚校正 |
| 方差不齐 | Glass Δ | 以对照组（组2）SD 为分母 |
| ANOVA | η² / ω² | 解释比例；ω² 更少偏倚 |
| 分类 | Cramér's V | 关联强度 |

Cohen's d/g 的 95% CI 用 Hedges-Olkin 正态近似：
`se = sqrt((n1+n2)/(n1·n2) + d²/(2(n1+n2)))`，`CI = d ± 1.96·se`。写清口径，不冒充
非中心 t 精确 CI。

## 5. 置信区间口径（均为参数覆盖区间，非个体取值范围）

| 估计 | 方法 |
|---|---|
| 单组均值 | t CI（n-1 自由度） |
| 两组均值差 | Welch t CI（Welch 自由度） |
| 比例 | Wilson score |
| 相关系数 | Fisher z 变换 + 正态临界值 |

CI 必须与检验结论、样本量、不确定性一致；p 值显著但 CI 宽到无实际意义时如实说明。

## 6. 七类情形处理规则（对应评分维度）

1. **缺失值**：逐列计数+比例；不当 0、不静默整行删除；分析时 pairwise/listwise 明确口径。
2. **异常值**：IQR 1.5 标记（给出上下 fence），**不静默删除**；是否纳入分析写明理由。
3. **重复记录**：完全重复行去重，保留第一条，记录去重前后 n。
4. **统计假设**：先正态性/方差齐性再选检验；≥3 组不用两两 t；多重比较校正。
5. **图表选择**：组间比较→箱线图，分布→直方图；可编辑 SVG；图元对应计算值。
6. **代码运行**：纯标准库、无随机数、确定性；`code/` 保留源码可复跑。
7. **数据库字段**：推断列类型（int/float/categorical/date）；单位不明记 `unit_unknown`。

## 7. 结果解释纪律

- p 写精确值（`p=0.043`），不写"证明有效"；区分统计显著与实际意义。
- 每个关键数值给 `locator + quote` 或计算依据（cleaned CSV + code + 无 seed）。
- 标注适用条件、剩余不确定性、`pending_human`（需人工确认项）。
- 冲突信息不隐藏：同指标两个来源不一致时两处都记录并标 `source_conflict`。
- 不编造引用、DOI、数值、软件状态、运行记录。

## 8. 常见错误（自检时逐条排除）

1. 缺失当 0 或整行删除却不报删了多少。
2. 异常值未识别直接进均值。
3. 重复未去重导致样本量虚增。
4. 三组数据塞进两样本 t 检验。
5. 非正态小样本仍用参数方法。
6. 只报 p 值，缺效应量与 CI。
7. p=0.04 写成"证明有效"。
8. 多重比较未校正。
9. 依赖非标准库导致换机报错。
10. 单位 μg/mg 全程不交代。
