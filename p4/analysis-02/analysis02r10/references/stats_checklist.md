# 统计口径与自检细则（stats_checklist）

本文件是 SKILL.md 第 5 节的展开，供 Agent 在“任务解读”与“结果解释”阶段逐条对照；
计算实现见 `scripts/statlib.py`，每个结果都带 `method` 字段说明口径。

## 1. 检验选择表（先正态性/方差齐性，再选检验）

| 设计 | 条件 | 选择 | 备注 |
|---|---|---|---|
| 两组独立 | 双正态 + 方差齐 | Student t | 池化方差，df=n1+n2-2 |
| 两组独立 | 双正态 + 方差不齐 | Welch t | Satterthwaite df |
| 两组独立 | 任一非正态或 n<20 正态性不适用 | Mann-Whitney U | 正态近似+连续性+结校正 |
| ≥3 组独立 | 全正态 + 方差齐 | one-way ANOVA | F(df_between, df_within) |
| ≥3 组独立 | 全正态 + 方差不齐 | Welch ANOVA | 不等方差 F |
| ≥3 组独立 | 任一非正态 | Kruskal-Wallis | χ² 近似 + 结校正 |
| ≥3 组事后 | 上述任选后 | 逐对比较 + Bonferroni/BH | **禁止裸两两 t**，保留校正前后 p |
| 两数值列 | 线性相关 | Pearson r（t 检验 + Fisher z CI） | 或 Spearman（秩相关） |
| 数值→数值 | 预测/回归 | OLS 简单线性回归 | 斜率 t 检验 + 95% CI + R² |
| 两分类列 | 关联 | Pearson χ² + Cramér's V | 2×2 或更大列联表 |

正态性用 D'Agostino-Pearson K²（n≥20）；n<20 时标“不适用”，建议用 scipy
Shapiro-Wilk 交叉核对。方差齐性用 Brown-Forsythe（中位数 Levene）。

## 2. 效应量与置信区间口径

| 指标 | 公式/口径 | CI |
|---|---|---|
| Cohen's d | (x̄1−x̄2)/s_pooled | 正态近似 95% CI |
| Hedges' g | d·(1−3/(4(n1+n2)−9)) | 同乘校正因子 |
| Glass Δ | (x̄1−x̄2)/s_control | 无闭式（标 not_reported） |
| η² | SS_between/SS_total | 点估计 |
| ω² | (SS_b−df_b·MS_w)/(SS_t+MS_w) | 点估计（偏差校正） |
| Pearson r | 协方差/标准差乘积 | Fisher z 95% CI |
| R²（回归） | 1−SSE/SST | — |
| Cramér's V | sqrt(χ²/(n·min(r−1,c−1))) | — |
| 均值 95% CI | x̄ ± t(α/2,n−1)·s/√n | 参数覆盖区间 |
| 均值差 CI | Welch-Satterthwaite | 参数覆盖区间 |
| 比例 CI | Wilson | — |

CI 是**参数覆盖区间**，不是个体取值范围，解释时必须写明。

## 3. 七类情形的处理规则

1. 缺失值：计数 + 比例；不当 0、不静默整行删除；统计量用可用观测（listwise）。
2. 异常值：Tukey IQR 1.5 标记，保留并报告数量，不静默删除。
3. 重复记录：去重前后 n + 保留规则（默认“完全重复行保留首条”）。
4. 统计假设：先正态性 + 方差齐性，检验选择写 `method` 与理由。
5. 图表选择：组间→箱线图；相关/回归→散点图；分布→直方图；均为可编辑 SVG。
6. 代码运行：stdlib-only、无随机数、同输入同输出；`analysis_code.py` 可复跑。
7. 数据库字段：dtype + 单位从数据字典推断；不明写 `unit_unknown`，不猜。

## 4. 常见错误（避免）

- 缺失当 0 参与均值；整行删除却不报删除数。
- 异常值未识别直接进均值。
- 重复未去重导致样本量虚增。
- 三组数据塞进两样本 t；多重比较不校正。
- 非正态小样本套参数方法；从不做正态性/方差齐性。
- 只有 p 值，无效应量、无置信区间。
- p=0.04 写成“证明有效”；p 只给 <0.05 不写精确值。
- CI 误读为个体取值范围。
- 依赖未声明包版本；换机器跑不动。
- 单位 μg/mg、字符串/数值不分。

## 5. 结果解释模板（写进 interpretation）

- 结论 + 精确 p（如 `p=0.043`）+ 效应量（方向 + CI）。
- “统计显著”与“实际意义”分开表述。
- 适用条件（正态性/齐性/样本量/设计）与剩余不确定性。
- 需人工确认项：单位、配对结构、缺失机制、异常值是否应为测量错误。
