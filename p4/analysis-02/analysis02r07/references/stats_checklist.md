# 统计口径与检查清单（stats_checklist）

本清单对应评分维度：任务完成度、结果正确性、结果完整性、结果可核验性。
脚本 `scripts/statlib.py` 是唯一权威计算实现；此文件说明口径与判断规则。

## 1. 口径约定（与 statlib.py 一致）

| 项 | 口径 |
|---|---|
| 标准差 | 样本标准差（Bessel 校正，ddof=1） |
| 分位数 Q1/Q3 | 线性插值法（numpy 默认 type 7） |
| 偏度 | Fisher-Pearson g1 |
| 峰度 | 超额峰度 g2 |
| p 值 | 双侧，除非注明单侧 |
| t/F/χ² 分布 | 由不完全 Beta/不完全 Gamma 函数自算，可与 scipy 交叉核对 |
| 确定性 | 无随机数；JSON `sort_keys` 稳定输出；同输入重复运行结果一致 |

## 2. 检验选择（先假设，后检验）

1. 每个组先做正态性：Jarque-Bera（有 p）+ Shapiro-Francia W′（筛选指标，n<3 不适用）。
2. 两组及以上做方差齐性：Levene（Brown-Forsythe，中位数中心化）。
3. 选择规则：

| 条件 | 两组 | ≥3 组 |
|---|---|---|
| 正态 + 方差齐 | Student t（合并方差） | 单因素 ANOVA |
| 正态 + 方差不齐 | Welch t | Welch 型（或仍用 ANOVA + 说明） |
| 非正态 / 小样本 / 无法满足 | Mann-Whitney U | Kruskal-Wallis H |

- **≥3 组严禁两两 t**；事后比较用 Bonferroni 或 BH 校正并保留校正前后 p。
- 配对设计用配对 t / Wilcoxon 符号秩；相关设计用 Pearson / Spearman。

## 3. 效应量与置信区间

| 设计 | 效应量 | 置信区间 |
|---|---|---|
| 两组（方差齐） | Cohen's d / Hedges' g（方向+CI） | 均值差 Welch CI |
| 两组（方差不齐） | Glass Δ（对照标准差） | 均值差 Welch CI |
| 多组 | eta² / omega² | —（或按需事后 CI） |
| 分类 | Cramér's V | —（χ² 检验） |
| 相关 | Pearson r / Spearman ρ | Fisher z 变换 CI |
| 比例 | — | Wilson 得分 CI |
| 单组均值 | — | Student t CI |

- CI 是参数覆盖区间，不解释为个体取值范围。
- 效应量方向需与检验方向一致；数值与 n、自由度、不确定性一致。

## 4. 七类情形必须逐项交代

1. **缺失值**：每列计数 + 比例；不当 0 参与计算；删除方式（listwise/pairwise）写清。
2. **异常值**：IQR 1.5 标记，**不静默删除**；报告标记数量与比例。
3. **重复记录**：去重前后 n + 保留规则（保留首次出现）。
4. **统计假设**：正态性 + 方差齐性结果与检验选择理由。
5. **图表选择**：数值分布用箱线图/直方图（可编辑 SVG）；分类用条形图；不放默认样式。
6. **代码运行**：`code/` 快照 + 运行环境 + 复跑命令；同输入两次结果一致。
7. **数据库字段**：每表 schema、列类型、单位；单位不明写 `unit_unknown`；字符串/数值类型交代。

## 5. 常见错误（避免）

- 缺失当 0、整行删除不报数、重复不去重。
- 三组套两样本 t；非正态小样本套参数法。
- 只有 p 没有效应量/CI；p=0.04 写"证明有效"。
- 多重比较不校正；靠反复换方法凑显著。
- 只给最终数字，不给来源、规则、代码、seed。

## 6. 证据溯源

- 每个关键数值给 `locator`（文件#行/列）+ 逐字 `quote` 或计算依据（cleaned.csv + code/）。
- 冲突信息不隐藏：同一指标两个来源不一致时都记录并标 `source_conflict`。
- 不虚构引用、DOI、数值；缺失写 `not_reported` 或 `pending_human`。
