# 统计口径与检验选择（stats_checklist）

本文件给出脚本实现所依据的统计口径、检验选择表、效应量与区间解释、七类情形处理
与常见错误。Agent 与复核人都应据此判断“方法是否与数据匹配、数字是否可信”。

## 1. 描述统计口径

- n：有效（非缺失）样本数；缺失单独计数并给比例，**不当作 0 参与计算**。
- 中心：mean、median。离散：样本标准差 sd（ddof=1）、IQR、min/max。
- 分位：Q1/Q3 用线性插值（type 7，与 numpy/pandas 默认一致）。
- 形态：skewness 与 kurtosis 用偏差校正估计（pandas 默认口径），kurtosis 为超值峰度
  （正态=0）。
- 单位：每个统计量后写单位；单位不明写 `unit_unknown`，不猜 μg/mg、cm/mm。

## 2. 正态性与方差齐性

- 正态性：Shapiro-Wilk（Royston 1992/1995，AS R94 扩展，n=3–5000），报 W 与 p。
  scipy 可用时可用 `scipy.stats.shapiro` 交叉核对（两者算法同源）。
- 方差齐性：Brown-Forsythe（Levene 中位数中心化），报 F、p、df1、df2。
- 结论只写“在 α=0.05 下未能拒绝/拒绝正态（或方差齐）”，不写“数据是正态的”。

## 3. 检验选择表

| 设计 | 条件 | 选择 | 注意 |
|---|---|---|---|
| 两组独立 | 正态 + 方差齐 | Student t（合并方差） | 报告 df、t、p、均值差 |
| 两组独立 | 正态 + 方差不齐 | Welch t | Welch 自由度非整数，如实报告 |
| 两组独立 | 非正态或小样本 | Mann-Whitney U | 秩和；报 z、秩双列相关 |
| ≥3 组独立 | 正态 + 方差齐 | 单因素 ANOVA | 报 F、df_b、df_w |
| ≥3 组独立 | 非正态 | Kruskal-Wallis | 报 H、df、p |
| 配对 | 差值正态 | 配对 t | 报 t、df、p |
| 配对 | 差值非正态 | Wilcoxon 符号秩 | 报 T、z、p |
| 两数值变量 | 线性 | Pearson r + Fisher z CI | 报 r、t、df、p |
| 两数值变量 | 非线性/有离群 | Spearman ρ | 报 ρ、p |
| 两分类变量 | 独立性 | χ² + Cramér's V | 报 χ²、df、p、V |

**≥3 组禁止两两 t 检验**。若需事后比较，用 Bonferroni 或 Benjamini-Hochberg 校正，
并同时保留校正前与校正后的 p。

## 4. 效应量与置信区间口径

- Cohen's d：均值差 / 合并标准差（组 0 − 组 1，写方向）。CI 用渐近方差
  `(n1+n2)/(n1·n2) + d²/(2(n1+n2))`（Hedges & Olkin）。
- Hedges' g：d × (1 − 3/(4(n1+n2) − 9))，小样本校正。
- Glass Δ：均值差 / 对照组标准差（方差不齐时用）。
- ANOVA：eta² = SS_between/SS_total；omega² 为偏差校正版本，报告更稳妥。
- Cramér's V = sqrt(χ²/(n·min(r−1,c−1)))。
- 相关：Fisher z 变换 CI = tanh(atanh(r) ± z·SE)，SE = 1/sqrt(n−3)。
- 均值 CI：t 分位数（df=n−1）。比例 CI：Wilson。均值差 CI：Welch 自由度。
- **CI 是参数覆盖区间，不是个体取值范围**；解释时不得混淆。

## 5. 结果解释纪律

- p 写精确值（`p=0.043`），不写 `p<0.05` 就不给值；不写“证明有效/无效”。
- 区分统计显著与实际意义：显著 = 数据与 H0 不一致的概率低；意义 = 效应量大小 +
  CI 精度 + 领域阈值。
- 标注适用条件、剩余不确定性、需人工确认项（设计、单位、离群处理策略）。

## 6. 七类情形处理

1. 缺失值：计数 + 比例；分析列 case-complete 删除并记录删除行数；不补 0。
2. 异常值：IQR 1.5 标记（或任务指定方法）；默认**保留并标注**，不静默删除。
3. 重复记录：去重前后 n + 保留规则（keep first）；样本量不得凭空变大。
4. 统计假设：正态性/方差齐性先检；方法随假设改变。
5. 图表选择：组间→箱线图，单变量→直方图，相关→散点图；用可编辑 SVG。
6. 代码运行：纯标准库、相对路径、退出码 0、确定性；scipy 仅作交叉核对。
7. 数据库字段：读 schema，区分数值/分类/日期；数字串显式转数值；单位不明标
   `unit_unknown`。

## 7. 常见误用（本 Skill 规避项）

- 缺失当 0、整行删除不报数、异常直接进均值、重复不 dedup。
- 三组塞两样本 t；非正态小样本套参数法；正态性/方差齐性从不检。
- 只有 p 值没有效应量与 CI；p=0.04 写成“证明有效”。
- 多重比较不校正，靠换方法凑显著。
- 代码换机器因包版本报错；数据库字段单位/类型不交代。
- 单位瞎猜、随机种子不固定导致不可复现。
