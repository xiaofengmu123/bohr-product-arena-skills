# 结果与讨论章节写作协议（运行时事实底稿）

本文件是 SKILL.md 的细则，规定把“图表已画好、数据已在手”的科研材料转成
**可投稿的结果段与讨论段**的写法与证据要求。执行时以 `/input/case.json` 的
output_contract、受众/文体/格式约束为准；本文件提供默认规则。

## 1. 四个硬问题（对应题目“读得准/分得清/说得住/核得了”）

### 读得准 —— 图表只读不猜
- 数值、单位、误差棒含义（SEM/SD/CI）、坐标刻度、样本量 n、统计量与 p 值，
  必须逐项读入并写进正文；读不清就标 `uncertainty`，不补造。
- 多面板图写清 `图X第Y面板`；补充材料写清 `Figure S…`/`Table S…` 编号。
- 单位换算与有效数字保持与原始图表一致；换算过程写入 `facts_sources` 的
  `derivation` 字段。

### 分得清 —— 结果段与讨论段不互相顶替
- **结果段**：只陈述观察到的事实（方向、幅度、显著性、比较），不解释机制、
  不引用“他人为何一致”，不写局限。
- **讨论段**：承担解释、文献对照（一致/不一致及可能原因）、机制与因果边界、
  局限。可以回指结果数值，但不再重复罗列结果。
- 两节之间不留“主次不分”的流水账；按图序或按科学问题组织，各段首句给出
  该段结论，段尾回到证据。

### 说得住 —— 语气强度与证据强度匹配
趋势与差异必须写全四要素：**方向、幅度、显著性、比较对象**。有边界的写法：
- 趋势一致但未达显著 → “呈 … 趋势（P = 0.08），未达预设显著性水平”，
  不得写成“显著升高”。
- 仅在高剂量组出现 → “仅在高剂量组观察到 …，其余组未见”，不得写成全局结论。
- 统计量缺失 → 只写描述性观察，并标 `uncertainty: 统计量未提供`。
- 相关 ≠ 预测 ≠ 因果：写“与 … 相关”就只写相关；机制推测必须标“推测/假设”。

### 核得了 —— 每个数值/论断可回溯
- 正文每个关键数值 → `facts_sources` 一条：`locator`（文件+图/表/页码/段落）
  + 逐字 `quote` + 可选 `derivation`。
- 讨论每条论断 → 对应本研究数据 `locator` 或具体文献 `locator`；文献只写
  已在材料中实际出现的条目，不新增、不编 DOI/URL，找不到就标 `unverified`。
- 冲突信息（同一指标两个来源不一致）两条都记录，标 `source_conflict`。

## 2. 章节组织模板（默认，可被 case.json 覆盖）

```
## Results
1. (图序/问题序) 观察事实：方向/幅度/显著性/比较对象 → 证据引用 [图X/表Y]
2. 阴性结果与未达显著的边界写法
3. 与图注一致的单位、误差棒、n、p
## Discussion
1. 本研究主要发现（回指结果，不重复罗列）
2. 与文献一致/不一致及可能原因（每条论断→具体文献 locator）
3. 机制与因果边界（推测显式标注）
4. Limitations：方法、样本、测量、统计四个层面，具体可操作
```

## 3. 证据强度阶梯（动词选择）

| 证据 | 可用措辞 | 禁用措辞 |
|---|---|---|
| 统计显著 + 复制 | 表明/证实（established 才用证实） | 首次、颠覆性 |
| 单研究/未复制 | 初步表明 | 证实 |
| 趋势未达显著 | 呈 … 趋势、未达显著 | 显著升高 |
| 相关 | 与 … 相关 | 导致、引起 |
| 机制推测 | 推测、假设、有待验证 | 证明 |

## 4. facts_sources 条目字段（逐条）

```json
{
  "locator": "materials/fig2.pdf#p3 或 case.json#figures[0]",
  "quote": "逐字片段",
  "derivation": "单位换算/有效数字/合并规则（可空）",
  "status": "verified | unverified | source_conflict"
}
```

`locator` 必须指向 `/input` 下真实材料或 case.json 内真实位置；`quote` 必须
是逐字片段，不得改写。数值经换算时把原值与换算公式写进 `derivation`。
