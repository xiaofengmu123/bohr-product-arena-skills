# 结果与讨论章节：四问规则与检查清单

本文件是 `SKILL.md` 自检清单的展开规则。四个问题对应题面“读得准 / 分得清 /
说得住 / 核得了”。运行时如 `case.json` 给出不同约束，以 case.json 为准。

## 1. 读得准（图表读数与转写）

- 只依据实际读到的数值、单位、坐标刻度、误差棒含义、统计量写作；
  不依据文件名、图题猜测、领域常识补造。
- 数值转写规则：保留有效数字与原文单位；换算单位时明确写 `原值 (原单位)
  = 换算值 (目标单位)`，换算因子写进 `facts_sources`。
- 误差棒先辨语义：`SD`（离散度）、`SEM`（均值精度）、`CI`（区间）三者不可混用；
  正文写 `mean ± SEM (n=…)` 时三项都必须能从来源读到。
- 多面板图逐面板定位：`Figure 1a` 与 `Figure 1b` 分别给 locator；补充材料编号
  原样保留（如 `Fig. S3`）。
- 统计量转写：`p` 值、检验名、自由度、样本量逐项对应；不得把 `p=0.052` 写成
  “显著”，不得把“趋势一致但未达显著”写成“两组存在差异”。

## 2. 分得清（结果 vs 讨论不互相顶替）

- 结果段：只陈述观察到的现象与描述性/推断性统计结果，不解释机制、不做文献
  对比、不下“表明/证实某因果关系”的结论。
- 讨论段：承担解释、文献对照、一致性/不一致性、可能原因与局限；不重复报数，
  引用具体文献并说明与本结果的“一致/不一致/可能解释”。
- 交叉检查：结果段里出现“suggests / indicates / due to / caused by”等解释性
  措辞，应移到讨论段或改为中性描述。

## 3. 说得住（趋势、差异、因果表述与证据强度匹配）

- 方向、幅度、显著性分开写：`方向（升/降）+ 幅度（Δx, x%）+ 显著性（检验, p, n）`。
- 语气强度对照表：
  - `p < 0.05` 且效应明确 → “显著升高/降低”；
  - 未达显著但方向一致 → “呈上升趋势，但差异未达统计显著（p=…）”；
  - 仅某剂量/亚组出现 → “仅在高剂量组观察到”，不做全样本推广；
  - 相关/预测 ≠ 因果 → “与…相关”“预测…”；机制推测明确标 `(推测)`。
- 每个“趋势/差异/因果”句必须挂一个 `facts_sources` 证据项，写清是“材料内
  数据”还是“文献引用”。

## 4. 核得了（逐条可回溯）

- 段落 → 证据 三级对应：正文句 ↔ `facts_sources` 条目 ↔ 来源 locator + 逐字 quote。
- locator 规范：`materials/<file>#L<line>` 或 `materials/<file>#p<page>`；若材料
  是 PDF 且平台已解析，用解析后文本的行号；否则标注 `unverified`。
- 每个关键数值、术语、引用、图表、论断都有且仅有一个来源；同一指标两个来源
  不一致时两个都记录并标 `source_conflict`。
- 无来源的数值/文献/政策口径一律写 `pending_human` 或 `not_reported`，不伪造。
