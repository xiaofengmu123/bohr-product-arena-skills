# 结果与讨论写作规则：读得准 / 分得清 / 说得住 / 核得了

本文件是 SKILL.md 核心规则的展开，写作时逐条对照；运行时若 case.json 另有要求，以 case.json 为准。

## 1. 读得准：图表/统计 → 正文的转写规则

正文中出现的每个数值必须满足“五带”：

1. **带单位**：与源图/源表一致；单位缺失或不明时写 `unit_unknown` 并进 uncertainty，禁止自行推断。
2. **带有效数字**：与源一致，不做无依据的四舍五入；源给 3.24 就写 3.24，不写 3.2。
3. **带误差棒含义**：明确 SD / SEM / 95% CI / 四分位范围（IQR）/ 全距（range）之一，不混用；源图只画误差棒但图注未说明时，写“误差棒含义见图注/未说明”并标 uncertainty。
4. **带样本量与统计量**：n、检验方法（t 检验 / ANOVA / Mann–Whitney U / χ² 等）、p 值或效应量（Cohen's d / η² / r）、自由度（df）；缺失时如实写“未报告”。
5. **带图/表定位**：`Fig 1B`（多面板写 A/B，不写 Fig 1）、`Table 2`、`Fig S3`（补充材料）。同一数据同时出现在正文图表与补充材料时，两处编号都记录。

额外规则：

- 不把“趋势”写成“显著”：只有源给出 p 值且低于显著性水平时才写“显著”，否则写“趋势/未见显著差异”。
- 不把均值差写成“升高了 3 倍”除非源明确给出倍率或百分比；优先写原始差值与效应量。
- 多面板图、复合图、叠加图分别抽取各面板数值，不合并；读不清的面板标 `chart_reading_unclear`。

## 2. 分得清：结果段 vs 讨论段的边界

| 内容 | Results | Discussion |
|---|---|---|
| 观察到的方向/幅度/比较/显著性/阴性结果 | ✅ | ❌ |
| 与文献一致/不一致的比较 | ❌ | ✅ |
| 机制解释、因果关系推断 | ❌ | ✅（标“推测”） |
| 方法/样本/测量/统计局限 | ❌ | ✅ |
| 对未来研究的建议 | ❌ | ✅ |

**两遍写作法**：

1. 第一遍：只写 `## Results`，逐图/逐表/逐统计输出列出“观察事实”，每条事实后附 locator+quote；
2. 第二遍：写 `## Discussion`，从第一遍的事实清单取证，逐条写解释、文献对照、局限，每条论断标注依据（本研究数据 or 具体文献）。

判定句“这句属于哪一节”的口诀：**说“是什么/多少”进结果；说“为什么/意味着什么/和谁比”进讨论。**

## 3. 说得住：语气强度校准表

语气强度必须等于证据强度，不得越级。

| 证据 | 允许表述 | 禁止表述 |
|---|---|---|
| 显著差异（p 给定，n 给定） | “显著升高/降低（p=…，n=…）” | 泛化到未测群体 |
| 方向一致但 p≥阈值 | “呈…趋势，但未达统计学显著（p=…）” | “显著/明显” |
| 仅部分组/高剂量出现 | “仅在高剂量组观察到…（n=…）” | 推广为总体效应 |
| 相关性 | “相关/关联（r=…，p=…）” | 因果词 |
| 预测模型 | “预测（AUC=…/R²=…）” | 因果词 |
| 随机对照/干预/因果设计 | 可用“导致/引起/降低风险” | 因果词用到观察设计 |
| 机制推测 | “提示…可能…（属推测）” | 断言机制 |

**禁词表**（除非材料原文逐字引用并标出处，否则删除或降级）：
首次、国际领先、世界领先、填补空白、颠覆性、革命性、重大突破、突破性、首创、全球第一、世界第一、史无前例、独一无二、开创性；first-in-class、world-leading、groundbreaking、revolutionary、unprecedented、best-in-class、breakthrough。

**因果边界**：区分“相关 / 预测 / 因果”三档。观察性设计默认只能写“相关，不足以推断因果”；只有随机对照、干预、工具变量、因果推断方法才可写“导致/引起/降低风险”。机制推测必须写“可能/提示/推测”，不能写成“证明了机制”。

## 4. 核得了：证据溯源规范

**locator 格式**：`<相对文件名>#<定位>`，定位可为页码、行号、图号、表号、段落标识，如 `materials/fig1.txt#L12`、`materials/paper.md#p3`、`materials/table2.csv#row5`。locator 必须指向实际存在的材料文件。

**quote 规范**：逐字引用材料中的原文片段（数字、术语、关键句），不转述、不改写；长度以能定位为准（通常 ≤200 字符）。材料是图时，quote 写图注原句 + 读出的数值。

**evidence map 结构**（facts_sources 或 output_contract 等价字段）：

```json
{
  "locator": "materials/fig1.txt#L12",
  "quote": "mean ± SD = 3.24 ± 0.41",
  "used_in": "## Results 第 2 段",
  "kind": "figure|table|statistical_output|reference"
}
```

**覆盖要求**：正文中每个数值、每条统计结论、每条文献对照论断都要有一条 evidence 记录；`used_in` 写清正文位置，使第三方能判断“这句该不该这么写”。

**文献引用规则**：只写材料中真实出现的文献条目（作者、年份、期刊、DOI/URL 中材料确有者）；材料没有的 DOI/页码/作者一律不补，标 `unverified`。不伪造引用。
