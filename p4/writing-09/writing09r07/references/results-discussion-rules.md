# 结果与讨论章节写作规则与检查清单

本文件是 Skill 在写作阶段的默认规则。运行时若 `/input/case.json` 给出更具体的
受众、文体、格式或章节结构约束，以 case.json 为准；本文件负责填补其未覆盖的
科研写作底层规则。

## 1. 四个核心问题（写作时逐条对照）

- **读得准**：正文中的每个数值、单位、误差棒含义、坐标刻度、显著性统计量都
  必须来自材料里可定位的图、表、统计输出或文字，不靠猜。
- **分得清**：结果段只陈述观察事实；解释、文献对照、机制、局限放到讨论段。
- **说得住**：趋势、组间差异、因果表述必须有数据或检验支撑，语气强度与证据
  强度匹配。
- **核得了**：每个数值能回溯到某张图/某张表/某份统计输出；每条讨论论断能对应
  到本研究数据或具体文献。

## 2. 结果段与讨论段分界

| 内容 | 结果段 | 讨论段 |
|-|-|-|
| 观察到的现象、数值、统计量 | 写 | 不重复铺陈 |
| 趋势/差异的表述（方向、幅度、显著性） | 写（只描述） | 可总结 |
| 解释“为什么”、机制、与文献对比 | 不写 | 写 |
| 因果、推测、临床/实践意义 | 不写 | 写并标推测 |
| 局限（方法/样本/测量/统计层面） | 不写 | 写 |
| 阴性结果、不一致文献 | 如实写 | 如实写并解释 |

判断一句是否越界：把“观察到/检验显示/数据显示”去掉后，若该句仍主张“导致/表明/
说明/原因”，它属于讨论段。

## 3. 语气强度对照（证据 → 措辞）

| 证据强度 | 允许的措辞 | 禁止的措辞 |
|-|-|-|
| 有检验且显著（报告 p 值与检验名） | 显著高于/低于（附 p=…，检验名） | 明显/大幅（无检验时） |
| 趋势一致但未达显著 | 呈升高趋势，但差异未达统计学显著（p=…） | 显著升高、证明 |
| 相关关系 | 与…相关（r=…，p=…） | 导致、决定、因果 |
| 预测模型 | 可预测/与…相关 | 致病、机制 |
| 机制推测 | 可能提示、我们推测 | 表明、证实 |
| 单中心/小样本 | 本研究样本中观察到 | 普遍结论 |

无检验的“大/小/高/低”只允许用于有描述统计或明确刻度的比较，并给出数值。

## 4. 因果边界规则

1. 相关、预测、因果三者分别标注，不互相替代。
2. 机制解释若没有实验直接支持，一律加“推测/可能”，并写入 facts_sources 标
   `kind=interpretation`。
3. 横断面、观察性、事后分析（post hoc）等设计限制必须进入局限，不能只写
   “样本量小”这类泛泛自我评价。

## 5. 局限的四层写法

局限必须落到具体层面并说明对结论的影响：

1. 方法层：测量手段、盲法、混杂控制、技术分辨率。
2. 样本层：样本量、纳入排除、代表性、失访。
3. 测量层：单位、检测下限、缺失值处理、多面板/补充材料对应关系。
4. 统计层：多重比较、事后检验、效应量未报告、置信区间宽度。

## 6. 图表读数转写规则

- 先读图注与坐标轴标签，再读数；不确定刻度时标 `unverified`，不估读。
- 单位与有效数字与原文一致，不做无依据换算；换算时写清换算公式。
- 误差棒含义（SD / SE / CI / IQR）必须从图注或方法中确认；图注未说明时在
  uncertainty 标注“误差棒含义未说明”。
- 多面板图按“Fig 2A / 2B / 2C”编号逐面板引用；补充材料写“Fig S1”。
- 显著性记号（*、**、ns）在正文首现处解释，并与图注一致。
- 统计量写法：`(t(38)=2.41, p=0.021)`、`(χ²(1)=5.2, p=0.023)`、`(r=0.61,
  p<0.001)`；只写材料中出现过的值。

## 7. 证据溯源规则（逐条）

每条关键结论/数值/引用写入 `facts_sources`，字段：

```json
{"claim": "……正文中的论断……",
 "locator": "materials/table2.md#L12-L15 或 figures/fig2.txt#Fig 2",
 "quote": "材料中逐字原文片段",
 "kind": "observed|statistic|reference|interpretation",
 "status": "verified|unverified|pending_human|not_reported"}
```

- `quote` 用 `scripts/main.py quote --file … --locator …` 提取逐字原文，不凭记忆。
- 冲突信息不隐藏：同一指标两个来源不一致时两条都记，标 `source_conflict`。
- 引用无法核实：保留原文位置并标 `unverified`，不伪造 DOI/URL。

## 8. 写作后自检清单（逐条勾选）

- [ ] 结果段无“导致/表明机制/原因/推测”类解释性句子。
- [ ] 讨论段每个论断对应本研究数据或具体文献，无只堆引用不讲关系。
- [ ] 每个数值/统计量可回溯到图/表/统计输出（facts_sources 有 locator+quote）。
- [ ] 趋势/差异措辞与显著性一致；未达显著处明确写“未达统计学显著”。
- [ ] 因果表述已区分相关/预测/因果，机制推测已标“推测”。
- [ ] 局限落到方法/样本/测量/统计层面，并说明对结论的影响。
- [ ] 阴性结果与不一致文献已如实交代。
- [ ] 全文无“首次/国际领先/填补空白/颠覆性”等无据措辞。
- [ ] 已完成（观察事实）与拟解释（推测）不混写。
- [ ] result.json 的 case_id、status、sources、uncertainty、pending_human、
      change_log 与真实执行一致。
