# 章节稿结构模板（deliverable 的规范骨架）

本模板只规定**结构与会话标记**，正文内容必须来自实际读到的材料；空白处不预填任何数值
或结论。运行时以 case.json 指定的体裁、受众、语言与格式为准，本文件提供默认结构。

## 1. deliverable 文件名与格式

- 默认 `manuscript.md`；case.json 指定文件名/格式（.docx/.tex 等）时以 case.json 为准。
- 结果与讨论是**可编辑正文**：段落连续书写，不为凑结构而列表化。
- 需要双语时按 case.json 给双栏或顺序双语；引用格式按 case.json，未指定则保持材料原文样式。

## 2. 角色标记（写入草稿、交付前删除）

自检用的非输出标记，帮助强制“结果不解释、讨论不堆结果”：

- `[R]` 结果段：只写方向、幅度、显著性、组间比较、阴性结果。
- `[D]` 讨论段：解释、机制、文献对照、局限。
- 交付前把 `[R]`/`[D]` 前缀删除，只留正文。

## 3. 结果段（Results）默认组织

按“图序”或“问题”二选一，不混用；每个小节首句给观察，不解释：

```
## Results
### 3.1 [研究对象/基线描述]
### 3.2 [主要结局，按图1→图2 顺序]
### 3.3 [次要结局/亚组，仅在高剂量组出现…]
### 3.4 [阴性结果，如实报告“未达显著（p=…）”]
```

## 4. 讨论段（Discussion）默认组织

```
## Discussion
### 4.1 主要发现摘要（对应本研究数据，给 locator）
### 4.2 与文献一致/不一致及可能原因（每条引文给 locator 或 unverified）
### 4.3 机制推测（标“可能/推测”，与设计强度一致）
### 4.4 局限（按方法/样本/测量/统计四层写具体项）
```

## 5. 局限四层（禁止空泛）

- 方法层：测量手段、试剂/设备、建模假设。
- 样本层：n、纳入排除、随访/时间点、代表人群。
- 测量层：误差棒含义、单位、缺失值、多面板读数不确定性。
- 统计层：多重比较、检验前提、效应量、未达显著即写“未达显著”。

## 6. 交付前一致性核对顺序

1. 结果段每个数字 → 图表事实清单 → 原文 quote 三者一致。
2. 讨论段每条论断 → 本研究数据 locator 或文献 locator/unverified。
3. 趋势/差异方向与幅度 → 与 p、n、误差类型一致。
4. 局限 → 四层具体项，不是“样本量小”空话。
5. 禁词扫描 `core_impl.forbid_scan` 零命中，或有据保留并给 locator+quote。
