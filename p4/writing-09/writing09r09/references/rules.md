# 四查规则、语气分级与降级/核验规则

本文件是 `SKILL.md` 的补充细则，Agent 写结果与讨论章节时逐条执行；运行时以 case.json 的具体约束为准。

## 1. 四查（核心流程，读图→列发现→写结果→核证据→写讨论）

1. **读得准**：正文中的数值、单位、有效数字、误差棒含义（SD/SEM/CI）、坐标刻度、面板编号与统计量，
   必须来自材料原文（图、表、图注、统计输出）。单位换算在 facts_sources 记原始值与换算结果；
   读不清就标 `unverified` 并写 pending_human，禁止猜。
2. **分得清**：结果段只陈述“观察到的事实”（方向、幅度、显著性、组间比较），不写解释、机制、因果、文献评价；
   讨论段承担解释、文献对照（一致/不一致及可能原因）、局限。
3. **说得住**：语气与证据强度匹配——
   - 有统计检验（p 值/CI）→ 可写“显著/无显著差异”，并附检验量与 p 值；
   - 只有方向或数值趋势、未达显著 → 写“数值上偏高/呈增加趋势（未达显著）”，不得写“显著”；
   - 仅个别组/亚组出现 → 写“仅在……组观察到”，不得泛化为全体结论；
   - 相关/回归/预测 ≠ 因果：写“相关”“预测”或“与……相关”，机制表述必须加“可能/推测/有待验证”。
4. **核得了**：每个数值回溯到图/表/统计输出，每条论断对应到具体文献或本研究数据；
   facts_sources 逐条带 `locator`（文件+页码/段落/图号）与 `quote`（逐字原文）；无法核实标 `unverified`。

## 2. 语气分级（写正文时对照）

| 证据 | 允许表述 | 禁止表述 |
|---|---|---|
| 有 p 值/CI 的组间检验 | 显著升高/降低（p=…，检验名） | — |
| 方向一致但未达显著 | 呈…趋势（未达显著） | 显著改变、明显改善 |
| 单组/单剂量出现 | 仅在…组观察到 | 普遍存在、各组均 |
| 相关/回归 | 与…相关（r/β=…） | 导致、引起、证明因果 |
| 机制推测 | 可能通过…，有待进一步验证 | 证实机制为… |

## 3. 已完成 vs 拟开展（材料来源标记）

- “材料内事实”：材料原文直接给出的数值/结论 → 事实陈述，来源为原文 locator+quote。
- “推断”：由材料推论但原文未直接写 → 单独标注“推断”，写入 uncertainty 或 version_boundaries，
  不并入事实陈述。
- 本研究数据（Results）与文献对照（Discussion）分开记录：前者来源为图表/统计输出，后者来源为参考文献。

## 4. 降级规则（禁止编造）

| 场景 | 处置 |
|---|---|
| 材料缺失/字段不明 | uncertainty 或 version_boundaries 标“缺失/无法判断”，字段留空或 null，不补造数值/文献/作者/单位 |
| 图表读数不清、单位不明 | 标 `unverified`，写 pending_human，不猜 |
| 引用无法核实 | 保留原文位置并标 `unverified`，不伪造 DOI/URL |
| 同一指标两个来源冲突 | 两个都记录并标 `source_conflict`，正文采用时说明依据 |
| 软件/工具不可用（无 pdf-text-tool/office 渲染） | 如实写 degradations，交付纯文本/结构化产物，不假装已渲染 |
| 输入超长/跨度大 | 截取关键段落，uncertainty 说明“已截断/未覆盖” |
| 运行失败 | status=failed，change_log 记失败原因与已完成中间产物，result.json 仍落盘 |

## 5. 结果与讨论边界（分得清 细则）

- 结果段句式：主语 + 观察动词 + 数据（数值、单位、误差、统计量）。示例：“A 组存活率高于 B 组（82% vs 61%，p=0.012）。”
- 讨论段句式：解释动词 + 依据（本研究数据或文献）+ 限定词。示例：“该差异可能与剂量相关，与既往报道一致[ref]，但样本量有限，尚不能排除混杂。”
- 以下内容只进讨论、不进结果：与既往文献的对比评价、可能机制、临床/政策含义、方法/样本/测量/统计局限。

## 6. 自检要点（与 SKILL.md 清单对应，check 脚本自动化部分）

- 结构：case_id + 全部 output_contract 字段 + status/sources/uncertainty/pending_human/change_log。
- 禁词：无“首次/国际领先/填补空白/颠覆性/革命性/首创”等无据措辞（脚本扫描）。
- 溯源：facts_sources 每条有 locator + quote（脚本扫描缺口）。
- 语气：结果段出现“导致/机制/证实”等结论词时，确认有统计支撑或已移入讨论（脚本扫描标记）。
