# 六类分面审查清单与判据

本文档是分面审查（fact_check / citation_support / method_design / statistics_report / argument_chain / academic_norms）的判定锚点。目的不是给出一份"万能答案"，而是把每条 finding 的 facet、severity、issue_type 与判断依据固定下来，减少误报并保证可复核。

## 0. 通用原则

- 每条 finding 必须给出**原文定位（locator）+ 逐字 quote**；quote 由 `scripts/main.py check` 与原文逐字比对，不能改写、不能凭记忆。
- 区分四类 issue_type：`factual_error`（可证伪的事实/数值/引用错误）、`insufficient_evidence`（报告或材料缺失，无法支持论断）、`standards_issue`（不符合学术/报告规范）、`suggestion`（可改进但非缺陷）。数值/来源冲突另用 `source_conflict`。
- 不确定的一律 `verdict=to_review`，绝不 `confirmed`；只有证据明确时才 `confirmed`。
- 主观判断必须写明**可接受范围**与不确定性，不能把学科写作惯例、期刊格式差异、作者的有意取舍误判为缺陷。

## 1. fact_check（事实核验）

检查锚点：

- 摘要、正文、图表中的数值是否一致（同一指标在摘要/正文/图表出现两处及以上时逐一比对）。
- 术语与定义前后是否统一（同一概念是否换了名称、含义是否漂移）。
- 可查证的外部事实（年份、机构、药物、公式、公认常数、历史事实）是否与常识/来源一致。

判据与抑制误报：

- 仅当两处数值或陈述直接冲突时，记 `source_conflict` 并**两处都记录**，不擅自取舍。
- 无法核验外部事实且无来源时，记 `citation_support` 或 `unchecked_items`，不要臆断为 `factual_error`。
- 学科惯例（如单位写法、缩写）不记缺陷，除非明显错误。

## 2. citation_support（引用支持）

检查锚点：

- 正文论断与所引文献主张是否对应；引用编号/作者/年份是否指向正确条目。
- 被引文献主张是否足以支持"本文论断"（例如引文只报告相关性，正文却写"证明因果"）。
- 参考文献是否缺失、编号是否断链、是否存在"该引未引"或"引而未列"。

判据与抑制误报：

- 每条关键引用问题必须列出**本文论断**与**被引文献主张**的对应关系，不能只说"引用不支持"。
- 参考文献缺失/无法获取原文时，把该面列为 `not_checked`，注明"无法核验"，不臆断被引文献内容。
- 引用风格差异（APA/GB/T/期刊模板）不记 `standards_issue`，除非与目标期刊要求明确冲突。

## 3. method_design（方法设计）

检查锚点：

- 对照设置：是否有对照/比较组，缺失时是"方法缺陷"还是"报告不全"。
- 样本量与抽样方式：是否说明样本量、纳入排除标准、抽样/招募方式、是否报告统计功效。
- 评价指标与测量：指标选择是否合理，测量工具/剂量/时间点是否完整。
- 重复与随机化：是否说明随机化、盲法、重复次数。

判据与抑制误报：

- 区分 `method_design`（方法本身缺陷）与 `statistics_report`（方法可接受但统计量报告不全）。
- "该领域常用但未报告"属于报告不全（`insufficient_evidence`），不臆断为方法错误。
- 探索性研究的灵活分析（事后分析）记 `argument_chain`（结论外推）而非 `method_design`，除非方法本身错误。

## 4. statistics_report（统计报告）

检查锚点：

- 显著性：是否报告 p 值/置信区间/效应量；"显著"是否给出了对应统计量。
- 误差与不确定度：是否报告 SD/SE/CI、测量误差、重复次数。
- 多重比较与模型假设：是否说明校正方法、检验方法、分布假设。
- 单位与有效数字：是否遗漏单位、位数是否与测量精度匹配。

判据与抑制误报：

- "只报 p 值不报效应量/CI"通常是 `standards_issue` 或 `insufficient_evidence`，不是 `factual_error`。
- 缺失某个量（如没报 SD）→ `insufficient_evidence`，并写明"缺了哪个量"。
- 统计方法选择本身是否恰当若可判断，归 `method_design`；报告格式问题归 `statistics_report`。

## 5. argument_chain（论证链）

检查锚点：

- 从假设到结论的推理路径是否完整；定位缺失环节。
- 循环论证、因果与相关混淆（correlation vs causation）。
- 结论外推是否超出数据范围（样本、动物模型、人群、时间尺度）。

判据与抑制误报：

- 定位"哪一步断了"，而不是泛泛说"逻辑不严密"。
- 因果主张没有设计支持（无对照/无纵向/无干预）→ `argument_chain` + `insufficient_evidence`。
- 合理的限制声明（limitations）不记缺陷；只有未声明的外推才记。

## 6. academic_norms（学术规范与可发表性）

检查锚点：

- 数据可用性声明、代码/材料共享声明。
- 伦理与利益冲突声明、知情同意、动物伦理。
- 图表版权与来源、已发表图表的授权。
- 术语、单位、格式是否符合目标期刊要求。

判据与抑制误报：

- 把"规范问题"与"实质问题"分开呈现；纯格式问题给 `minor`/`suggestion`。
- 无目标期刊信息时，格式类问题降级为 `suggestion` 或列入 `unchecked_items`，不臆断期刊要求。
- 声明缺失但材料为预印本/草稿时，注明"可能因版本所致"，给 `to_review`。

## 严重度（severity）判据

- `critical`：结论被证伪、数据造假、致命方法错误或明显学术不端。
- `major`：影响主要结论可信度的问题（缺对照、样本量缺失、关键引用错配、论证断链）。
- `minor`：不影响主要结论，但需修正（单位缺失、术语漂移、声明不全）。
- `suggestion`：可改进但非缺陷（补充报告、改进图注、增加说明）。

> 无法确认严重度时，宁可降一档并 `to_review`，不升级为 `critical`。

## 置信度（confidence）判据

- `high`：quote 逐字命中、判据与学科常识/写作规范一致、无冲突来源。
- `medium`：quote 命中但判据依赖单一来源或领域惯例判断。
- `low`：材料歧义、信息缺失或依赖外推，必须 `to_review`。

## 误报抑制总则

1. 只有"具体、可定位、可复核"的证据才记 finding；泛泛的印象不记。
2. 学科写作惯例、期刊格式差异、作者有意取舍不作为缺陷。
3. 冲突信息两个都记录（`source_conflict`），不掩盖、不取舍。
4. 缺数据/缺软件/缺来源如实写 `unchecked_items` 与 `degradations`，不编造。
