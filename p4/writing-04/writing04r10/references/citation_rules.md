# 语义判断与核验规则（Agent 依据）

脚本只完成确定性部分；本文档规定 Agent 必须手工完成的语义判断与回写格式。所有结论必须写入 `evidence_map.json` 与 `change_log`，并带 locator + 逐字 quote。

## 1. 论断句定位（挂得对）

- 逐段读稿件，切分为论断句（claim）：含数字/百分比、比较词（显著、高于、提升、下降、表明、显示、证实）、或已有引用标记的句子。
- 引用应插到**真正需要来源支撑的那句话末尾**（标点前），不是整段末尾或图表注附近。
- 一句多引：按“并列证据”原则在同一处写 `[a,b]`；多句一引：只在首个论断句落引用，后续句不再重复。
- 引用形式由 `case.json` 的 `target_style` 决定：顺序编码制用 `[n]`；著者—出版年制用 `(Author, Year)`；脚注按任务要求。

## 2. claim ↔ 文献匹配（对得上）

- 每条引用必须映射到文献库中的真实条目；依据是正文论断与文献**主题、结论、方法、数据**的对应，而不是只看年份或作者同名。
- 匹配依据（match_basis）至少写一条可复核理由，例如“文献报告同类 34% 提升，与论断数值一致”。
- 同名不同文献、同作者同年多篇：不得自动合并/不得误匹配，标 `source_conflict` 或 `pending_human`。
- 无法确认的条目：`status = not_verified`，写 `pending_human`；绝不虚构 DOI、卷期页或结论。

## 3. 去重判据（收得净）

- 脚本已按两级判据合并：**DOI 一致**，或**规范化题名 + 第一作者 + 年份**一致（题名缺失则不合并）。
- 规范化规则：去 LaTeX 命令与花括号、转小写、去标点与多余空白；DOI 去前缀 `https://doi.org/`、去尾点、转小写。
- 合并依据写入 `merge_evidence`，含 criterion、保留条目、被合并条目；人工复核时关注“预印本 vs 正式版”应保留正式版（有卷期页/DOI 者优先）。
- 判据不足（只有作者+年份、题名缺失）：**不自动合并**，标 `pending_human`。

## 4. 编号重排（编得顺）

- 脚本按“首次出现顺序”重排正文编号，并经“原索引→幸存索引”映射（去重后不悬空）。
- 复核点：正文标记连续且从 1 开始；文末列表顺序与正文首次出现一致；交叉引用与图表注同步；上标样式统一。
- 异常（编号跳号、正文引用超出原始文献库大小）由 `consistency_report.json` 列出，Agent 判定并回写处置。

## 5. 格式转换（GB/T 7714—2015 / APA）

- 目标规范由 `case.json` 的 `target_style`（缺省 `gbt7714`）决定；脚本支持 `--style gbt7714|apa`。
- 保留关键字段：DOI、卷、期、页、文献类型标识；中英文混排按目标规范处理标点。
- 字段缺失：保留可确认部分，缺失字段不补造；记 `not_reported`。

## 6. 来源核验

- 元数据只来自输入材料；DOI/数据库检索用于**核验**而非补造，失败即标 `not_verified`。
- 冲突信息不隐藏：同一指标两个来源不一致时，两条都记录并标 `source_conflict`。
- 每个关键结论/数值/引用必须能回溯到材料中的逐字片段（locator + quote），写入 `evidence_map.json`。

## 7. 诚实回写

- `status`：`ok` 仅在语义核验全部完成后设置；否则 `partial`；材料不足为 `insufficient_evidence`；输入不可解析为 `input_error`。
- `pending_human`：列出所有需要人工确认的缺口，不静默跳过。
- 严禁编造评测分数、DOI、元数据、检索结果或实验数据。
