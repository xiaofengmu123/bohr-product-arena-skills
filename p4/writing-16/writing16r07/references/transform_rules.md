# 科研成果转化写作：改写规则与证据强度

本文定义 Skill 的核心方法，供 Agent 在改写时逐条执行。规则围绕题面四个要求：
**读得懂、留得住、说得准、接得住**。

## 1. 受众适配（读得懂）

| 受众 | 术语密度 | 缩写处理 | 类比/例子 | 默认篇幅取向 |
|---|---|---|---|---|
| 同行专家 | 高，保留领域术语 | 首次展开即可 | 少 | 依题目 |
| 跨学科研究者 | 中，首次出现即定义 | 必须首次展开 | 1–2 个 | 依题目 |
| 管理者/资助方 | 低，只保留结论性术语 | 展开或改述 | 强调价值与成本 | 更短 |
| 公众/科普 | 低，行话改述 | 禁用或首次展开+解释 | 必用生活化类比 | 更短 |

- 未展开的缩写、未解释的公式、领域行话必须处理：首次出现 `全称（缩写）`，公式给出文字含义。
- 解释深度与篇幅以题目给定约束为准；题目未说明时，按"读者不加背景知识能读懂"执行。

## 2. 内容取舍（留得住）

改写前先把源文信息分三级，写入 `facts_sources`：

1. **必须保留（MUST）**：关键结论、数值与单位、比较基准、样本量、统计口径、限定条件、方法要点、图表引用、引用来源。
2. **可压缩（MAY-COMPRESS）**：方法细节的展开、背景铺垫、重复表述。
3. **可删除（MAY-DELETE）**：与目标读者无关的冗余、明显重复的句子、已在前文说明的过渡。

删掉的是冗余，不是证据。任何被删的关键项都要进入 `change_log` 并说明理由。

## 3. 科学事实与数据（留得住 + 说得准）

- 数值、单位、小数位、比较基准、样本量、统计口径、图表编号、引用编号**逐字照抄**，不得改写、不得四舍五入后冒充原值。
- 限定语（"在 X 条件下"、"n=…"、"p=…"、"初步"、"提示"）必须随结论一起保留。
- 图表引用保留原编号；若源文编号与目标体裁冲突，保留原编号并在 `change_log` 说明。

## 4. 论断强度分级（说得准）

| 源文表述 | 强度 | 改写时保留的最低表述 |
|---|---|---|
| 证实 / 表明 / 证明 | 强 | 表明 |
| 提示 / 初步表明 / 可能 | 弱 | 提示（不得升为"表明"） |
| 相关 / 关联 | 相关 | 相关（不得写成因果） |
| 导致 / 因果 | 因果 | 导致（不得降为无关） |

- 不把相关写成因果、不把初步结果写成定论、不新增源文没有支持的结论。
- 源文无结论只有数据时，只描述数据，不做因果推断。
- 同一概念全文只保留一个说法（见术语锁定）。

## 5. 术语锁定（读得懂 + 说得准）

- 先建立术语表：每个核心概念定一个**唯一主名**，同义词收敛到主名。
- 缩写首次展开，之后全文统一。
- 跨文体替换术语时，替换后必须与原术语保持同一指称，并在 `facts_sources` 记录 `term` 映射。

## 6. 文体结构映射（接得住）

| 体裁 | 必备结构要素 |
|---|---|
| 论文 | 标题、摘要、引言、方法、结果、讨论、结论、参考文献 |
| 技术报告 | 标题、摘要、背景、方法、结果、结论、风险/限制 |
| 项目申报 | 背景与意义、研究目标、内容与方案、创新点、预期成果、进度 |
| 科普文章 | 标题、导语、主体（结论先行）、方法通俗化、一句话来源 |

- 简化表达只针对表述方式，不得删除结论必需的限定语。
- 任何体裁转换后，结构要素与论断强度都要与原体裁一一对应。

## 7. 证据溯源与待确认

- 每条 `facts_sources` 条目格式：`{"fact", "locator", "quote", "type", "confidence"}`。
  - `locator` 用 `materials/<file>#段号` 或源文页码；`quote` 为源文逐字片段。
- 两个来源数值冲突时，都记录并标 `source_conflict`，改写稿选一个并在 `version_boundary.conflicts` 说明。
- 缺失、未报告、无法判断的项写入 `version_boundary.gaps` 或 `pending_human`，用 `not_reported` / `pending_human` 标注，**不编造**。
