# 体裁与受众画像（genre profiles）

本文件给出四类高频转化任务的读者画像、解释深度、取舍规则与篇幅建议。用于快速确定“写给谁、留什么、删什么”。实际案例以输入文件中的约束为准，本文件只作默认参考，不覆盖输入约束。

## 1. 科普短文（论文摘要/技术报告 → 公众文章）

- 读者画像：非本领域、无术语背景、阅读目的是“快速知道是什么、为什么重要、有何限制”。
- 解释深度：先结论后细节；每个领域术语首次出现即用日常语言解释；公式只保留必须的并文字说明其含义。
- 术语密度：极低；缩写全部展开，专业名词配类比或一句话定义。
- 必须保留：核心结论、样本量/人群、关键效应量（翻译成可理解比例）、主要限制、来源可追溯的“依据是什么”。
- 可压缩：方法细节、敏感性分析、逐项统计检验、讨论中的次级论点。
- 论断强度：相关不写成因果；初步结果必须保留“初步/有限”限定语。
- 篇幅：依题面篇幅上限；超限时删“次级论点与次要方法”，不删证据。

## 2. 项目申报材料（论文/技术报告 → 申报书）

- 读者画像：评审专家/资助方，熟悉领域但关心“创新点、可行性、意义、风险”。
- 解释深度：保留学科精确术语，但对创新点给出“现有方法不足 → 本方案如何解决”的显式桥接。
- 术语密度：中等；缩写首次展开即可，同义词必须收敛到一个写法。
- 必须保留：问题与缺口、方法创新点、关键技术指标、可行性证据、与现有工作的边界。
- 可压缩：纯综述性铺陈、与立项论证无关的实验细节。
- 论断强度：不得把“初步结果表明可行”写成“已经解决”；风险与不确定性如实写入。
- 篇幅：按申报模板分节；每节结论前置，删除重复论证。

## 3. 技术报告（论文 → 报告）

- 读者画像：项目组/上下游协作者，需要“可复现、可交接、可审计”。
- 解释深度：完整保留方法、参数、口径；增加“结论—依据—限制”三段式小结。
- 术语密度：高；建立术语表锁定写法，图表编号与正文引用一一对应。
- 必须保留：数据来源、样本量、指标口径、图表编号、引用、假设与限制。
- 可压缩：背景铺陈、与任务无关的讨论。
- 论断强度：逐条标注证据强度；未验证项单列“待确认”。

## 4. 论文摘要/结构化写作（材料 → 摘要或章节）

- 读者画像：同行评审者，要求信息密度与严谨性。
- 解释深度：不额外科普；保留学科标准术语与引用编号。
- 术语密度：高；同一概念全文一个说法，缩写首次展开。
- 必须保留：目标、方法要点、主要结果（含数值与统计口径）、结论与限定。
- 可压缩：重复论证、示例性罗列。
- 论断强度：严格对应源文证据等级；不新增引用，不扩大结论范围。

## 通用取舍优先级（删改时按序执行）

1. 保留：关键结论、数值/单位、样本量、统计口径、图表编号、引用、限定条件。
2. 压缩：方法细节、次级论点、重复论证、背景铺陈。
3. 删除：冗余（与证据无关的修辞、重复句）、超出目标读者需求的次要信息。
4. 永远不做：为凑篇幅删掉证据；为可读性补造源文没有的事实；把相关写成因果。
