# 体裁 / 受众 / 术语与论断强度规则

本文件是改写时的硬规则，供 Agent 在"受众画像 → 取舍策略 → 边界标注 → 多文体映射"链条中逐条套用。所有条目最终都要落到 `result.json` 的 `evidence_map`、`change_log` 与 `uncertainty`。

## 1. 受众画像（读得懂）

改写前先判定并写清以下四点，缺一就记入 `pending_human`：

1. 知识背景：外行 / 相关学科 / 同领域专家。
2. 阅读目的：获取结论 / 用于决策 / 学习背景 / 复核证据。
3. 信息需求：要结论还是方法、要数字还是原理。
4. 允许的解释手段：类比、示例、背景段落；但类比不改变结论方向。

术语密度随读者下调；**每个缩写首次出现必须展开**（中文稿给中文全称+英文全称+缩写），之后全篇锁定同一写法。

## 2. 内容取舍（留得住）

- **必须保留**：关键结论、全部数值与单位、比较基准、样本量、统计口径、方法要点、图表编号与引用、限定条件。
- **可压缩**：过程性叙述、重复举例、与结论无关的背景铺陈。
- **可删除**：纯冗余、口头语、对结论无贡献的修饰；**删除的理由必须写进 `change_log`**。
- 压缩时先检查：删掉的句子是否含有任何证据（数字、引用、限定语）；有则不可删，只能改写表达。

## 3. 事实与数据（说得准）

- 数值、单位、小数位、百分比、区间、样本量（n/N）逐字核对，不得四舍五入、不得换算单位后改变口径。
- 比较类表述必须保留比较基准（"较对照组提高 12%" 而非 "提高 12%"）。
- 图表引用保留原编号（"见图 2"、"如表 1"），不重编号；无编号则用描述性定位。
- 引用（`[n]`、`(Author, Year)`、DOI）逐条核对；源文没有的引用**绝不补造**，缺失记 `not_reported`。

## 4. 论断强度阶梯（用词随证据）

| 源文证据 | 允许用词 | 禁用用词 |
|-|-|-|
| 已证实的结论 | 表明、证实、显示 | 无需降级 |
| 观察/回归结果 | 显示、提示 | 证实、证明 |
| 初步结果/小样本 | 初步表明、有待验证 | 表明、证实 |
| 推测/展望 | 有望、可能、或可 | 将、已 |
| 相关关系 | 相关、与…有关 | 导致、使（因果） |

把"相关"写成"因果"、把"初步"写成"定论"都是硬错误；改写后必须用 `evidence_map` 逐条标 `claim` 与 `status`。

## 5. 术语锁定与跨文体映射

- 建立术语表：源文术语 → 全称 → 目标文体用词 → 缩写形式；同一概念全文只用一个说法。
- 同义词收敛：把近义表达归并到主术语，避免同一概念前后三种写法。
- 跨文体替换只在"解释层"进行（用通俗语解释），**不在"证据层"替换**（数值、单位、结论保留原口径）。
- 中英双语稿：术语对应表逐条记录，中文译名首次给出原文；不自行发明译名，无把握记 `pending_human`。

## 6. 多文体映射（接得住）

论文 → 科普：结论前置、背景后移、公式转为文字、行话替换为通俗解释，保留所有限定语。
论文/报告 → 申报材料：突出意义与应用、保留方法与可行性证据，不夸大成果。
通用原则：结构要素（问题/方法/结果/结论/限制）与论断强度逐层对应，任何简化的结论都不得越过源文强度。
