# 改写规则与映射表

本文件是 SKILL.md 的复用资源，供 Agent 在 P1–P2 阶段直接套用。所有“保留/压缩/删除”判断都要以源文逐字片段为据。

## 1. 内容取舍：保留优先级（自上而下，先保上面的）

| 优先级 | 内容 | 处理 |
|-|-|-|
| P0 必保留 | 结论、方向、数值、单位、样本量、统计口径、置信区间/显著性、比较基准、图表编号、文献引用、限定条件（人群/时间/适用范围/未发表/预印本） | 原样或等价改写，不得省略 |
| P1 应保留 | 方法要点、主要结果的支撑数据、图表的文字说明、作者自陈的局限 | 可压缩表达，不可删除 |
| P2 可压缩 | 背景铺垫、方法细节重复、例证、可合并的同义句 | 删掉冗余措辞，保留证据 |
| P3 可删除 | 与目标读者无关的次要旁支、纯客套、重复引用同一事实 | 在改动清单标注“已删除+理由” |

删改的判定词：“删除”指移除整句；“压缩”指保留关键数字但缩短；“等价改写”指换文体但信息量不变。三者都要进 `change_record`。

## 2. 论断强度分级（说得准）

源文强度词 → 改写时允许的强度词，**不得向上越级**：

| 源文 | 允许改写为 |
|-|-|
| 证实 / established / demonstrated | 表明、证实 |
| 表明 / indicate / show | 表明、提示（不能写“证实”） |
| 提示 / suggest / 初步表明 | 提示、初步表明、可能（不能写“表明/证实”） |
| 可能 / may / might / likely | 可能、或许、尚不确定 |
| 相关 / associated / correlation | 相关、关联（**禁止写“导致/因果”**） |
| 因果 / causal / cause | 因果、导致（源文无因果证据时不得使用） |

规则：相关≠因果；初步≠定论；外推≠源文结论；同一概念全文只用一个说法。凡是源文没有支持的新结论，必须删除或标 `not_reported`。

## 3. 术语锁定（说得准 / 术语一致）

- 缩写首次出现写 `全称(缩写)`，之后只写缩写；跨章节复用同一展开。
- 同义词收敛：先定一个主词，全稿一致（例：均选择“患者”或“受试者”之一，“疗效”或“有效性”之一）。
- 跨文体替换只允许换表达层级，不允许换数值/口径：
  - 论文→科普：`p<0.001` 可写“差异有统计学意义”，但保留 p 值本身；
  - 技术报告→申报材料：保留指标口径与样本量，可加一句业务意义。
- `terms.json` 的 `abbreviations` 表必须逐条写进 `evidence_map.json`，并在成稿后核对。

## 4. 文体映射（结构要素与论据边界）

| 要素 | 论文 | 技术报告 | 项目申报 | 科普文章 |
|-|-|-|-|-|
| 背景 | 研究缺口 | 问题背景 | 需求与政策 | 现象与常识 |
| 方法 | 详细方法学 | 方案与指标 | 技术路线 | 比喻/通俗解释 |
| 结果 | 数据+统计 | 数据+分析 | 里程碑+成果 | 关键数字+故事 |
| 结论 | 谨慎限定 | 建议 | 预期价值 | 意义与边界 |
| 引用 | 编号引用 | 编号/脚注 | 支撑依据 | 少而必要 |

跨文体转换时“结构要素”对应，“论断强度”不变：结论限定语、样本信息、统计口径、图表引用在四类文体中都必须保留。

## 5. 证据映射条目格式（evidence_map.json 每条）

```json
{"fact": "被改写的事实/数字/术语/引用",
 "locator": "materials/<file>#L<行> 或 #P<段>",
 "quote": "源文逐字片段（不超过 300 字）",
 "kind": "number|statistic|figure_table_eq|citation|abbreviation|claim",
 "action": "kept|compressed|reworded|deleted|added_context",
 "status": "verified|source_conflict|pending_human|not_reported"}
```

`status=added_context` 仅用于“背景解释/类比”，不得新增源文外的事实性结论；新增事实一律不允许，除非显式标 `not_reported` 并放入 `pending_human`。
