# 科研成果转化写作方法（可复用规则）

本文是 SKILL.md 的执行细则，供 Agent 改写时逐条对照，也可被他人复用于同类任务。

## 1. 受众画像（改写前必填）

先写四行，再动笔：

- 读者背景：目标读者已有知识（如“临床医生 / 无医学背景公众 / 项目评审专家”）。
- 阅读目的：想知道结论 / 想评估可行性 / 想转述给他人。
- 术语密度：允许的缩写数与未展开行话上限。
- 篇幅与格式：字数上限、结构要素、可编辑格式（md/docx/pptx）。

判定标准：目标读者在不补充背景知识下能读懂，且不丢失证据。

## 2. 内容取舍优先级

| 等级 | 内容 | 动作 |
|---|---|---|
| 必须保留 | 关键结论、数值与单位、样本量与统计口径、图表编号、引用、限定条件 | 逐字核对，不简化掉 |
| 可以压缩 | 方法细节、推导过程、背景铺陈 | 合并改写，保留口径 |
| 可以删除 | 冗余重复、与结论无关的修辞 | 删除并记入 change_log |

压缩原则：优先保证据，其次保可读性；绝不为了“顺”而删掉样本量、置信区间或“相关/因果”的限定语。

## 3. 论断强度分级

同一句话按源文证据强度定调，跨文体转换不得升级：

- 相关 / associated / 关联 → 只能写“相关/关联”，不得写“导致/提高”。
- 提示 / suggest / 初步 / preliminary → 只能写“提示/初步显示”，不得写“证实/证明”。
- 表明 / 证实 / demonstrate / confirm → 源文明确时才可用“证实/表明”。
- 可能 / may / might → 保留“可能”，不得删除。

源文无支持的结论一律删除，或转 `pending_human`，不得新增材料外事实。

## 4. 体裁结构映射

| 体裁 | 必备结构要素 | 备注 |
|---|---|---|
| 科普文章 | 一句话结论→背景→关键发现与数据→边界与限定→术语说明→来源 | 展开缩写，用类比解释，保留数据 |
| 项目申报 | 立项依据→研究内容与目标→技术路线与创新点→预期成果与指标→工作基础 | 创新点须与源文证据一致 |
| 简报 | 核心结论(1–3条)→关键数据→边界与不确定性→行动建议(若有依据)→来源 | 结论前置，限定语保留 |
| 双语摘要 | 目的→方法→结果→结论（中英各一份） | 数字与口径中英一致，缩写各自首次展开 |
| 技术报告 | 摘要→背景→方法→结果→讨论→结论→引用 | 图表编号与源文一致 |
| 新闻稿 | 导语→关键数据→意义→边界→来源/引用 | 禁把相关写成因果 |

## 5. 术语锁定

- 缩写首次出现必须展开：如“磁共振成像（MRI）”，此后统一用 MRI。
- 同义表达收敛到唯一 canonical 说法，跨段落、跨产出一致。
- 术语表字段：canonical / abbr / expansion / variants / first_use。

## 6. 证据映射与改动清单格式

证据映射每项至少包含：

```json
{"type": "number|citation|figure_ref|term|claim",
 "quote": "源文逐字片段", "locator": "材料路径#L行号", "context": "所在句"}
```

改动清单每项至少包含：

```json
{"locator": "deliverable.md 位置或源文定位",
 "before": "原文/原句", "after": "改后", "reason": "删冗余/术语统一/强度对齐/格式"}
```

## 7. 冲突与缺口标注

- 同一指标两处来源不一致：两处都记录并标 `source_conflict`，不改写为单一事实。
- 缺样本量/缺置信区间/缺引用：写入 `uncertainty` 与 `pending_human`，不补造。
- 材料涉密或未发表：写入 `limitations`，优先给合规最小产物。
