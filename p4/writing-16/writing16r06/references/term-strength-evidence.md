# 术语锁定、论断强度与证据映射规则

这是把科研源材料转写成面向特定读者的稿件时，Agent 必须遵守的可复核规则。
目标四项：**读得懂、留得住、说得准、接得住**。

## 1. 术语锁定（说得准 / 留得住）

- 同一概念全文只保留一种说法；首次出现时给出规范写法，后续不得换同义词。
- 缩写首次出现必须展开为「全称（缩写）」，之后只用缩写；未在源文展开的缩写不得臆造全称。
- 面向非专业读者时，术语替换为通俗表述，但必须保留一个术语表条目：
  `术语 | 源文表述 | 目标稿表述 | 替换理由 | 是否保留限定语`。
- 术语表写入 `work/term_table.json`，并在 `result.json` 的 `term_table` 字段引用。

## 2. 论断强度分级（说得准）

| 源文证据 | 目标稿用词 | 是否允许简化 |
|---|---|---|
| 已证实（实验复现/显著结果） | 表明 / 证实 / 显示 | 可省细节，不省结论 |
| 初步/探索性 | 初步表明 / 提示 / 或可 | 必须保留"初步" |
| 相关/关联 | 相关 / 有关联 | 严禁改写成因果 |
| 假设/模型推测 | 推测 / 假设 / 有待验证 | 必须保留限定语 |
| 源文未提及 | 不写 | 不得新增结论 |

- 升级或降级论断强度都属于事实漂移，必须写进 `change_log` 并标注理由。
- 数字、单位、比较基准、样本量、统计口径、图表编号**逐字核验**，不允许四舍五入或"约等于"。

## 3. 必须保留项（留得住）

按优先级锁定，压缩时先删低优先级：

1. 关键结论与限定条件
2. 数据、单位、样本量、统计口径、图表编号、引用
3. 方法要点（能解释结论为何成立的最小集合）
4. 背景与动机
5. 冗余解释、重复举例（可删）

## 4. 证据映射格式（接得住）

`work/evidence_map.json` 每条记录：

```json
{
  "target_locator": "稿件#第3段",
  "kind": "数据|结论|术语|图表|引用",
  "source_locator": "materials/paper.md#p5",
  "quote": "逐字摘录的源文片段",
  "note": "保留/改写/删除及理由，或 source_conflict"
}
```

- `source_locator` 指向真实存在的输入文件与段落；没有可解析文本时用文件名+页码。
- 冲突信息不隐藏：同一指标两个来源不一致，两条都记录并标 `source_conflict`。
- 不虚构引用、DOI、数值；缺失写 `not_reported`，需人定夺写 `pending_human`。

## 5. 改动清单格式

`work/change_log.json` 每条记录：

```json
{
  "location": "稿件第N段",
  "before": "原表述（或 deleted）",
  "after": "新表述（或 added）",
  "reason": "受众适配|压缩冗余|修正强度|术语统一|事实核验",
  "evidence": "对应 evidence_map 条目 id"
}
```

原作者据此可逐段复核每一处删改；没有理由的改动不得保留。
