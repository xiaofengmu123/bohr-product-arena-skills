# 自检清单（对应评分维度）

本清单用于收尾阶段逐条勾选；脚本 `scripts/verify.py` 负责自动核验可机检项，
下列语义项由 Agent 人工复核。任何一项失败都要回到源材料修正，不得用臆测填补。

## 一、实际效果（40 分）

- [ ] 完成的是**可直接使用**的改写稿，不是建议、提纲或片段润色
- [ ] 满足题目指定的**读者、体裁、篇幅**三项约束
- [ ] 关键结论、数据、单位、样本量、统计口径、图表编号与源文一致
- [ ] 数字与引用可逐条回到源文（locator + 逐字 quote），无新增事实
- [ ] 删的是冗余，不是证据；限定条件（相关≠因果、初步≠定论）保留
- [ ] 逐段对照 + 改动清单 + 删改理由 + 待确认项齐全，原作者可按段复核

## 二、使用增益（25 分）

- [ ] 术语单一化：同一概念全文只用一种说法，缩写首次展开
- [ ] 论断强度分级：确认/初步/相关/未证实各归其位，不升格
- [ ] 受众画像→取舍策略→边界标注→多文体映射的链条被真实执行
- [ ] 同源文、同约束重复运行，产出结构与术语保持一致（确定性）

## 三、创新增益（15 分）

- [ ] 术语表锁定 + 必须保留项清单 + 证据映射是本次实际产出的方法产物
- [ ] 方法对基础 Agent 的典型失败（事实漂移、受众错配、术语不一致）有针对性

## 四、可靠体验（10 分）

- [ ] `python3 scripts/main.py --help` 退出码 0
- [ ] 空输入 → 退 0 并写 `insufficient_evidence`，不抛异常
- [ ] 坏 JSON / 坏编码 → 记录 errors/degradations，继续处理其余材料
- [ ] 缺引用 / 数据自相矛盾 / 体裁与篇幅冲突 / 涉密未发表 → 显式标注

## 五、生态贡献（10 分）

- [ ] SKILL.md、references/、scripts/ 齐全，路径有效
- [ ] 术语表、改动清单、证据映射格式可被他人直接复用
- [ ] 无预制答案、无伪造评测分数、无虚构 DOI/数值

## 降级原则（贯穿全部）

- 材料不足 → `insufficient_evidence`；无法判断 → `uncertainty` + `pending_human`
- 缺软件/缺工具 → 在 `degradations` 如实说明，给出最小合法产物
- 冲突信息 → 双方都记录并标 `source_conflict`，不选边
- 缺失值 → `not_reported` / `null`，绝不编造
