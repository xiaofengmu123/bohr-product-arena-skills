# 学术翻译规则与双语格式（供执行 Agent 与复核人复用）

本文把"术语稳、数字实、对得齐、边界清"四问落成可执行规则；`scripts/check.py` 只做确定性复核，本文说明判断依据。

## 1. 术语稳（术语一致性）

- 先抽术语：领域名词、缩写、上下位词、固定搭配；每个术语建一条 `{"canonical", "variants"}`。
- `canonical` 是锁定进全文的**目标语言译法**；`variants` 是允许出现的同义/缩写/原文写法。
- 同一术语在摘要、正文、图表题注、附录中必须用同一 canonical；跨学科同名异译要按当前学科锁死并在 `note` 说明。
- 首现缩写给出全称 + 缩写；之后统一用缩写或全称，不混用。

## 2. 数字实（数字、单位、量级、范围、口径）

- 数字、单位、量级、范围、年份、样本量、统计口径**原样落地**：不四舍五入、不换单位、不"顺手改成整数"。
- 中英文数字表达差异（万/亿 ↔ million/billion）只做自然表达转换，**数值不变**；转换时在术语注或 `note` 保留原数字，便于复核。
- 有效数字位数保持；范围、区间、置信区间、百分比的小数位不缩不扩。
- 公式符号、上下标、单位符号保持原样，不改成近似值。

## 3. 对得齐（句段级对齐）

- 按句段产出 SRC/TRG 对齐块，段 id 连续递增、一一对应：

```text
> SRC[12]|loc:paper.pdf#p4|原句...
> TRG[12]|术语注:…|译文...
```

- 段落顺序、图表编号、题注、脚注、参考文献条目保持原位；公式块、表格块不拆分。
- 每个 TRG 都要能指回 SRC 的 `loc`；增译/省译/合并/拆分要在 `note` 标注原因，不静默改动。

## 4. 边界清（增省译、否定、因果、模糊限制语、引用归属）

- 否定范围（not/no/never/unless）不扩大不缩小；因果强度（causes/leads to/may/associated with）不升不降。
- 模糊限制语（may/could/likely/possibly/suggests/初步表明）保持原强度，不把学术表述改成宣传口吻或口语化。
- 引用标记（`[n]`、作者—年份、`(n)`、`et al.`、上标）保留，格式差异（方括号/圆括号、et al. 全半角）按目标语言规范处理但**归属不变**；参考文献条目完整保留。
- 不添加作者没说过的结论；有把握的改写才落笔，否则标 `pending_human`。

## 5. 溯源格式（fact_source_map）

每项：

```json
{"item": "样本量", "kind": "number", "value": "n=200",
 "locator": "paper.pdf#p4", "quote": "n = 200 participants",
 "note": "原样保留，未四舍五入"}
```

- `kind` 取 `term|number|unit|citation|reference_entry|claim|figure|table|formula|footnote`。
- `quote` 必须是材料中的逐字片段；`locator` 是 `文件:页码/段落`；推断在 `note` 标"推断/待核"。

## 6. 降级与边界

- 缺材料/缺软件如实写 `limitations`/`degradations`，不编造；语向不支持明确写出并 `status=partial`。
- 术语表冲突、编号不连续、引用找不到原文：能自动判定就修，否则交 `human_confirm`。
