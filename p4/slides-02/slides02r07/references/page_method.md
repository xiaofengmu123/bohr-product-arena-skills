# 页面规划与证据映射方法（page_method）

本文是 `academic-slide-builder-robust` 的方法说明，供 Agent 在步骤 2–3 复用，也是评审可复核的方法依据。方法均需以实际材料为准，任何无材料的判断一律记入 `uncertainty`。

## 1. 页面叙事角色（page role）

| 角色 | 作用 | 典型内容 |
|-|-|-|
| title | 标题页 | 题目、汇报人、场合、日期 |
| motivation | 研究问题 | 待解决问题 + 现有缺口，1 句主张 |
| background | 背景/已知 | 必要术语、已有结论，最多 3 条 |
| method | 方法 | 支撑结果的最少步骤，3–6 条 |
| result_k | 结果页 | 每条高价值结果独立成页，1 个核心数字 |
| discussion | 讨论/限制 | 假设、边界、未决项 |
| conclusion | 结论/展望 | 与 motivation 呼应的收束 |
| appendix | 附录 | 致谢、引用、补充数据 |

## 2. 页序规划启发式

1. 先抽取全部结果主张，每个“独立可引用”的结果占一页，弱结果合并。
2. 方法页只保留支撑结果页的最少步骤，不按论文方法节逐条搬。
3. 图/表按“首次被引用的主张”排序，而非原论文编号机械排列；允许图 3 先于图 2。
4. 单页要点 3–5 条，每条用“标题句 + 证据句”结构；一页只讲一件事。
5. 换受众重排：导师（压缩背景）、评审（突出贡献与限制）、同行（突出方法与数据）。

## 3. 每页主张的字数与层级预算

- 页标题 ≤ 12 字，或一句完整主张。
- 要点每条 ≤ 20 字，一页 ≤ 5 条。
- 字号层级：标题 ≥ 24pt、正文 ≥ 16pt、图注/引用编号 ≤ 12pt；低于 16pt 的正文需拆页。
- 每页最多 1 个核心数字/结论，且必须附出处。

## 4. 图表数据绑定规则

可重绘（须同时满足）：
1. 原文提供数据表或可提取的数值点；
2. 单位、误差棒、坐标轴完整；
3. 重绘后与原文曲线逐点一致。

仅引用（满足其一）：
1. 纯位图且 OCR 无法可靠取数；
2. 图含复杂标注、子图或照片；
3. 数据缺失或同一指标存在 `source_conflict`。

处置：仅引用时保留原图 + 图号/页码定位，写 `uncertainty`，不补值、不重绘假曲线。

## 5. 模板槽位映射

1. 先枚举母版版式（layout 名 + placeholder 类型/数量）。
2. 角色映射：title→标题版式、result_k→图表版式、method→两栏版式。
3. 槽位不足时映射最近似版式并写 `uncertainty`，不改母版配色/字体/页脚。
4. 只编辑 placeholder 内容，禁止新建覆盖母版；改一页不得影响后续页。

## 6. 局部编辑与版本回退

- 改动前 `record.py version` 存快照（含文件路径与 note）。
- 每次编辑用 `record.py change` 记录 step/action/reason；diff 经 `version_records` 定位。
- 回退 = 取最近可用快照的源文件覆盖，并记录回退原因与目标版本。

## 7. 页级证据映射 schema

每条 evidence：
```json
{"page": 4, "role": "result", "claim": "页上真实出现的文本",
 "refs": ["Fig 3", "Table 1"], "loc": "materials/paper.pdf#p7",
 "quote": "材料中的逐字片段"}
```
要求：`claim` 是页上真实文本；`quote` 是材料逐字片段；`loc` 可定位到页/图/表；无 `quote` 的结论不得进入页面主张。

## 8. 讲稿备注规则

- 每页备注 = 该页叙事角色 + 1 句过渡 + 关键数字出处提醒。
- 备注不含页面未出现的数字，避免讲稿与页面不一致；数字/引用逐字核对原文后再写入。
