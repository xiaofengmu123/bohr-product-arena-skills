# 长文档一致性检查清单

对应“连得上”与评分维度中的“结果正确性 / 使用增益-质量”。每项由 `scripts/consistency.py` 出候选，Agent 复核后修正；脚本只提示、不自动改写，保证作者对改动可控。

## 术语与缩写
- [ ] 每个术语/缩写首次出现时给出全称，之后统一使用同一形式。
- [ ] 同一中文术语不出现两种英文/缩写写法；重复定义已合并为首次定义。
- [ ] 符号表与正文符号一致，单位制一致（SI/单位、量纲、正负号约定）。

## 编号与交叉引用
- [ ] 章节编号连续，无缺口、无重复。
- [ ] 图、表、式编号连续；正文中“见图 X / 见表 X / 式(X)”的目标都存在。
- [ ] 图表引用顺序与编号顺序一致（正文先提后出现）。

## 结论与事实
- [ ] 同一指标/结论在摘要、结果、讨论、结论四处数值一致，无前后矛盾。
- [ ] 每条数字/结论能回溯到 `fact_source_map` 的 `locator+quote`。
- [ ] 引用了文献但结论被改写、或引用不存在文献的情况已标 `missing_source`/`pending_human`。

## 改动记录
- [ ] 每条改动记 `before/after/reason`，只动必要处，保留作者原意与既有表述。
- [ ] 受一处改动影响的段落已同步更新（术语改名、编号重排、结论调整）。

## 边界与异常
- [ ] 材料缺失、引用找不到原文、编号不连续、格式不支持、超长截断均已标注。
- [ ] `status` 与实际情况一致，未把 `partial` 标成 `ok`。
