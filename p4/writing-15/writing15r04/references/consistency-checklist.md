# 跨章节一致性检查清单

本清单用于 Step 3，配合 `scripts/consistency.py`。目标：术语、符号、定义、编号、图表引用、结论在整篇文档内前后一致，改动一处能找到受影响的段落。

## A. 术语与缩写

- [ ] 同一概念全文只用一个中文名 + 一个缩写；首次出现给「全称（缩写）」，后文只用缩写。
- [ ] 缩写大小写、连字符统一（如 LSTM / lstm / LSTM 只留一种）。
- [ ] 同缩写不指两个不同概念；`consistency.py check` 的 `term_conflicts` 非空必须逐条处理。
- [ ] 术语表 `term_table.md` 记录：术语、缩写、定义、首次出现定位、来源文件与逐字引用。

## B. 符号与定义

- [ ] 同一符号只表一个量；同一量只用同一个符号（含正斜体、上下标）。
- [ ] 符号首次出现给定义，后文不再重复定义；重复定义段需合并或标注。
- [ ] 单位、量纲、变量命名与原文/材料一致，不引入材料外符号。

## C. 章节与图表编号

- [ ] 章节编号连续无重复：`check_numbering` 的 `section_duplicates` 与 `section_gaps` 为空。
- [ ] 图/表/公式编号连续且格式统一（图 2-1 与 Figure 2 不混用；中文/英文体例取其一）。
- [ ] 正文「见图 3」「如表 2-1」「式(2.1)」的交叉引用，目标编号真实存在且指向正确对象。
- [ ] 编号重排后，所有交叉引用同步更新；`change_record.md` 记录改动前后编号映射。

## D. 结论与论证链

- [ ] 前后章节结论不互相矛盾；出现冲突时两个说法都保留并标 `source_conflict`，不擅自取舍。
- [ ] 每节回答提纲赋予它的论证任务，不把材料堆成若干段通顺文字；重复论述段标注或合并。
- [ ] 字数/篇幅分配与提纲一致；超限段注明原因。

## E. 可核验性

- [ ] 每个数字、术语、图表、关键论断都能指回材料段落（locator + 逐字 quote），见 `evidence_map.json`。
- [ ] `scripts/evidence.py verify` 未命中的引用一律标 `unverified`，写入 `uncertainty` 或 `pending_human`。
- [ ] 不新增材料外事实；推测、推断、待确认项分别标 `inference` / `pending_human`。

## 映射到评分维度

- 实际效果·结果正确性：B/C 项（符号、编号、术语与材料一致）。
- 实际效果·完整性：C/D 项（图表、参考文献、附录、论证要素齐全）。
- 使用增益：A/C 项由 `consistency.py` 确定性检出，减少人工通读与手工统一。
- 创新增益：E 项的逐字核验是基础 Agent 不稳定的能力边界。
