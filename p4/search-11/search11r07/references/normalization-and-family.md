# 字段口径、号码规范化与同族归并规则

本文档给出本 Skill 使用的机械规则口径，供他人复核。所有规则只做「可复核的机械判定」，不推断官方登记；无法判定的口径显式标注 uncertainty 而不是硬猜。

## 1. 号码口径（number_type）

| 口径 | 含义 | 典型形式 | 判定依据 |
|---|---|---|---|
| `publication` | 申请公开号 | `WO 2023/123456 A1`、`CN 109876543 A`、`EP 3456789 A1` | 类别码以 A 开头，或 WO 的 `YYYY/NNNNNN` 形式 |
| `grant` | 授权号/专利号 | `US 12,345,678 B2`、`KR 10-2019-0123456 B1` | 类别码以 B/C 开头 |
| `application` | 申请号 | `US 16/123,456`、`EP 18123456.7` | 无类别码且含 `/` 或 `.` 的申请编号形式 |
| `priority` | 优先权号 | `US 62/345,678`（美国临时申请 61/62 系列） | 无类别码且首段为 61/62 |
| `utility_model` / `design` | 实用新型 / 外观设计 | `CN ... U/Y`、`US ... S` | 类别码 U/Y 或 S |
| `publication_or_grant` | 公开号或授权号不明 | 无类别码的 6–8 位号码 | 类别码缺失时如实标注低置信 |
| `unknown` | 无法判定 | 不满足任何规则 | 保留原始串并写 notes |

**规范化**：统一大写、去分隔符（空格/逗号/点/连字符）、保留斜杠（WO 年份与美申号分隔）；输出形如 `US12345678B2`、`WO2023/123456A1`。全角字符先做 NFKC 归一化，OCR 粘连（如 `WO2023/123456A1` 无空格）可识别。

## 2. 类别码（kind code，WIPO ST.16 常见值）

`A1/A2/A9` 申请公开；`B1/B2/C1/C2` 授权；`U/U1/Y` 实用新型；`S` 外观设计；`T` 译文。类别码决定「公开号 vs 授权号」口径，不得混用。

## 3. 同族归并（family）

- **归并键**：归一化后的公开号、申请号、优先权号、授权号任一相同即并入同一族（并查集连通分量）。
- **口径**：
  - `simple`（简单族）：成员公开号与优先权号完全一致（重复记录/单一文献）。
  - `extended`（扩展族）：共享申请号或优先权号但公开号不同（跨局/多成员）。
  - 所有结果一律标 `observed:true`、`exhaustive:false`，并在 basis 注明「仅在已观察记录内归并，未查 INPADOC」。
- **限制**：不把「关键词命中的几件不同专利」当成同族；只有共用申请号/优先权号才能归并。资料只给出部分号码时，family_scope 标 `family_scope_unclear`。

## 4. 法律状态核验

- 只以**官方登记页**（USPTO/Espacenet/PATENTSCOPE/国家局）为登记依据，转载页、二手聚合站只作线索不作结论。
- 每条状态必须写：`status`、`effective_date`、`source`（库名+URL）、`as_of`（查询日期）、`staleness_risk`（滞后风险）、`confidence`。
- 官方状态未知就写 `unknown`，不推断「有效/失效」；两来源冲突时双方证据并列并标 `source_conflict`。
- 状态取值建议：`granted / pending / expired / withdrawn / rejected / revoked / unknown`。

## 5. 授权边界（绿/黄/红）

- **绿**：公开官方登记、许可允许展示；可引用字段与原文片段。
- **黄**：可访问但展示/留存受限；只记录元数据与查询记录，不展示受限原文。
- **红**：付费墙/登录库/企业保密；标 `degradations` 说明不可用与降级方案，不尝试登录、不绕过、不上传。
- 每条授权记录写 `{source, license_basis, tier, displayable_fields, retention}`。

## 6. 主题检索式构造（专利文献 vs 技术文献）

**两条检索逻辑分开**：专利文献靠分类号/申请人/引证定位技术领域；技术文献靠主题词/同义词/年份窗口发现对比论文，不能把两者混在一条检索式里。

专利文献检索式（可解释、可复跑）：
- 分类号：IPC 按国际专利分类定位技术领域，CPC 更细（可下钻到小组）。
- 申请人/发明人：用于锁定竞争机构与同主题团队。
- 引证：前引（本专利被谁引用，cited by）与后引（本专利引用了谁，cites）双向追踪技术脉络。
- 组合示例（示意）：`分类号 AND (关键词 OR 同义词) AND (申请人 OR 发明人)`，逐条记录每个运算符的选择理由。

技术文献检索式：
- 用 `paper_search`/`web_search` 检索标题/摘要/DOI，主题词+同义词扩召回，年份窗口控制时效。
- 每条命中保留 `relevance_rationale`（为何相关）与 `evidence`（摘要/原文片段逐字引用）。

**官方登记核验口径**（库名+版本+查询日期三者齐备）：USPTO Patent Center、Espacenet、PATENTSCOPE、各国国家局为登记依据；Google Patents 等聚合站只作定位线索，不作法律状态结论。实际 URL 以检索当时官方页面为准，记录到 `sources[]`，不写死过期链接。
