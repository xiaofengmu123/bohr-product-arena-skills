# 评分维度核对表（提交前逐条过一遍）

本表把题目五个评分维度拆成可在交付前逐条核对的检查项。每项都对应 `SKILL.md` 或 `scripts/` 中的具体落点，核对时以“真实运行证据”为准，不以文字自述替代。

## 1. 实际效果（40 分）

- [ ] 任务完成度：真的以种子为起点，沿前向/后向与关联信号完成扩展，而非只做关键词列表。
- [ ] 结果正确性：文献真实存在（可回指 DOI/arXiv/出版信息）；引用方向正确（`source cites target`，无猜测）；同文不同版本已正确合并，未误合并同名不同文。
- [ ] 结果完整性：覆盖种子关键被引出处（后向）、主要后续改进（前向）、代表性平行工作（共被引/耦合/作者/数据集关联），遗漏已写入 `coverage_gaps`。
- [ ] 结果可核验性：`seed_key`、扩展层级、每条边、数据源均可独立复核（`locator` + `quote`）。

## 2. 使用增益（25 分）

- [ ] 质量增益：相同种子与预算下，相比基础 Agent 的追踪结果更可复核、方向更规范、身份合并更干净。
- [ ] 效率增益：去重与方向规范化由脚本完成，减少人工核验条目数、无效接口翻页、去重返工与综合调用成本（`dedupe/rank/path` 单条命令即可）。
- [ ] 增益可验证性：`scripts/selftest.py` 提供空输入/坏 JSON/确定性对照，说明增益可被公平复现。

## 3. 创新增益（15 分）

- [ ] 新增能力：跨库身份对齐（DOI→arXiv→标题链）、方向感知扩展、可解释路径（`path` 逐跳）至少落地一项。
- [ ] 方法改进：去重键优先级、`direction_unknown` 不猜测、距离加权排序（明确“高被引≠高相关”）带来实质改进。
- [ ] 创新证据：与“只按关键词/只按被引次数”的基线有清晰边界与价值说明。

## 4. 可靠体验（10 分）

- [ ] 调用易用：`python3 scripts/main.py help` 退出码 0，Agent 能按 SKILL.md 完成一次完整追踪。
- [ ] 运行稳定：不同学科/引文覆盖度/数据源/重复运行下持续产出可用结果（确定性 + 标准库）。
- [ ] 异常处理：种子无引文记录、同名论文歧义、跨库字段冲突、撤稿与更正、限流/权限不足均已识别并如实写入 `errors/degradations/pending_human`，不崩溃。

## 5. 生态贡献（10 分）

- [ ] 文档完整性：用途、调用方式、输入输出契约、字段规范、去重规则、异常处理齐全（SKILL.md + references/）。
- [ ] 资源可复用：边表字段（`papers.csv`/`edges.csv`）、去重脚本（`dedupe`）、排序/路径函数可被他人直接复用。
- [ ] 分享价值：可沉淀真实追踪案例、路径图（SVG）与去重经验。

## 快速自检命令

```bash
python3 scripts/selftest.py        # 全部通过则可靠性自检 OK
python3 scripts/main.py help       # 退出码 0
python3 -c "import json;r=json.load(open('/app/output/result.json',encoding='utf-8'));assert r.get('case_id') and r.get('status');print('ok',r['status'])"
```

## 常见扣分点提醒

- result.json 里缺 `case_id` 或 `status`（评分主产物必须完整）。
- `output_contract` 键被改名/删除，或缺值没回填。
- 边方向写反或对“只给被引列表”的数据强行猜方向。
- 把高被引直接当作高相关，未提供距离/方法相关性依据。
- 同文多版本没合并、或把同名不同文误合并。
- 证据只有结论没有 `locator + quote`，无法复核。
- 缺数据时编造 DOI/引用次数/出版信息，而不是如实标 `insufficient_evidence`。
