# 方法约定与检查清单（复用与复核依据）

本文沉淀本 Skill 的方法决策、边界与可复用规则，使他人无需读源码即可复用去重键、排序权重、路径规则与停止判据，并对评分维度逐条自查。

## 1. 身份合并键（确定性优先级）

`citation_lib.key_of` 按以下顺序取键，**所有实现必须一致**：

1. `doi`（归一化为小写、去尾 `.`）；
2. `arxiv` / `arxiv_id` / `arXiv`（小写、去 `vN` 版本后缀）；
3. `title`（归一化）+ 第一作者姓 + `year`；
4. `title`（归一化）;
5. 无键 → 独立成簇（不强行合并）。

合并后保留证据：`merge_key_used`（用了哪一级键）、`members[]`（全部成员）、`merge_evidence`（描述为何判定同一工作）、`confidence`（无 DOI 时随键级降低）。同名不同文靠“title+第一作者姓+年份”区分；同文不同名靠 DOI/arXiv 拉齐；预印本/会议版/期刊版/增补版合并进同一 `members[]`，代表版优先 DOI，其次期刊版，其次最早年份。

## 2. 排序权重（高被引 ≠ 高相关）

`rank_papers` 的分数构成：

- 距种子层数主导：种子 100；一层 60；二层 30；三层 12；更远 4；
- 被引次数仅弱信号：`min(被引, 20) × 0.5`；
- 年份仅近期轻微加权：2015–2026 每年 +0.2（封顶 +2.0）；
- 来源置信度作乘数：DOI 1.0 / arXiv 0.9 / title+作者+年份 0.8 / title 0.6 / 无键 0.4。

设计意图：把“直接相关但少被引”排在“高被引但主题漂移”之前；主题相似不等于方法相关，平行工作必须给出共被引/文献耦合/作者机构/数据集任务等具体依据。

## 3. 路径与方向

- 边方向统一 `source` cites `target`，`shortest_path` 求“种子如何间接引用到远端文献”的有向链。
- 逐跳输出 `hops`（节点序列）与 `edges`（边 id），区分直接引用与间接可达；不可达时 `kind=unreachable` 并说明，不虚构边。
- 只给被引列表不给方向时标 `direction_unknown`，不猜测方向。

## 4. 停止判据与剪枝

- 扩展层数上限默认 3；无新节点即停。
- 剩余时间 < 120 秒或剩余模型请求 < 8 即收束，先保证 `result.json` 合法。
- 剪枝原因写入 `plan.pruned`（按相关性/年份/文献类型），不静默丢弃。

## 5. 证据硬要求

每个关键结论/边/数值给 `locator`（如 `materials/x.pdf#p3`）+ 逐字 `quote`；冲突信息两者都记并标 `source_conflict`；缺失标 `not_reported`，写入 `pending_human`。不虚构 DOI、数值、引用或软件状态。

## 6. 提交前检查清单（对应评分维度）

**实际效果**
- [ ] 种子身份已在材料中核实并写 `plan.seed_key`；
- [ ] 每条边方向正确、有来源证据，无猜测方向；
- [ ] 同文多版本已合并，合并证据可复核；
- [ ] 关键被引出处、主要后续改进、代表性平行工作已覆盖或注明遗漏。

**使用增益**
- [ ] 去重与方向规范化由脚本完成，减少人工核验条目数与无效翻页；
- [ ] 同输入两次运行 `results` 逐字节一致（脚本确定性）。

**创新增益**
- [ ] 中间表示五层分离（意图→证据→实体→关系→结果）落地；
- [ ] 跨源身份对齐、方向感知扩展、可解释路径至少一项可复核。

**可靠体验**
- [ ] 空输入/坏 JSON/坏编码不崩溃、退出码 0；
- [ ] 种子无引文记录、同名论文歧义、跨库字段冲突、撤稿更正、限流/权限不足已识别并写 `errors`/`degradations`。

**生态贡献**
- [ ] `SKILL.md`、`references/schema.md`、`references/method.md` 齐备；
- [ ] 边表字段、去重键、排序权重、停止判据可被他人复用。

运行自检：`python3 scripts/main.py selftest --root .`（退出码 0 即通过）。
