# 评价量表（rubric）— 证据锚定版

本量表是 `litqa-evidence` 的判定依据。所有 `assessment` 条目必须来自本表所列维度与检查点，
每条判断绑定 `locator + quote` 并登记到 `evidence_map`；证据不足时弃权，不得补造。

## 0. 适用范围与文献类型

适用：干预性研究（RCT、非随机对照）、观察性研究（队列、病例对照、横断面）、
系统综述/Meta 分析、诊断准确性研究、定性研究。先识别文献类型，再启用对应特有检查点（见 §3）。
不替代同行评审、事实核验、临床/政策决策或研究结论。

## 1. 判定词表（受限值，避免自由发挥）

- `verdict ∈ { low_risk, some_concerns, high_risk, insufficient_evidence, not_applicable }`
- 证据状态 `basis ∈ { direct, inferred, abstain }`：
  - `direct`：`quote` 逐字来自原文相应位置；
  - `inferred`：结论由原文可定位片段合理推导（须在 `judgment` 中说明推导步骤）；
  - `abstain`：原文未报告且无法推导，`verdict=insufficient_evidence`。
- 证据来源层 `provenance ∈ { fulltext, abstract, table_figure, metadata, secondary }`。

## 2. 四类核心维度与检查点

每条检查点标注 `critical`（分级加权）与判定所需证据。`quote` 必须可定位到句子级或表格级
（`locator` 形如 `source_id#region.p段.s句`，并附 `char_span`）。

### D1 研究设计（study design）
| 检查点 | critical | 证据要求 |
|---|---|---|
| 设计类型与研究问题匹配 | 是 | 原文说明设计类型（RCT/队列/病例对照/横断面/系统综述等） |
| 对照/比较设置合理 | 是 | 原文描述对照组、暴露组或比较组 |
| 干预/暴露定义清晰 | 否 | 原文给出操作性定义与时间窗口 |
| 主要结局预设（非事后挑选） | 是 | 方法/注册信息中预设结局的表述 |

### D2 证据充分性（evidence sufficiency）
| 检查点 | critical | 证据要求 |
|---|---|---|
| 样本量与把握度/估计精度 | 是 | 样本量计算、效应量或置信区间表述 |
| 抽样与纳入排除标准 | 否 | 原文给出抽样框架、纳入/排除标准 |
| 测量与结局完整性 | 是 | 结局定义、测量工具、缺失处理 |
| 随访/应答率充分 | 否 | 随访时长、失访/应答率数字 |

### D3 偏倚风险（risk of bias）
| 检查点 | critical | 证据要求 |
|---|---|---|
| 选择偏倚（分配/选择过程） | 是 | 随机化/分配隐藏或暴露组形成过程 |
| 信息/测量偏倚（盲法、结局测量） | 是 | 盲法、客观测量或验证性测量 |
| 混杂控制 | 是 | 调整变量、分层、匹配或多变量模型 |
| 选择性报告 | 是 | 全部预设结局是否都报告，协议/注册一致性 |

### D4 报告完整性（report completeness）
| 检查点 | critical | 证据要求 |
|---|---|---|
| 方法可复现 | 是 | 方法细节足以外人重复 |
| 结果完整（含不良/阴性） | 是 | 全部结局结果、效应量、精确度报告 |
| 局限与推广性声明 | 否 | 原文明确讨论局限与适用范围 |
| 数据/协议可得性 | 否 | 数据共享、注册号、预注册声明 |

判定规则：某检查点无任何可定位证据 → `insufficient_evidence` + `basis=abstain`，
在 `judgment` 写"原文未报告该信息"，绝不写推测性结论。

## 3. 文献类型特有检查点

- RCT：随机序列生成、分配隐藏、盲法、ITT 分析、提前终止规则。
- 队列：暴露组与随访起点定义、失访偏倚、时变混杂、Cox/回归口径。
- 病例对照：病例与对照来源、匹配与过度匹配、回忆偏倚、暴露测量时相。
- 横断面：抽样代表性、应答率、因果方向无法推断的局限声明。
- 系统综述/Meta：检索策略与日期、纳入标准、异质性 I²、发表偏倚（漏斗图）、GRADE/证据分级。
- 诊断准确性：金标准独立验证、谱系偏倚、盲法读片、阈值预设。

## 4. 证据优先顺序

1. 全文正文（方法+结果）> 2. 表格/图注数字 > 3. 摘要声明 > 4. 元数据/注册信息。
冲突时全部记录并标 `source_conflict`；高优先级的"缺失"不可被低优先级来源替代成"存在"。

## 5. 分级阈值（确定性聚合）

- 单条 `high_risk` 计 2 分、`some_concerns` 计 1 分、`insufficient_evidence` 计 1 分（趋向 unclear）、
  `low_risk` 计 0 分、`not_applicable` 不参与分母。
- 总体等级：
  - `high`：任一 critical 检查点 `high_risk`；
  - `unclear`：`insufficient_evidence` 数量超过适用条目一半；
  - `moderate`：加权分数/适用条目 ≥ 0.5，或存在任一 `high_risk`（非 critical 时）；
  - `low`：其余情况。
- 输出必须含 `n_applicable`、各 verdict 计数与理由，不得只给孤立等级标签。

## 6. 依赖与限制

- 仅依赖 Python 标准库；文本抽取依赖运行时提供的 PDF 文本工具（不可用时降级，见 SKILL.md §6）。
- 量表为辅助工具，不覆盖全部研究设计；引文核验限于已抽取文本，图片/公式内容不可解析时如实标注。
- 分级反映"报告质量与可复核性"，不等于"结论正确性"。
