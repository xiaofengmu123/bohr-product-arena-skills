# 量表与分级规则（litqa-evidence-index）

本文件是判定与复核的唯一量表来源，与 `scripts/rubric.py` 中常量一致；脚本编码阈值与本文一致，人工复核按本文执行。

## 1. 判定值词汇表（受限值）

| 字段 | 取值 | 含义 |
|---|---|---|
| `verdict`（单条判断） | 支持 / 部分支持 / 不支持 / 证据不足 / 无法评价 | 该检查点结论是否被原文证据支持 |
| `bias`（偏倚领域） | 明确存在 / 可能存在 / 未见迹象 / 证据不足 | 该偏倚领域在本文献中的具体表现 |
| `critical`（关键性） | 关键 / 重要 / 一般 | 该检查点对结论可靠性的影响权重 |
| `grade`（汇总等级） | 低偏倚风险 / 中偏倚风险 / 高偏倚风险 / 证据不足 | 由维度结果按阈值聚合 |

`verdict` 与 `bias` 都必须由 `quote` 逐字支撑；写 `证据不足`/`无法评价` 时，`basis` 必须说明缺的是哪项证据。

## 2. 四类维度与检查点

### 2.1 研究设计（research_design）

判定对象：研究类型是否被正确识别，设计要素与结论主张是否相称。

| 检查点 | 关键性 | 需要的证据 |
|---|---|---|
| design_type 研究类型识别 | 关键 | 原文对设计类型的表述（RCT/队列/病例对照/横断面/定性/系统综述/临床前） |
| design_claim_alignment 设计与结论相称 | 关键 | 结论动词（因果/关联/描述）与研究设计的推断强度 |
| comparator 对照/参照 | 重要 | 对照组或参照条件的定义与选择理由 |
| allocation_blinding 分配与盲法 | 重要 | 抽样/分组方法；适用时盲法是否实施并报告 |
| confounding 混杂控制 | 关键 | 主要混杂因素是否在设计或分析中处理 |

### 2.2 证据充分性（evidence_sufficiency）

判定对象：样本、功效、效应量与精度、缺失数据、多重比较是否支撑结论。

| 检查点 | 关键性 | 需要的证据 |
|---|---|---|
| sample_size 样本量与功效 | 关键 | 样本量、功效分析或样本量计算依据 |
| effect_estimate 效应量与精度 | 关键 | 效应量 + 置信区间/标准误 |
| missing_data 缺失与失访 | 重要 | 缺失/失访/排除的数量与处理方式 |
| multiplicity 多重比较 | 一般 | 亚组/敏感性/多重比较的说明或控制 |
| method_fit 方法匹配 | 重要 | 统计方法与数据类型/设计的匹配性 |

### 2.3 偏倚风险（bias_risk）

判定对象：按文献类型选适用领域，逐领域给出四档结论并指明环节。

| 检查点 | 关键性 | 需要的证据 |
|---|---|---|
| selection_bias 选择偏倚 | 关键 | 纳入排除、招募、随访环节 |
| performance_bias 实施偏倚 | 重要 | 干预/暴露执行、依从、盲法 |
| detection_bias 检测偏倚 | 重要 | 结局测量、盲评、判定标准 |
| attrition_bias 失访偏倚 | 重要 | 失访/退出数量与影响 |
| reporting_bias 报告偏倚 | 关键 | 选择性报告、结局是否预注册 |

### 2.4 报告完整性（reporting_completeness）

判定对象：方法可复现、结果完整、注册/协议、资助/利益冲突、数据/代码/图表可及。

| 检查点 | 关键性 | 需要的证据 |
|---|---|---|
| methods_reproducibility 方法可复现 | 关键 | 对象、步骤、测量、统计方法是否完整 |
| results_completeness 结果完整 | 关键 | 预定义结局全报告（含阴性），数字与图表一致 |
| registration_protocol 注册/协议 | 重要 | 注册号/研究方案，主要结局与协议一致性 |
| funding_coi 资助与利益冲突 | 一般 | 资助来源与 COI 声明 |
| data_code_availability 数据/代码可及 | 一般 | 数据/代码可用性声明、图表/补充可访问 |

## 3. 文献类型特有检查点（按类型叠加）

| 类型 | 特有检查点 |
|---|---|
| RCT | 随机方法、分配隐藏、盲法、ITT 分析、注册号 |
| 观察性研究 | 暴露/结局定义、随访、混杂调整、缺失处理 |
| 临床前研究 | 动物/细胞模型、盲法、重复数、统计方法 |
| 系统综述 | 检索式、纳入排除标准、纳入研究质量评价、异质性 |
| 定性研究 | 抽样策略、数据饱和、编码过程、研究者反思/三角验证 |

识别到研究类型后，把该类型的特有检查点作为该文献"一般"或"重要"条目追加到对应维度，并在 `basis` 注明"类型特有"。

## 4. 分级阈值（由 `grade` 命令编码实现）

对每条 assessment 计算加权偏倚信号：`关键性权重 = 关键3 / 重要2 / 一般1`，`偏倚权重 = 明确存在1.0 / 可能存在0.5 / 未见迹象0.0 / 证据不足0.0`。

| 等级 | 判定条件 |
|---|---|
| 高偏倚风险 | 任一关键检查点偏倚明确存在；或（关键+重要）≥3 个检查点偏倚明确存在；或 ≥5 个检查点偏倚为明确/可能存在 |
| 中偏倚风险 | 任一重要检查点偏倚明确存在；或 ≥1 个关键检查点偏倚可能存在；或 ≥2 个检查点偏倚可能存在 |
| 低偏倚风险 | 无明确存在，且至多 1 个一般检查点为可能存在 |
| 证据不足 | ≥2 个关键检查点证据不足；或全文不可得 |

`grade` 输出的 `rationale` 必须写明命中哪条阈值与具体计数；`thresholds_applied` 保存本表文本。

## 5. 证据优先级与定位

1. 全文段落级（`rel_path#pN`）> 摘要句子级 > 图表编号。
2. 同一判断可多 `locator` 并列，`basis` 指明主证据；主证据必须是全文而非摘要。
3. `quote` 必须是单段内连续原文，经空白归一化后逐字匹配；跨段/改写不算证据，标 `证据不足`。
4. 图表不可解析时，可引用图表编号与题注原文作为弱证据，并在 `limitations` 声明"图表未解析"。
5. 冲突：同一指标多来源不一致时全部记录并标 `source_conflict`，`uncertainty` 说明差异来源与影响。

## 6. 适用边界与不适用范围

- 适用：给定研究问题下的文献检索筛选、研究设计/报告质量评价、证据定位、偏倚风险分级与复核辅助。
- 不适用：事实核验、替代同行评审、临床/政策决策或研究结论裁决；不覆盖全部研究设计与全部学科，仅需在明确类型上做对可复核评价。
- 相对已有方案（泛化摘要、公开报告清单、编辑初筛）的边界：本量表强制逐条证据锚定、受限判定值、可解释阈值与弃权规则，产出可被第二人复核，而非"看似合理"的整体评语。
