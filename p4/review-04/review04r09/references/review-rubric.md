# 审查规则与严重度判据（执行前必读）

本文件是逐条审查的操作规范：六类检查项、缺陷类型、严重度分级、防误判守则、证据与建议标准。所有规则服务于一个目标——**每条问题都能回到原文某一句话，每条建议都能落到具体句子**。

---

## 0. 前置：先建主张清单，再逐条核查

读完全部材料后，先抽取主张清单（写入 `claims[]`），再进入六维审查。抽取时逐条区分 `speaker`：

- `author`：作者在本研究中提出的主张（结论、方法贡献、机制解释）。
- `cited`：作者转述他人/文献的观点（"X 报道了……"、"前人认为……"）。
- `assumption`：明确标注的假设、限定条件、研究前提（"假设……"、"在……前提下"）。

引言中的承诺（"本研究将检验/分析/比较……"）单独登记进 `commitments[]`，供第 4 步"承诺—交付"对照使用。**转述他人观点、明确假设、对照组，不是作者自相矛盾，不得当作缺陷。**

---

## 1. 六类检查项

### 1.1 事实核验（factual_verification）
核查论文内的数值、单位、年代、名称、公式等是否自洽、是否与常识/可获取的公开事实一致。**只报能回到原文某一句的事实问题**；无法外部核验的写 `pending_review`，不得断言"错误"。
典型缺陷：数值前后不一致、单位换算错误、把相关研究的时间/归属张冠李戴。

### 1.2 引用支持（citation_support）
核查被引文献是否支持所引的那句话。仅凭文内转述即可判断"所引内容与主张的强度是否匹配"；引用的真实内容是否被正确转述，无法获取全文时标 `pending_review`，写"需外部核对"，**不得断言"引用不支持"**。
典型缺陷：用"研究 X 证明了 Y"表述实际只有相关性的证据；引用综述/间接来源却当作原始发现。

### 1.3 方法设计（method_design）
核查方法能否回答研究问题：样本与对照设置是否对应目标、混杂/偏倚是否说明、操作定义是否清晰、局限是否声明。
典型缺陷：研究问题问 A，方法只测了 B；缺少必要的对照组；样本选择偏差未说明。

### 1.4 统计报告（statistical_reporting）
核查统计口径与结论方向是否一致、显著性表述是否准确、效应量与置信区间是否报告、多重比较是否说明。**不重算原始数据**，只做口径与表述层面的核对。
典型缺陷：p 值与结论方向相反；把"无显著差异"写成"两组相同"；多重比较未校正却宣称显著。

### 1.5 论证链（argument_chain）
核查从前提到结论的推理是否完整：是否存在跳跃、隐含假设未说明、替代解释未排除、相关与因果混用。
典型缺陷：横断面/观察性设计却用因果动词；把中介/相关关系写成直接因果；排除竞争解释缺失。

### 1.6 学术规范（academic_norms）
核查重复发表/冗余表述、数据可用性与可复现声明、利益冲突与伦理声明、图表与正文一致性。**不做查重与学术不端判定**，只报可核验的规范缺口。
典型缺陷：图表数据与正文描述不一致、方法关键参数缺失致无法复现、结果承诺"数据可获取"却无访问路径。

## 2. 缺陷类型（type）

| type | 含义 |
|---|---|
| `factual_error` | 可回到原文的事实错误 |
| `evidence_insufficient` | 主张有方向但证据不足（样本小、缺对照、缺效应量） |
| `overclaim` | 结论强度超出数据/设计能支撑的范围 |
| `unsupported_citation` | 引用与其支持的主张强度不匹配 |
| `method_mismatch` | 方法回答不了研究问题 |
| `statistical_misreport` | 统计口径或显著性表述失真 |
| `argument_gap` | 推理跳跃、相关当因果、替代解释未排除 |
| `inconsistency` | 跨章节/图表/摘要结论不一致、承诺未交付 |
| `norm_issue` | 学术规范缺口（数据可用性、可复现、伦理声明等） |
| `suggestion` | 非缺陷，可改进的建议 |

## 3. 严重度分级（severity）

| 级别 | 判据（三问，缺一不可，写入 reasoning） | 示例 |
|---|---|---|
| `major` | ① 影响主结论成立 或 ② 不可修正 或 ③ 显著影响可复现性 | 因果结论来自横断面设计；关键参数缺失无法复现 |
| `minor` | 不影响主结论、可修正、可复现性受影响有限 | 局部数值前后不一致；缺置信区间 |
| `suggestion` | 非错误，仅建议提升清晰度/稳健性 | 补充敏感性分析；补效应量报告 |

**禁止一律标"中"**。每条 finding 的 `reasoning` 必须显式写三问：是否影响主结论 / 是否可修正 / 是否影响可复现，再由三问推出级别。

## 4. 状态与置信度

- `status`：`confirmed`（原文可坐实）｜`probable`（证据较强但不唯一）｜`pending_review`（需外部/额外核对）｜`ruled_out`（核查后排除）。
- `confidence`：`high` / `medium` / `low`。status 为 `pending_review` 时置信度不得为 `high`。

## 5. 防误判守则（每条 finding 落笔前自查）

1. **对照组不是缺陷**：实验组与对照组的差异是设计意图，不报"缺少一致性"。
2. **明确假设不是缺陷**：作者已标注"假设/前提/在……条件下"的内容，不当作未说明。
3. **转述他人观点不是缺陷**：`cited` 的观点即使与作者结论不同，也是正常引用，不报作者自相矛盾。
4. **只在材料范围内判断**：材料没给的数据、附录、外部文献全文，不凭常识或文件名臆测。
5. **宁少勿假**：无法确认的条目标 `pending_review` 或写入 `uncertainty`，绝不编造数值、DOI、引用或软件状态。

## 6. 证据与建议标准

- **定位**：`locator` 用语料库定位符（如 `p3 ¶P0012`），精确到段落；`quote` 逐字复制原文，不得改写、不得删减关键限定词。
- **依据**：`evidence` 写判断依据——来自本文哪一段/哪张表、或"需外部核对"。
- **建议可执行**：落到具体句子。写明"把哪句改成什么""补什么证据（样本量/对照组/效应量/置信区间）""把哪个动词降级（证明→提示，因果→相关）"。禁止"建议补充论证""建议加强逻辑"这类空话。

## 7. 每类检查项的"承诺—交付"对照

第 4 步单独做一遍跨章节一致性：把 `commitments[]` 的每条引言承诺，与结果/讨论中的对应交付对照，登记 `delivered_at`（交付位置或 `null`）。摘要与正文结论、方法与结果口径、图表与正文描述，两两核对；发现不一致报 `inconsistency`，并同时记入两条 finding 的定位。

## 8. 逐维探测问题（核查时逐条过）

### 事实核验
- 摘要、正文、图表、结论中的同一数值是否一致？单位是否一致？
- 引用的年代、机构、作者归属是否有误（限可核对项）？
- 公式与文字描述是否自洽？

### 引用支持
- 文内转述的强度（"证明/表明/提示"）是否超出被引研究的设计（RCT/观察/综述）？
- 是否用间接来源或综述代替原始发现来支持强主张？
- 所引文献与主张的主题、人群、物种、时间尺度是否对得上（限文内可判断项）？

### 方法设计
- 研究问题问的指标，方法是否真的测量了该指标？
- 是否有必要的对照组？对照设置是否对应研究目标？
- 样本来源、纳入排除、偏倚与混杂是否说明？未说明则记 `evidence_insufficient`，不臆断。

### 统计报告
- 显著性方向与结论措辞方向是否一致（p<0.05 却写"无差异"、p>0.05 却写"显著"）？
- 是否用"无显著差异"表述"两组相同"？是否缺效应量/置信区间？
- 多重比较是否说明校正？小样本是否被当作稳健结论？

### 论证链
- 结论是否超出前提？是否有未声明的隐含假设？
- 替代解释是否被排除或至少讨论？
- 观察性/横断面设计是否用了因果动词（导致、提升、抑制）？

### 学术规范
- 方法关键参数是否齐全到足以复现？
- 数据可用性声明与"数据可获取"是否给出实际访问路径？
- 图/表数据与正文描述是否对应？

## 9. 工作示例（一条完整 finding，非正式案例答案）

```json
{
  "id": "F001",
  "type": "overclaim",
  "severity": "major",
  "locator": "p4 ¶P0017",
  "quote": "该方法已被证明能够普遍提升所有任务的表现。",
  "claim": "方法对所有任务普遍有效",
  "evidence": "正文仅报告 n=10 单任务样本，未给出多任务或外推证据",
  "reasoning": "影响主结论（把单样本结果外推为普遍结论）；可修正（降级措辞即可）；不影响可复现（方法描述仍在）。",
  "suggestion": "将 p4 ¶P0017 的\"已被证明能够普遍提升所有任务\"改为\"在本样本中初步提示改善\"，并补充跨任务/大样本验证或删去\"所有任务\"限定。",
  "status": "confirmed",
  "confidence": "high"
}
```

要点：`quote` 逐字；`reasoning` 三问齐全且推出 `major`；`suggestion` 落到具体句子的改写与补充证据。

## 10. 结果字段速查

`findings[]` 每条：`id / type / severity / locator / quote / claim / evidence / reasoning / suggestion / status / confidence`。
`claims[]` 每条：`id / text / speaker / section / locator / verdict / evidence`。
`commitments[]` 每条：`id / promise / locator / delivered_at / verdict / note`。
`coverage` 六维：`{status: done|partial|skipped|pending, checked, note}`。
