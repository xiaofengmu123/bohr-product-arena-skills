# 体裁风格与双语表达规则（精简版）

润色前先按输入 `task.md` 确定目标体裁与语言，再把对应规则注入逐句编辑。
规则是**方向**而非模板：只改表达，不改事实与强度（保真规则见
`preservation-rules.md`）。

## 1. 体裁语域矩阵

| 体裁 | 语域要求 | 常见问题与处理 |
|---|---|---|
| 期刊论文 | 客观、信息密度高、被动/中性主动、无宣传词 | 删 `remarkable`/`极其`/`重大突破`；保留数据与限定词 |
| 学位论文 | 正式、章节完整、允许更长的背景铺陈 | 统一术语跨章节写法；人称改为中性（本文/本研究） |
| 基金申请书 | 正式但有前景导向，用"有望/拟/预期"而非"已经" | 区分已证实与预期；避免过度承诺 |
| 审稿回复 | 礼貌、明确、逐条对应审稿意见 | 语气不过度谦卑也不失礼；逐条给出修改定位 |
| 英文摘要 | 简洁、主动语态优先、信息重心前置 | 删中式冗余；主语+谓语尽早出现 |

## 2. 术语一致性（全篇回扫）

1. 同一概念只保留一个规范写法（`glossary.json` 的 `canonical`），别名写入
   `variants`，改文只用规范写法。
2. 缩写首次出现给全称 + 缩写：`deep neural network (DNN)`，之后只用 `DNN`。
3. 大小写、连字符、希腊字母/拉丁符号统一：`T-cell` 与 `T cell`、`in vivo`
   与 `in-vivo` 只取一种，除非领域惯例另有规定。
4. 中英术语对齐：中文术语首次出现括注英文，英文首次出现括注中文，之后一致。

## 3. 中译英表达质量

1. **信息重心前置**：把"研究发现 X"译为 `We found that X`，不要
   `That X was found by us`；主语+谓语尽早出现。
2. **拆直译腔**：`with the development of ...`、`plays an important role`
   按语境改为具体动词（`has increased`、`contributes to`）。
3. **控制名词化**：`the improvement of accuracy` → `improving accuracy`（动作
   需要时）；`conduct an analysis of` → `analyze`。
4. **连接词克制**：`In addition/Moreover/Furthermore` 连用会失真，按逻辑改用
   因果、转折或直接陈述；不新增原文没有的逻辑关系。
5. **数字/单位/引用原样保留**（见 `preservation-rules.md`），只调整语序与
   用词。

## 4. 最小编辑原则（文体不明时的默认值）

- 只改硬语法错误（主谓一致、时态、冠词、标点、悬垂修饰）。
- 不动限定词、不换同义词、不重组信息；在 `uncertainty` 标注"文体未明，
  采用最小编辑"。
- 每句仍逐句产出"原文—改文—修改类型—理由"；不改的句子标 `no_change`。
