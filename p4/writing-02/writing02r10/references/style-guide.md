# 语域与术语治理指南（style-guide）

在逐句编辑（阶段 2）前先读本文件，按任务指定的体裁、受众与语种定基调；未指定时走最小编辑。

## 1. 语域对照（区分“说得像”）

| 体裁 | 语气基调 | 允许 | 避免 |
|---|---|---|---|
| 期刊论文 | 客观、克制、可证伪 | 第一人称复数 we、被动语态、限定词 | 宣传语、绝对化、人称误用、口语 |
| 学位论文 | 正式、章节间自洽 | 术语全篇统一、章节逻辑连接 | 口语、跳跃式省略 |
| 基金申请书 | 目标导向、有据可查 | 本研究/申请人/项目组、可行性论证 | 空泛承诺、越界夸大结论 |
| 审稿回复 | 礼貌、逐条对应 | 先引审稿意见再作答、点对点 | 避重就轻、删减审稿人原话 |
| 英文摘要 | 信息密度高、时态正确 | 现在时结论、过去时方法与结果 | 中式直译腔、冗余名词化 |

- 中文稿按中文正式书面语：多用“本研究/本文/该方法”，避免“我/你”；并列项用顿号。
- 英文稿消除中式英语：去掉冗余名词化（make an analysis of→analyze）、修正主语与信息重心、控制逻辑连接词密度。

## 2. 最小编辑原则（守住“没改坏”）

1. 只改表达，不改事实与强度；限定词、数据、单位、引用、图表指向、因果与相关、否定范围、条件句、量词原样保留。
2. 长句切分时不得拆散承载信息的主从关系；切分后的信息总量不变。
3. 同义替换只在不造成专业含义偏移时使用；术语不做“同义换写”。
4. 拿不准的改动宁可不改，标 `uncertain`/`pending_human`，让第三方判断。

## 3. 术语表治理（守住“改得对、说得像”）

- 每个概念唯一写法：同一概念中英文、缩写、大小写、连字符全篇统一。
- 缩写首次出现给出全称：如“人工智能（AI）”；英文首次出现写 `artificial intelligence (AI)`。
- 术语漂移处理：引言与方法之间同义混用（如 model 与 framework）统一到一个首选词，并在术语表 `terms[]` 记录 `{term, preferred, first_use, note}`。
- 脚本在 `glossary.json` 的 `candidates[]` 自动列出 `A (B)` 与独立大写缩写，Agent 逐条确认后移入 `terms[]`。

## 4. 逐句修改表字段（阶段 2 填写规范）

| 字段 | 含义 | 要求 |
|---|---|---|
| `sentence_id` | 对应 register.json 的句 id | 与基线逐句对齐，不重不漏 |
| `original` | 原句 | 必须与基线逐字一致（空白除外） |
| `revised` | 改句 | 只改表达；不得为空 |
| `edit_type` | 修改类型 | grammar/terminology/register/punctuation/splitting/no_change 等 |
| `reason` | 修改理由 | 足以让第三方判断“该不该改” |
| `evidence` | 证据定位 | locator，如 `materials/paper.md#p3s1` |
| `hedge_justified` | 是否显式说明限定词变动 | 变 true 时必须在 `reason` 写理由 |

## 5. 双通道审校（阶段 3）

先编辑、后独立复核：对照原文逐句回读改文，中英互译时做回译，确认未加强/削弱结论；然后跑 `python3 -B scripts/main.py verify` 得到确定性 `check_report.json`。人工复核负责词表覆盖不到的语义项（因果/相关、专业搭配、语域），脚本负责可机械核验的守恒项。
