# 交付复核清单（对齐评分维度）

交付前逐条核对。括号内为对应的评分维度与分值。

## A. 实际效果（40 分）

- [ ] **任务完成度（15）**：交付"润色后完整文本＋逐句修改表"，而非写作建议或整段重写；`manuscript.md` 含"润色后全文"与逐句表两节。
- [ ] **结果正确性（15）**：`verify` 的 `errors == 0`；数值、单位、引用、图表指向、术语译法均与原文一致；无静默加强/削弱结论。
- [ ] **结果完整性（5）**：指定章节逐段处理；术语表建全；缩写/符号首次出现统一；中英对照与修改清单齐全。
- [ ] **结果可核验性（5）**：每条修改有原文、改文、修改类型、理由；`fact_source_map` 逐条有 `locator`＋逐字 `quote`，第三方可判断"该处该不该改"。

## B. 使用增益（25 分）

- [ ] **质量增益（15）**：同输入、同术语表、同风格规则下，语法修正、术语一致、语义保持、语气贴合稳定优于裸 Agent。
- [ ] **效率增益（5）**：减少人工返修与逐句核对；不把成本转移到事后校对（`verify` 在定稿前已清零 error）。
- [ ] **增益可验证性（5）**：对照条件一致——同一原文、同一术语表、同一评分人、同一验收标准；必要时盲评；`sources` 摘要指纹保证材料一致。

## C. 创新增益（15 分）

- [ ] **新增能力（5）**：术语表驱动全篇一致性回扫、限定强度守恒检查、双语术语对齐、按目标期刊风格改写，至少一项稳定可复现。
- [ ] **方法改进（5）**：最小编辑、分句级编辑、术语表/风格指南注入、改后回读/回译、编辑与审校双通道。
- [ ] **创新证据（5）**：相对基础 Agent、通用写作工具、翻译工具、人工润色基线的边界与价值说明清楚。

## D. 可靠体验（10 分）

- [ ] **调用与易用性（3）**：该润色时触发、纯问答时不擅自改写；粘入纯文本/Markdown/LaTeX 片段或章节稿后输出可直接用。
- [ ] **运行稳定性（4）**：长文本、分章节、多次重复运行、不同学科术语下持续可用；同一段落重复润色结论不漂移（确定性校验）。
- [ ] **异常处理（3）**：超长输入、编码混乱、公式与引用混杂、中英日混排、术语表冲突、目标文体不明均有识别与处置。

## E. 生态贡献（10 分）

- [ ] **文档完整性（3）**：SKILL.md、术语表与风格指南格式、输入输出示例、适用范围、限制、维护信息齐全。
- [ ] **资源可复用性（4）**：术语表、风格规则、测试文本、评分表、脚本可被他人直接用于自己的稿件与学科。
- [ ] **分享推广价值（3）**：沉淀可分享的案例、评测集、术语治理经验与真实应用价值。

## 交付前命令序列

```bash
python3 -B scripts/main.py scaffold     # 1. 早落盘 partial 骨架
# 2. Agent 填 /app/work/edits.json、glossary.json
python3 -B scripts/main.py verify       # 3. errors 必须为 0，warning 逐条处置
python3 -B scripts/main.py finalize     # 4. 组装产物
python3 -B scripts/main.py selfcheck    # 5. 期望输出 selfcheck: OK
python3 -B scripts/main.py selftest     # 6. 包级自检，期望 selftest PASS
```

三项硬门槛：**前 3 分钟落盘骨架**、**`verify` errors 清零**、**`selfcheck` 返回 OK**。
