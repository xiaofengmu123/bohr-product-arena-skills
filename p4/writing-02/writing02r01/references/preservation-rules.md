# 保真与最小编辑规则

本文件规定润色时的"可改/不可改"边界，供 Agent 与复核者逐条对照。核心原则：
**只改表达，不改事实与强度**。以下规则与 `scripts/evidence.py` 的守恒校验一一对应。

## 1. 必须原样保留（硬约束，守恒校验按 error 处理）

- **数字与单位**：数值、小数位、量程、单位不得改动。仅允许排版性归一化
  （如 `12,500` → `12500`），不允许改变量级、精度或单位。
- **引用编号**：`[1]`、`[1,2]`、`[1–3]`、`(Smith 2020)` 的编号、作者与年份
  不得增删或重排；只允许空白与全角/半角括号的排版性归一化。
- **图表指向**：`Fig. 1`、`Figure 1A`、`Table 2`、`图1`、`表2` 的编号与子图
  字母必须对得上，不得改指。
- **否定范围**：`not/no/never/不/未/无/非` 等不得删除或新增，否则意义翻转。

## 2. 限定强度守恒（守恒校验按 warning 处理，须回退或写理由）

- **hedge 词**：may/might/could/suggest/indicate/possibly/可能/或许/初步/提示/
  有望 等，不得被替换为 prove/confirm/demonstrate/证实/证明/确定 等 strong 词。
- **strong 词**：不得被悄悄降级为 hedge；若确需降级，须在 `reason` 写明依据。
- 一句话中"加强"与"削弱"都算偏移，均须显式留痕。

## 3. 因果、相关、条件与量词（守恒校验按 warning 处理）

- **因果 vs 相关**：correlate/associate/相关/关联 不得写成 cause/导致；
  反之亦然。观察性描述应保持相关性措辞。
- **条件句**：if/when/unless/若/如果/除非 不得删除，条件范围不得收窄或扩大。
- **量词**：all/some/most/few/全部/部分/多数/少数 不得增删；"部分"不得变"全部"。

## 4. 术语一致性

- 同一概念全文唯一写法：中英文对应、缩写首次出现给全称（`Full Name (ABBR)`），
  之后仅用缩写；大小写与连字符统一（如 `T cell` vs `T-cell` 全文二选一）。
- 缩写首次出现的"定义句"本身保留为证据 `term`，locator + 逐字 quote 可回源。
- 术语表内部冲突（同一缩写对应两个全称）标 `source_conflict`，不静默选边。

## 5. 语域与体裁

- 期刊论文/英文摘要：第三人称、过去时描述方法与结果、现在时陈述既有结论。
- 基金申请书/学位论文：允许"本项目/本文/申请人"等正式书面语，避免"我/你"。
- 审稿回复：对审稿人意见逐条回应，先复述后修改，保留礼貌语域。
- 中文文本遵循中文书面语规范：全角标点、顿号枚举、平行短语；保留既定术语与
  拉丁缩写的原形。

## 6. 双语处理（中英互译）

- 中译英：重组信息重心（避免直译腔），消除冗余名词化与逻辑连接词滥用；
  但不得为"流畅"而增删数字、限定词、否定或因果关系。
- 英译中：术语译法遵循领域惯例，无法确定时保留原文并标 `pending_human`。
- 双语对照：交付原文—改文对照，逐句保留 `original`/`revised` 两栏。

## 7. 文体/受众不明时的兜底

- 只改硬语法错误（主谓一致、时态、标点、拼写），**不动限定词、数字、单位、
  引用、图表指向与句子信息结构**；并在 `uncertainty` 标注"采用最小编辑"。
