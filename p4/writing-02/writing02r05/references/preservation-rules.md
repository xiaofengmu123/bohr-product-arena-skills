# 保真守恒规则（preservation rules）

润色只改"表达"，不改"事实与强度"。本文件是改写时的硬约束与复核时的判定依据，与
`scripts/checks.py` 的确定性校验对应：脚本负责把"可疑差异"自动挑出来，Agent 负责逐条
"回退或写明理由"，两者叠加，不把保真交给事后印象。

## 1. 限定强度（hedge strength）

| 原文强度 | 允许 | 禁止 |
|---|---|---|
| 弱（may / might / could / 可能 / 提示 / 表明 / 推测） | 保留或更弱 | 删掉后变成强断言 |
| 强（prove / demonstrate / 证实 / 证明） | 保留 | 换成更弱但改变结论方向 |
| 中性（no marker） | 保持中性 | 加入绝对化词 |

判定口诀：**删弱词、加强词都算改强度**。若确有充分依据要调整强度，必须在
`reason` 写明依据并标 `pending_human`，不能静默。

## 2. 数字与单位

- 数值必须逐字保留：`3.5` 不能变 `4`、`1,234` 不能变 `1234`（除非格式规范要求且写明）、
  `p < 0.05` 不能变 `p = 0.04`。
- 单位必须原样保留：`mg/mL`、`μM`、`°C`、`%` 不得改写成"毫克/毫升"或换算成别的单位。
- 范围、上下限、±、置信区间必须整体保留，不得只保留一头。
- 数字与单位的关系（"均值±SD"、"中位数(IQR)"）不得改变。

## 3. 引用编号与图表指向

- 引用编号 `[1]`、`[1,2]`、`[3-5]` 必须一一对应，不得重排、合并或丢失。
- `Fig. 1` / `图 2` / `Table 3` / `Eq. (4)` / `公式(5)` 指向不得张冠李戴。
- 人名-年份引用 `(Smith et al., 2020)` 的作者、年份、顺序不得改动。

## 4. 语义关系

- 因果 vs 相关：`causes` 不写 `correlates with`，反之亦然。
- 否定范围：`not all` 不等于 `none`，`does not support` 不等于 `contradicts`。
- 条件句与量词：`if` / `when` / `only if`、`some` / `all` / `most` / `none` 不得换。
- 主语与信息重心：中译英时允许重排主语，但施事、受事、时态承载的事实不变。

## 5. 术语一致性

- 同一概念全文唯一写法；缩写首次出现给全称，之后只用缩写。
- 中文术语与英文术语、符号必须对齐；同名异译、同义混用要回扫统一。
- 术语表是"唯一事实源"：改写时以 `glossary.json` 的 canonical 为准，冲突标
  `source_conflict`，不静默选边。

## 6. 证据溯源

每个带数字、引用、关键论断的句子都必须有 locator + 逐字 quote，写入
`fact_source_map`。locator 形如 `materials/paper.md#p3` 或 `case.json.text:12`；
quote 必须是材料中的逐字片段，不新增材料外事实。

## 7. 判定流程（每处修改）

1. 该改的是硬错误还是风格？只改硬错误与语域，不做整段重写。
2. 改后回读/回译，对照原文逐条核对上面的 1–5。
3. 跑 `verify`：数字/单位/引用/图表指向/限定词一旦报警，要么回退，要么在 `reason`
   写明依据并标 `pending_human`。
4. 拿不准的用最保守的最小编辑：只改硬语法错误，不改限定词与数据。
