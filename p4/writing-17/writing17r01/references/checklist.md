# 自检与降级清单（对应评分维度）

交付前逐条核验；每条对应一个评分维度。未通过项写入 `selfcheck.json` 的
`checks` 并保留真实状态，不得打勾掩盖。

## 实际效果（40 分）

- [ ] 已读取事实底稿、目标读者、文体、格式约束（先读 `/input/case.json` 与 `/input/task.md`，再读材料本体）。
- [ ] 根节点与层级合理，同级粒度一致，无分类交叉、节点重复、重要信息埋没。
- [ ] 关键概念/问题/方法/证据/结论/任务/风险均已覆盖到对应层级分支。
- [ ] 每个关系都有材料依据，方向正确，无材料中不存在的连接。
- [ ] 关键节点与关系都能回溯到 locator + 逐字 quote（见 `evidence_map.json`）。
- [ ] 交付物可打开、可读、可继续编辑（`.md`/`.mm`），并含真实渲染预览（SVG，或 PDF/PNG）。

## 使用增益（25 分）

- [ ] 固定了确定性流程与脚本，重复运行同一输入结果一致（不写时间戳进 SVG/MM 内容）。
- [ ] 前 3 分钟内已落盘一版 `result.json` 骨架（`status=partial`），之后只做增量改进。
- [ ] 所有产物由脚本生成，减少手工排版、改图与返工。

## 创新增益（15 分）

- [ ] 材料抽取→主题归并→层级→关系→布局为分阶段流水线，可单独替换。
- [ ] 用 `kind` 分类抑制装饰性词语进节点；用 `relation` 枚举约束"连得对"。
- [ ] 证据映射独立成 JSON，与图元一一对应，实现"证据可追溯"。

## 可靠体验（10 分）

- [ ] `python3 scripts/discover_input.py --help` 退出码 0。
- [ ] 空输入目录、坏 JSON、坏编码、缺软件均不崩溃，写合法结果并标 `degradations`。
- [ ] 缺材料/冲突/节点规模爆炸均显式标注，不编造。

## 生态贡献（10 分）

- [ ] SKILL.md 写清用途、触发条件、输入输出契约、异常处理、自检方法。
- [ ] 脚本仅依赖标准库，路径为相对路径 `scripts/*.py`，他人可直接复用。
- [ ] schema 与清单独立成文，可作模板与题集沉淀。

## 降级策略（不允许编造）

| 情形 | 处置 |
|-|-|
| 缺 PDF 文本层 | 用 OCR/渲染工具重读；仍失败则 `insufficient_evidence`，不凭标签猜内容 |
| 缺软件/渲染器 | 保留 `.md`+`.mm`+SVG，注明"PDF/PNG 预览因缺渲染器未生成" |
| 材料自相矛盾 | 两来源都记录，标 `source_conflict`，写入 `uncertainty` |
| 节点规模爆炸 | 按主题归并到 ≤ 60 节点，其余记入 `uncertainty`/`pending_human` |
| 契约字段未知 | `discover_input.py` 从 case.json 回填全部键，缺值给 null/[]，不改名不删键 |
