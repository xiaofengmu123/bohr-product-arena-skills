# 玻尔产品赛（第四期）精造 Skill 包合集

本仓库收录本次比赛期间为每个题目精造的 Skill 包（每题 10 个候选，经静态校验与质量评分后择优提交）。

## 目录约定

- `p4/<题目>/README.md`：题目说明、候选列表、本次提交作品标记
- `p4/<题目>/<包名>/`：单个候选包（SKILL.md + scripts + references + META.json + GITHUB_URL.txt）
- 每个包目录内的 `GITHUB_URL.txt` 为该包在 GitHub 上的公开链接；提交到比赛平台时附带的即是此链接。

共 63 个题目，618 个包。
